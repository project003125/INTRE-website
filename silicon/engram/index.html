02 / 硅基 硅基分支 · 本页 面向「AI Agent 可观测性与控制平面」的那一侧：口径集中在流程定义处，观察落进每日监测流水，边界结论沉淀于基线与总账。本页全部图示与说明只覆盖这一支。 本页覆盖

两条分支同构：硅基分支内部同样分深、广两层——边界基线是深的一层，监测流水是广的一层；工程级治理不分叉，两分支共用同一套入口与归档规则。

What Is Patrolled

巡检什么

  • DAY · 每日按固定口径对可观测性与控制面做边界巡检；提示词与判定口径集中在流程定义处，避免随窗漂移。
  • FLOW · 流水监测流水逐日记录窗口观察，形成可回看的巡检日志。
  • BASE · 基线边界基线沉淀基线互链与演进记录，供跨窗口对表。
  • LEDGER · 总账样本总账累积巡检样本台账，作为上游证据的底册。
The Loop

巡检回路

四个工位首尾相衔：基线的回程使下一个窗口在上一轮的口径上继续，而不是从零开始。

  1. 01 观测 可观测性 · 控制平面 · 学术收敛
  2. 02 记录 窗口流水 · 样本台账
  3. 当前位 03 边界判定 三分类 · 边界外维度
  4. 04 供证 26 号基线
回程 · 基线回指判定口径

回路每日先核对基线的现行口径再开工：新碎片按三分类归档——能干净映射到 R-D-S 或 G-M-A-R 的记为正常覆盖，落入已登记边界外维度的另册归位，两边都进不去的真异常触发边界重审信号；重审后的基线回到下一个窗口的口径上。触碰裁量边界的样本须显式标注，不得当作正常覆盖收档。回路的出口是证据不是结论：覆盖是待验证的假设，是否成立由 26 号一侧判定。
