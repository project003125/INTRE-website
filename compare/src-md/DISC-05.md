## 一、问题的提出

DISC-01 的结论是：

> 基本单位是双范式对比的逻辑起点。变量范式的基本单位是“变量”，状态范式的基本单位是“功能状态 Ψ”。

这个结论意味着：

- 变量范式：基本单位是**可观测的**——量表分数、行为频率、自我报告。
- 状态范式：基本单位是**不可直接观测的**——功能状态 Ψ 是隐状态。

**代价就在这里：**

> 变量范式选了一个“看得见”的基本单位；状态范式选了一个“看不见”的基本单位。

“看不见”意味着：你不能直接拿尺子量 Ψ。你必须从观测数据**反解**它。这就带来了一整套技术难题：逆问题、高维、参数校准、可辨识性、收敛性。

本件要追问：**这笔账，状态范式自己承认了吗？它打算怎么还？**

---

## 二、代价一：逆问题——从观测反解状态

### 2.1 逆问题的定义

从观测数据反推系统状态参数的过程，在数学上属于**逆问题**。

03-A-19 明确指出，逆问题通常具有三个性质：

| 性质 | 含义 |
|---|---|
| **病态性** | 测量噪声可能被放大为参数估计的巨大偏差 |
| **解的不唯一性** | 不同的状态配置可能产生相同的观测输出 |
| **对先验信息的强依赖性** | 没有先验约束时，解可能无限多 |

### 2.2 状态范式怎么还这笔账？

03-A-19 给出了算法路径：

- **卡尔曼滤波**（线性高斯）
- **扩展/无迹卡尔曼滤波**（非线性）
- **粒子滤波**（非高斯）
- **变分推断**（高维近似）

核心思想是**递推贝叶斯估计**：基于群体先验初始化 → 利用状态方程预测下一时刻状态分布 → 获得新观测后计算后验分布 → 迭代。

**但这不是免费的：**

- 逆问题的病态性不能消除，只能**缓解**。
- 解的不唯一性不能消除，只能**通过先验约束缩小解空间**。
- 对先验信息的强依赖性意味着：**先验的质量直接决定估计的质量**。

### 2.3 状态范式的诚实声明

03-A-19 和 01-M-11 都明确承认了逆问题的困难。这不是“假装没有代价”，而是“把代价摆出来，然后给出应对方案”。

---

## 三、代价二：高维——42 维状态空间

### 3.1 高维的困难

Ψ ∈ R^42，这是一个 42 维状态空间。高维带来什么困难？

| 困难 | 含义 |
|---|---|
| **维数灾难** | 参数估计所需的样本量随维度指数增长 |
| **不可视化** | 42 维空间无法直接可视化 |
| **参数校准成本** | 340+ 参数待校准，计算成本高 |
| **稀疏数据问题** | 密集纵向数据仍然稀疏，难以覆盖 42 维空间 |

### 3.2 状态范式怎么还这笔账？

状态范式的应对策略有三条：

**策略一：动态降维。**

05-R-01 #16 的降维必然性测试证明：精简版框架（12 维）会丧失关键区分能力。但实际使用中，**可以聚焦核心致病模块进行动态降维**。42 维是理论建模的完整框架，临床操作中不需要同时使用全部 42 维。

**策略二：层级贝叶斯 + 群体先验。**

01-M-03 §七 的“群体→个体校准轴”：群体先验 → 个体后验。层级贝叶斯通过群体先验约束个体估计，缓解高维稀疏数据问题。

**策略三：多模态约束。**

01-M-11 的多模态融合：语义/行为/神经三模态从不同角度约束同一个潜在状态，使逆问题更可解。多模态数据提高了状态反解的信息量。

---

## 四、代价三：参数校准——340+ 参数待校准

### 4.1 参数校准的困难

状态范式有 340+ 参数，它们全部处于理论设计阶段，等待 PSE-M 仿真验证或 PSE-C 临床校准。

| 困难 | 含义 |
|---|---|
| **参数数量大** | 340+ 参数，远超一般统计模型的参数量 |
| **校准数据稀缺** | 密集纵向 + 多模态数据采集成本高 |
| **校准周期长** | PSE-C 需要持续迭代，每收集新数据触发一轮贝叶斯更新 |
| **模型选择不确定性** | L3 右端式子集 19 条 × 2-3 候选 = 38-57 个候选方程，BMA 计算成本高 |

### 4.2 状态范式怎么还这笔账？

**路径一：PSE-M 仿真生成先验。**

PSE-M 用 10⁴-10⁶ 量级规则编码 ABM 演化，生成先验分布。先验分布精度约 70%（P2i-m），为后续贝叶斯锚定提供合理初始估计。

**路径二：PSE-C 临床锚定。**

PSE-C 用约 1% 的真实临床数据做贝叶斯更新。预测精度可从 70% 的先验精度提升至 87% 的后验精度（P2i-m）。校准是持续迭代的。

**路径三：参数来源链显式化。**

01-M-03 §7.2 的参数来源链：L0 定义 → PSE-M 仿真生成先验 → L1 三模态观测输入 → PSE-C 贝叶斯后验校准 → 方程子层与模型选择子层消费。

**但状态范式也诚实承认：**

- BMA 在 38-57 个候选方程规模下的计算成本和权重退化处理策略尚未设计（01-M-03 已知局限）。
- 当前全部动力学假设与参数处于理论设计阶段（P2i-m）。
- 约 27% 的参数分布仍需 PSE-C 锚定。

## 五、代价四：可辨识性——状态能不能被唯一确定？

### 5.1 可辨识性问题

可辨识性问题是逆问题的核心：**给定观测数据，状态参数能否被唯一确定？**

如果两个不同的 Ψ 配置产生完全相同的观测输出，那么观测数据无法区分它们。这就是**不可辨识**。

### 5.2 状态范式怎么还这笔账？

**策略一：多模态一致性检验。**

01-M-00 §4.3 的间接验证路径 (a)：三通道似然在融合前的内部一致性。若三通道对同一 Ψ_t 的似然峰值严重分歧，提示 L2 融合或 L1 校准存在问题。

**策略二：L3 预测精度反推。**

01-M-00 §4.3 的间接验证路径 (b)：L3 基于 L2 输出的预测精度持续偏低，则反向质疑 L2 估计质量。

**策略三：临床专家交叉校准。**

01-M-00 §4.3 的间接验证路径 (c)：L2 输出的 Ψ_t 后验与独立临床评估的排序一致性。

**关键承认：** 这些间接路径**不构成完全独立验证**，但在无地面真值的系统中是可行的最佳方案。

## 六、状态范式的诚实清单

现在把状态范式承认的代价汇总：

| 代价 | 状态范式承认了吗？ | 还账路径 |
|---|---|---|
| 逆问题病态性 | ✓ 承认（03-A-19） | 卡尔曼滤波、粒子滤波、变分推断 |
| 解的不唯一性 | ✓ 承认（03-A-19） | 先验约束缩小解空间 |
| 高维 42 维 | ✓ 承认（05-R-01 #16） | 动态降维 + 层级贝叶斯 + 多模态约束 |
| 340+ 参数待校准 | ✓ 承认（01-M-03 边界声明） | PSE-M 仿真先验 + PSE-C 临床锚定 |
| BMA 计算成本 | ✓ 承认（01-M-03 已知局限） | 尚未设计 |
| 可辨识性 | ✓ 承认（01-M-00 §4.3） | 间接验证三条路径 |
| 无地面真值 | ✓ 承认（01-M-00 §4.3） | 间接验证，不构成完全独立验证 |

**关键发现：** 状态范式没有回避任何一项代价。它把每一项都摆出来，给出应对方案，同时诚实声明哪些方案还不成熟。

## 七、与变量范式的代价对比

变量范式也有代价，只是代价类型不同：

| 维度 | 变量范式的代价 | 状态范式的代价 |
|---|---|---|
| 基本单位 | 变量（可观测） | Ψ（不可直接观测） |
| 主要困难 | 节点本体不清、构念膨胀、复制危机 | 逆问题、高维、参数校准、可辨识性 |
| 困难性质 | **概念层面的困难**——不知道变量是什么 | **技术层面的困难**——知道 Ψ 是什么，但反解它很难 |
| 能否通过方法改进解决 | 不能——节点本体不清是结构性的 | 能——逆问题、高维、校准都是工程问题 |
| 还账路径 | 无明确路径（这是 DISC-01 的核心论点） | 有明确路径（PSE-M/C、多模态、层级贝叶斯） |

**关键差异：**

- 变量范式的代价是**概念层面的**——它的困难不是“技术不够好”，而是“基本单位本身有问题”。
- 状态范式的代价是**技术层面的**——它的困难是“反解 Ψ 很难”，但这是工程问题，可以通过算法改进、数据积累、计算资源来解决。

这就是 03-A-07 §8.1 说的“原则性问题”与“工程进展问题”的区别：

> 变量范式对 h 的缺席是**原则性的**——语法中无位置。  
> 状态范式对 h 的未完成是**阶段性的**——语法中有位置、参数待填充。

## 自反：如果还账失败会怎样——三支退化情景

> 本节系「状态范式局限性披露」自反节（2026-10-17 议案采纳·载体 15-X-126·处置账 `RPT-双范式对比学习模块-结构范式局限性披露议案-事实核查与批判性吸纳-处置账-v1.0-2026-10-17.md`）。§二至§六回答的是“代价是什么、打算怎么还”；本节回答对称的另一半——**如果还账失败，状态范式会退化成什么**。META-03 §三 已系统载有两套范式的失败模式对比（其结论偏向“技术性、可收敛”的乐观分支）；本节补写**失败分支**，两件互为表里。

**失败分支一：逆问题长期不可缓解。** 若病态性缓解与先验约束长期无效——噪声放大不可控、后验随数据剧烈波动——则 L2 状态估计失据，L4 规划与 L5 干预随之不可兑现。退化形态：状态范式收缩为**概念框架**——M-R-D-S / G-M-A-R 作为描述语言仍有定义价值（D 级），但一切 L/P 级主张不可兑现。

**失败分支二：可辨识性长期失败。** 若 01-M-00 §4.3 的三条间接验证路径长期相互分歧——多模态一致性、L3 预测反推、临床专家交叉校准持续冲突——则“状态被唯一确定”的承诺破产。退化形态：按 DISC-06 §6.1 失效条件第一条（“若状态范式的 Ψ 被证明不可辨识→比较结论需重写”），本系列的分工结论需重写；按体系级自律原则（06-S-06 §7.7 第三条·方向性纪律），框架面临“降级为候选理论语言”的预注册退出条件——不以“骨架幸存”为由延期裁决。

**失败分支三：校准长期到不了可用水准。** 若 PSE-C 锚定不成、约 27% 参数长期悬置、后验精度长期低于可用水准（教材面沿用 70%→87% 的 P2i-m 在册读数，其兑现本身待实证），则全部 P 级主张停留 P 级、不得进入 E 级、对外承诺边界不解除（06-S-06 §7.7 第四条）。顺带一提：03-A-07 §8.1 的 D1b 声明后已附**风险转移声明**——若“心理系统可建模为经典动态系统”这一前提失败，状态范式对 h 的缺席将从“阶段性未实例化”降级为“原则性无法实例化”，承诺随之失效。本分支是它的校准版补充：前提成立而校准长期不成，承诺同样不兑现。

**对 §七 定性的自我校准：** §七 说状态范式的困难“是技术层面的、能通过工程进展解决”。这个定性依赖一个预设——**那些困难原则上可解**。本节三条分支正是这个预设的边界：若任一分支长期成立，“技术性问题”就翻转为“概念性问题”，硬核（基本单位＝Ψ）进入受审状态。这不是本件的原论证，是它的失败模式披露——预先写明它，正是为了不让“保护带可修正”成为无限期豁免。

## 八、一句话总结

> 状态范式换了基本单位，选了不可直接观测的 Ψ，代价是逆问题、高维、参数校准、可辨识性。它没有回避这些代价——03-A-19 承认逆问题病态性，05-R-01 #16 承认高维困难，01-M-03 承认参数校准未完成，01-M-00 §4.3 承认无地面真值。它还账的路径是 PSE-M 仿真先验 + PSE-C 临床锚定 + 多模态约束 + 层级贝叶斯。关键是：这些代价是**技术层面的**，不是**概念层面的**——它们可以通过工程进展来解决，而不是像变量范式的节点本体不清那样，是结构性的。

## 九、留给 DISC-06 的问题

DISC-05 回答了“Ψ 不可观测的代价怎么还”。但它留下一个问题：

> 如果状态范式的代价是技术层面的，那在技术成熟之前，它的结论有多少可信度？在技术成熟之前，两套范式应该怎么共存？

这个问题与 DISC-06（两套范式共存与分工）直接相关，留待最后一篇展开。
