| 概念 | 线框稿（这里） | 设计图稿 / Mockup（已落） |
|---|---|---|
| 描述对象 | 文字 + 区域标注 + 布局图 | 视觉像素 + 节奏 |
| 关注点 | "屏幕上有什么、放哪儿、间距多大" | "长什么样、怎么动" |
| 输出物 | ASCII 布局图 + CSS 测量值 | 高保真 3D 场景 + 标注 |
| 可被开发者"照做" | 部分（需结合 06-design-spec.md） | 是（设计图稿层） |

> 我们的状态：**第 3 步是文字 + ASCII 布局图 + CSS 实测值**——并非传统意义上的"黑白稿 PNG"。
> 优势：所见即所得（基于真实浏览器渲染）；编码实现差异（如 z-index、像素坐标）已透明记录。
> 我们建议：**保留本文件的文字线框稿 + 保留你已有的 4 张截图**，作为视觉稿与开发的"沟通地基"。
