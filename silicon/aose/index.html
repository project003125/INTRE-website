Two-Layer Stack

双层架构

语言模型在上层供能力，Agent OS 在下层管调度与门控。

LLM
语言模型层

作为推理内核供符号域的理解与生成：语言、逻辑、叙事与知识调用在此完成，智能体的意图与语义均经此出入。其边界同样清楚——无具身、无行动后果，推理期冻结、不随反馈自我更新，价值与规则多靠外部注入。工程上按可替换组件对待：不写语言模型本体，只做外挂层。

G-M-A-R · 门控每一次干预
AGENT OS
Agent OS 层

以状态语法把智能体内部状态写成模块、资源、调度、结构四个可观测维度；以操作语法实施干预——门控、调制、校准、重联四类原子操作，各有合法靶点，越界即不合法。下层凭指令集级硬约束行使管理权：语言模型的输出不直接落地，每一次干预都经四门裁定，与训练式软约束划清边界。

Passing the Gates

干预如何过门

一次干预从意图到落地，依次经四道门裁定；每道门只认自己的合法靶点。

  1. IN 输入 意图 · 语义
  2. 首关 G 门控 DSP-F／DSP-B
  3. M 调制 RES-D
  4. A 校准 STR-R
  5. R 重联 STR-C
  6. OUT 落地 可观测状态变更

门控只落在调度通道与序列的激活面上，序列本身的内容面归约到校准来处理；调制只动资源存量，校准只动规则结构，重联只动连接结构——四门靶点互不共享，越界即不合法。过门次序同时是干预深度次序：调度层先稳、资源层再复、结构层最后重建；这条深度序列在本工程里被当作工程指南使用，不是自然定律。

// 合法靶点：每门只认自己那格
GATE     →  DSP-F ｜ DSP-B
         ｜  STR-S（激活面）
MODULATE →  RES-D
ALIGN    →  STR-R
RELINK   →  STR-C

// 归约写法：要改序列，拆成两步
ALIGN STR-R → GATE／训练 STR-S

// 非法直写：靶点互不共享
GATE STR-R ｜ GATE STR-C
ALIGN STR-C ｜ RELINK STR-R
Capability Spectrum

能力光谱

把语言模型的能力面平铺到六个功能格位上：强弱不是有／无二元的开关，而是明显偏科——只有符号一侧接近完备。档位只取「无／部分／有」三档定性描述，不放刻度、不放数值、不作任何测量声称。

  • M1最早 · 单细胞 具身 · 物理基座与能量引擎只能谈论饥饿与疲惫，没有真实的身体稳态；文本知识在，本体不在。 无本体为零
  • M2较晚 · 脊椎动物 认知 · 建模引擎与知识库符号推理与知识调用一侧强，物理动力学预测一侧弱；缺的不是建模，是打脸模型的反馈通道。 部分重度偏科
  • M3晚 · 哺乳动物 意志 · 中央调度器本体不做决策仲裁，冲突目标之间的取舍由外挂编排给；壳给的，不是本体长出来的。 部分外挂补位
  • M4早 · 多细胞 情绪 · 价值评估中心价值排序由外部偏好信号注入，没有体感来源，也没有内生驱动。 部分外生注入
  • M5最晚 · 人类独有 言语 · 符号接口与社会连接语言、逻辑、叙事与对话即其主场，六格里唯一接近完备的一档。 有近乎完备
  • M6最早 · 单细胞 行为 · 外部执行器没有行动出口，工具调用属外挂执行；最古老的行动能力反而最缺。 无近乎为零

六模块在此只作分析格位：借人类功能的这套切分给语言模型的能力面定位，不声称语言模型拥有与人类同型的模块，也不声称其具备体验。格位强弱与功能在进化史上出现的早晚大致相反——这条倒挂关系是待检验假说，不是结论，本页不据此下任何断言。空缺的两格按可替换组件对待：具身与行为的输入输出走可插拔端口，推理期冻结的能力面不随反馈自我更新，因此管理权只能由下层的四门硬约束来行使。
