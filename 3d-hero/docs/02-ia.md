### 1.2 概念骨架：三层架构 × 三通道

所有信息的底层组织逻辑是"三层 × 三通道"模型。2D 网站的模块页对应通道，3D Hero 的 4 幕对应层级叙事。

```
L1 现象层 (Phenomenal)    ← 可观测的心理现象
    ↓ 观测 Observe
L2 功能层 (Functional)    ← Ψ(t) ∈ ℝ⁴²，INTRE 运算中心
    ↑ 校准 Calibrate
L3 神经层 (Neural)        ← 神经回路、脑区激活

三通道汇聚于功能层 L2：
├── UBMP → p(y_b|Ψ)  行为通道（L1 → L2）  对应 2D /ubmp/
├── UPLP → p(y_s|Ψ)  语义通道（L1 → L2）  对应 2D /uplp/
└── UNIP → p(y_n|Ψ)  神经通道（L3 → L2）  对应 2D /unip/

融合公式：
p(Ψₜ | y_{b,t}, y_{s,t}, y_{n,t}) ∝ p(y_b|Ψ) · p(y_s|Ψ) · p(y_n|Ψ) · p(Ψₜ|Ψₜ₋₁)

3D Hero 叙事映射：
├── RCT1 开场    → 品牌入口（不属于三层）
├── RCT2 现象层  → L1
├── RCT3 功能层  → L2（Ψ(t) 的 42 维可视化）
└── RCT4 神经层  → L3 + 三通道 legend（UBMP/UPLP/UNIP 出口）+ D21 转场（纤维束接驳→锚定）
```

## 4. 3D Hero 叙事流程

3D Hero 是单页滚动叙事（1170vh），4 幕基于滚动进度 `p ∈ [0, 1]` 驱动。每幕有明确的淡入、稳态（阅读窗）、淡出区间。滚动进度经 `pace()` 非线性重映射：RCT1→2 紧凑快切（速率 3.5），RCT2/3/4 满屏 sticky 停留（速率 0.38）。

### 4.1 四幕总览：p 进度轴

```
p=0        0.16  0.24  0.26  0.34  0.44  0.52  0.60  0.74  0.80  0.88  1.0
│◄── RCT1 开场 ──►│  ◄── RCT2 现象层 ──►│  ◄── RCT3 功能层 ──►│◄── RCT4 神经层 ──►│
│  满显    淡出    │ 淡入 满显(阅读窗) 淡出│ 淡入 满显(阅读窗) 淡出│ 淡入  满显(永驻)   │
│                  │                      │                      │                    │
│ 星空常驻          │ 星座收敛              │ 晶格展开 + 星辰散布铺满棋盘│ 纤维束生长          │
│ 公式芯片可见      │                      │ 42徽章 + 节点可点      │ 三通道legend + 状态灯│
```

#### 6.2.4b 移动端顶部 banner（Q5 决策 · v2.1 新增）

```
触摸设备首次进入 3D Hero
  │
  ▼
#mobile-banner 顶部横幅显示
  ├─ 文本："用桌面浏览器获得完整 3D 交互体验"
  ├─ z-index: 200（高于所有 HUD）
  ├─ 可关闭（× 按钮）
  └─ 关闭后 sessionStorage 记忆，本次会话不再显示
  │
  ▼
用户点击 × 或继续滚动
  │
  ▼
横幅隐藏，3D 叙事正常进行
```

- 设计意图：移动端 WebGL 性能受限且交互降级，明确告知用户桌面端体验更佳
- 记忆机制：sessionStorage（关闭后本次会话不再打扰，刷新页面后重新显示）

#### 6.2.5 长时间停留 / 不滚动

```
停在 p=0.5（中途）→ 画面停留
  → 晶格 uLattice 半展
  → 通道粒子继续流动（UPLP 绿点持续上行/下行）
  → 鼠标微视差继续响应
  → 无自动播放、无超时跳转
```

- 行为：默认暂停态，等待用户主动继续
- 设计意图：不自动播放避免打扰；用户掌控节奏
- ✅ 已实现（默认行为）

## 11. 出口链接策略（Link-out Strategy）

> IA 不仅是"页面结构"，更是"路径设计"。本章定义 3D Hero → 2D 网站的完整路径规划。

### 11.1 出口策略原则

1. **入口与内容分离**：3D Hero 是"心智入口"，2D 网站是"内容枢纽"
2. **新标签打开**：所有 2D 出口 `target="_blank"`，保留 3D 滚动位置
3. **上下文链接**：链接位置与当前 3D 幕叙事匹配（如 RCT4 的 UPLP 图例 → UPLP 模块页）
4. **简洁可测**：链接用相对路径（部署后填前缀），便于 QA

### 11.2 链接分层

| 层级 | 链接类型 | 数量 | 锚点 |
|---|---|---|---|
| **L1 全局导航** | 顶栏 8 项 + 品牌标志 | 9 | `.nav-links` / `.nav-logo` |
| **L2 概念锚点** | 公式芯片 + 42 徽章 + 节点详情面板 | 3+ | `#formula-chip` / `.badge-42` / `.nd-link` |
| **L3 通道图例** | RCT4 三通道 | 3 | `.legend-item` ×3 |
| **L4 调试/状态** | （无外部链接，仅内部状态） | 0 | — |

### 11.3 链接打开行为

| 链接类型 | target | 备注 |
|---|---|---|
| L1 全局导航 | `_self` | 3D 是单页 SPA，但导航需跳到 2D 主页 |
| L2 概念锚点 | `_blank` | 保留 3D 体验，用户随时返回 |
| L3 通道图例 | `_blank` | 同 L2 |
| 外链（GitHub / Zenodo） | `_blank` + `rel="noopener noreferrer"` | 安全规范 |

### 11.4 链接可见性（按幕）

```
RCT1 开场：9 个出口（L1 全 8 + 公式芯片）   ← 出口最多
RCT2 现象层：9 个出口（L1 全 8 + 公式芯片）   ← 同上（公式芯片保留）
RCT3 功能层：11 个出口（L1 + 公式芯片 + 42 徽章 + 节点详情） ← 节点可点击新增
RCT4 神经层：12 个出口（L1 + 公式芯片 + 三通道图例）          ← 出口最丰富
```

### 11.5 链接点击埋点（与 PRD §12.2 联动）

- `external_link_click` 事件：记录 target_url, source_section, viewport
- 月度报表：按出口位点排序，找出"高 CTR 出口"（优化设计）和"零 CTR 出口"（考虑移除）

### 11.6 链接健康度监控

- 部署后每周跑一次链接检查脚本（curl -I 每个 URL）
- 失效链接 24h 内修复（优先级 P1）
- 2D 网站重构后同步更新 3D Hero 出口路径
