Two-Layer Stack

双层架构

语言模型在上层供能力，Agent OS 在下层管调度与门控。

LLM
语言模型层

作为推理内核供符号域的理解与生成：语言、逻辑、叙事与知识调用在此完成，智能体的意图与语义均经此出入。其边界同样清楚——无具身、无行动后果，推理期冻结、不随反馈自我更新，价值与规则多靠外部注入。工程上按可替换组件对待：不写语言模型本体，只做外挂层。

G-M-A-R · 门控每一次干预
AGENT OS
Agent OS 层

以状态语法把智能体内部状态写成模块、资源、调度、结构四个可观测维度；以操作语法实施干预——门控、调制、校准、重联四类原子操作，各有合法靶点，越界即不合法。下层凭指令集级硬约束行使管理权：语言模型的输出不直接落地，每一次干预都经四门裁定，与训练式软约束划清边界。
