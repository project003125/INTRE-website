第13章 L1-S 语义感知：UPLP 与知识生产

学习目标：完成本章后，你应能够：(1) 复述 S1–S5 编译流水线；(2) 说明 PSL/PCUI/PSA 的分工；(3) 概括共识工程三阶段；(4) 用逻辑指纹判定解析差异；(5) 追踪一条主诉到语义似然。

13.1 五层编译流水线：S1–S5

UPLP 是 PSE 感知层的语义输入端口。它把自然语言编译为语义似然，输出一个 42 维观测块。编译分五层，每层解决一个独立问题：文本如何成为可匹配单元，单元如何成为概念候选，候选如何落到坐标，坐标如何变成似然，似然如何封装成契约。

编号 层名 输入 → 输出 核心动作 典型失败
S1 STP 语义文本预处理 原始文本 → 结构化文本单元 分词、实体识别、语境消歧、形态归一化 否定范围误判、指代未消解
S2 SMT 语义词汇匹配 文本单元 → PCUI 候选集 词条匹配、共现修正、多候选置信度 一词多义、跨流派同义
S3 SCM 语义坐标映射 PCUI 候选 → 42 维坐标分布 按条目坐标字段落到模块与层级 坐标分散、维度稀疏
S4 SCW 语义置信加权 坐标分布 → 语义似然形状 按编译确定性调制 σ_s 歧义大时似然过尖
S5 SLO 语义似然输出 似然 → 观测块 {y_s, σ_s} 按契约封装，未覆盖维写无信息编码 维度重排、值域越界

S1 只产生候选单元，不产生语义判定。它处理分词、实体与指代，把“这半年心里堵得慌，脑子转不动”拆成带时间修饰与身体隐喻的单元。否定与不确定语气在这一层被标记，否则“没那么难受”会被误读为“难受”。

S2 把单元匹配到 PSL-L 词条，产出多个 PCUI 候选。每个候选携带初始置信度；共现模式参与修正，例如“堵”与“胸口”共现时更偏向情绪调度，而不是躯体疾病。匹配不追求唯一，歧义本身被保留为信息。

S3 把候选映射到 42 维坐标。单次语言观测通常只覆盖少数维度，例如只涉及 M4-DSP-B、M4-STR-C、M2-RES-D 与 M2-DSP-B。未覆盖维度不在这一层产生值，留待 S5 写成无信息编码。稀疏是语义观测的常态。

S4 按编译确定性调制似然形状。候选唯一、坐标集中时，σ_s 小，似然尖锐；候选分散、隐喻歧义大时，σ_s 增大，似然平坦。σ_s 不是拍脑袋的置信标签，它是标准差的工程编码，直接决定该维在 L2 融合中的权重。

S5 把似然封装为观测块。观测值落在 \([0,1]\)，不确定度落在 \([0,1/\sqrt{12}]\)；不可编译维度写 \(y=0.5\)、\(\sigma=1/\sqrt{12}\)。输出严格遵循统一契约，语义端口只能细化实现，不能改变输入类型、阶段划分或输出形式。

五层流水线的阶段划分属于契约语义。实现可以替换分词器、匹配算法或映射模型，但不能把“置信加权”并进“坐标映射”，也不能把“似然输出”提前到“词汇匹配”。阶段划分保证每步的输入输出可检查，出错时能定位到层。

13.2 PSA/PSL：从词汇到语义推理

语义编译依赖三层静态知识。它们回答三个不同层级的问题：这个词在语境中指向什么，这个概念的唯一身份与坐标是什么，这些坐标之间允许什么关系。

层 回答的问题 核心内容 编译中的角色
PSL-L 这个词在语境中指向什么？ 术语主表、语义映射、形态变体、上下文规则、多语言对齐 自然语言 → PCUI 候选
PCUI-L 这个概念的唯一身份与坐标是什么？ 编码、核心定义、坐标映射、多流派解释、干预指引 PCUI → M-R-D-S 坐标
PSA-L 这些坐标之间允许什么关系？ 坐标系、操作语法、结构约束、级联规则 约束检查与合法组合

三者构成一条从词汇到语义推理的链条，但“推理”不是自由生成。PSA 只提供约束，不允许编译席自行发明关系。一个主诉被映射为 M4-DSP-B 过度激活后，PSA 知道调度层持续运行消耗 RES-D，也知道 STR-C 可以把情绪与特定线索绑定；如果同一段叙述还报告“累得动不了”，编译结果就必须同时包含 M2-RES-D 与 M1-RES-D 的低值，并由跨层依赖检查其一致性。

PSA 的结构约束包括 6×6 模块依赖矩阵的存在性、STR 三分、三条跨层依赖公理、级联规则与六条动力学约束。它们在 L0 定义，在 L1-S 只读使用。编译不修改约束，也不为个案放宽约束；它只检查候选坐标是否落在合法配置内。级别更高的语义推理——例如从“反刍”推出“注意力资源被占用”——走的是级联模板，不是语言模型的自由联想。

这套分工使语义端口可以被审计。每个输出坐标都能回溯到词条、PCUI 条目与约束检查记录；歧义体现在 σ_s，而不是藏在黑箱分数里。语义似然的强度来自可追溯的映射，不来自模型规模。

PSA 的约束检查不产生新坐标，它只排除非法组合。例如把 M4-DSP-B 标为高激活，同时把 M1-RES-D 标为满值，并不违反单维值域，却与“调度持续运行消耗资源”的跨层公理冲突；检查会要求补充解释或降低置信。语义推理的产出因此是“合法配置”，不是“听起来通顺的解释”。

13.3 共识工程三阶段

术语实例层由三阶段知识生产流水线供给。采集阶段 PCC-P 遵循广度优先：从理论文献、临床实践、社区与新兴来源、多语言来源四类输入采集概念原材料，经基础验证、唯一性、可信度、理论多样性与文化敏感性五重质量门初筛。它容忍适度噪声，目标是把覆盖面拉开，而不是在这一步做精确裁决。

形式化编译阶段 PCF-P 遵循精度优先：跨流派编译席把原材料编译为 PCUI 草案，依次完成理论中立化、参数化定义、M-R-D-S 架构映射、多流派解释添加与逻辑一致性检查。每个概念由多个流派视角独立编译，再经跨流派共识与分窗终审；冲突按“同视角复窗、跨谱系加席、主理终裁”三级递进处理，异议结构化留存。

验证阶段 PCV-P 遵循权威性优先：25–35 人的评议团按五重标准判定条目是否发布——流派覆盖至少四个、总体支持率不低于 80%、各流派内部不低于 60%、临床工作者不低于 70%、无原则性冲突。未达标的条目按支持率分级进入中等修订、重大修订、暂行存档或拒绝。通过验证的条目写入术语实例层，经词典加载接口进入编译缓存，后续观测生效。

阶段 协议 核心任务 执行主体 通过率目标 产物
采集 PCC-P 广度优先采集概念原材料 采集器、复核席、终核席 约 95% 带元数据的概念原材料
形式化编译 PCF-P 把原材料编译为 PCUI 草案 跨流派编译席 约 60% 标准化 PCUI 草案
跨流派验证 PCV-P 按五重标准确立条目权威性 25–35 人评议团 约 75% 可发布的 PCUI 条目

三阶段是离线校准流程，不是运行时流程。它不参与实时编译，只在后台扩充与修正术语实例。运行时发现的新用法进入反馈队列，经三阶段评审后写入术语主表；这一写入属于数据驱动修订，不触发 L0 架构级审查。

通过率目标是协议设计规范，不是实测统计。它说明各阶段预期会过滤掉多少不合格输入：采集容忍噪声，编译收紧标准，验证再把关。失败条目不会被丢弃，而是按支持率进入修订、存档或拒绝队列，异议记录保留，供后续复核。

13.4 逻辑指纹与解析差异治理

同一概念经不同分析者解析，常出现术语、层级侧重与因果路径的差异。差异的根源是聚焦效应：任何单次解析都只采样完整结构的一个剖面。流程聚焦谈调度与资源消耗，结构聚焦谈信念与连接，资源聚焦谈能量与恢复。差异不是逻辑混乱，而是采样不完整。

判定两份解析是否描述同一实体，依据四组逻辑指纹。资源、层级、操作三组指纹要求方向一致；模块指纹允许视角相对的角色分配，只要可归入已建立的多视角集合。标准指纹不是单个解析自带的属性，而是跨视角综合与专家共识建构的规范实体。

指纹 判定问题 取值形式 示例
模块指纹 涉及哪些模块，角色如何？ 多视角集合 {(Mi, role)} 反刍：{(M2, 核心), (M4, 核心)}
资源指纹 消耗或保护哪类资源，方向如何？ {(RES-D, ±), (RES-B, ±)} 反刍：{(RES-D, −)}
层级指纹 表现层与根源层是什么，因果方向如何？ 表现层、根源层、方向 反刍：DSP-B ← {STR-C, STR-S}
操作指纹 优先操作是什么，序列是否符合深度逻辑？ 有序操作列表 反刍：[GATE−, MODULATE+, ALIGN/RELINK]

指纹体系必须可证伪，否则“所有差异都是合法视角”会变成封闭循环。错误解析有五条判据：完全遗漏公认核心模块；资源方向与标准完全相反；层级因果方向颠倒；操作序列违背由表及里的深度逻辑；模块角色与其余三组指纹产生系统性矛盾。任一触发即判为错误解析，退回重审。

治理流程因此是“先采样、再对齐、后裁决”。单份解析不被要求覆盖全貌，但必须声明自己的聚焦视角；跨视角综合产出标准指纹；新解析按指纹比对进入合法集合或错误判据。差异被保留为剖面信息，而不是被强行抹平。

指纹比对的实际用途有三项：合并同一概念的多份解析，检出明显错误的解析，给新条目确定多视角集合。它不用于判定“谁更正确”，因为标准指纹本身是共识建构物；它用于判定“是否可合并、是否需要退回”。

13.5 与 L0、L2 的边界

语义端口对 L0 是强依赖，没有降级。没有 42 维坐标系，S3 不知道坐标映射的靶空间；没有 PSL-L 与 PCUI-L，S2 无法产出候选；没有结构约束，PSA 无法检查合法配置。词典加载是编译的运行前提，不是可选优化。

语义端口对 L2 是供给关系。它输出 p(y_s|Ψ) 的观测编码，L2 负责融合与状态估计。语义端口不估计 Ψ，不预测演化，也不判断干预。语义衰减率 τ 校准的是“陈述何时生效、以何种权重计入当前观测”，属于观测时效处理，不是状态动力学。

知识生产流水线不属 L0。它是有输入、处理、输出的工作流，归入 L1-S 的离线校准；L0 只保留词汇体系结构、编码格式与映射规则。这条边界同时服务修订隔离：术语实例可以快速增补，坐标系与编码规则保持慢速稳定。

语义模态不可用时，L2 把 p(y_s|Ψ) 视为常数，退化为行为加神经双通道融合。这是契约层的降级，不是语义端口内部的重试。恢复后从下一观测周期正常输出，不输出混合状态。

语义端口还承担跨模态对齐服务。行为端口的观测函数锚定必须经语义端口确认；两个量表是否测量同一构念，由 PCUI 映射与编译结果判定。这个服务不改变行为端口的层归属，只为 B2 的桥接门控提供判据。

13.6 一个主诉到语义似然的微案例

一位 34 岁的来访者给出主诉：“这半年心里堵得慌，脑子转不动，晚上躺下就反复想白天说错的话。”以下数值为示意值，用于展示链路，不作为临床参数。

文本片段 S2 候选 S3 坐标 y 初值 σ
心里堵得慌 胸闷-郁结隐喻 M4-DSP-B；M4-STR-C 0.78；0.60 0.18
脑子转不动 认知迟滞 M2-RES-D；M2-DSP-F 0.32；0.40 0.12
反复想白天说错的话 反刍 M2-DSP-B；M2-STR-S 0.74；0.58 0.09
这半年 时程修饰 不新增维度 — —

S1 标记“这半年”为持续时程，标记“转不动”为能力下降而非意愿拒绝。S2 把“堵”匹配到情绪调度隐喻，而不是心肺症状；把“反复想”匹配到反刍条目。S3 落出五个维度，其余 37 维保持空白。

S4 按歧义调 σ。“反复想”指向明确，σ 取 0.09；“堵”是文化隐喻，候选分散，σ 取 0.18。S5 把五个维度写成观测值，其余维度写 \(0.5\) 与 \(1/\sqrt{12}\)，形成 42 维观测块。

L2 收到观测块后，用截断高斯核构造语义似然：

\[ p(y_s\mid \Psi) = \prod_i g\bigl(y_s[i];\ \Psi[i],\ \sigma_s[i]\bigr) \]

语义似然在 M4-DSP-B 与 M2-DSP-B 上较尖，在 M4-STR-C 上较平，在未覆盖维度上是常数。它与行为似然、神经似然相乘，再乘先验转移项，得到后验。语义通道的贡献是“把主诉转成带不确定度的坐标读数”，不是给出诊断。

这个案例也显示编译的边界。主诉没有提到睡眠、食欲或社交，语义端口不会凭空补出 M1-RES-B 或 M5-STR-C 的观测；这些维度只能由行为量表、数字表型或神经信号补充。缺什么，就在融合中缺什么，不用猜测填满。

当行为与神经通道同时在线时，语义通道的贡献会被自动加权。若行为量表覆盖了 M2-RES-D，而语义块在该维只有隐喻读数，L2 会用较小的 σ 压制语义噪声；若行为端口缺失，语义块就承担更多权重。权重不是固定的，由每次观测的 σ 决定。
