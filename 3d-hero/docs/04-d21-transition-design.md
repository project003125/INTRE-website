## 1. 问题陈述：当前转场缺了什么

### 1.1 现状（代码实测）

当前 RCT3→RCT4（p ∈ [0.72, 0.92]）的实际行为：

```
p 0.72 ─ 0.74 ─ 0.88 ─ 0.90 ─ 1.00
  │        │      │      │      │
  │        │      │      │      └─ brainReveal 完成，脑图满显
  │        │      │      └─ fiberFade 完成（DTI 平面淡入完毕）
  │        │      └─ latticeFade 完成（棋盘淡出完毕）
  │        └─ 棋盘开始淡出（latticeFade 起点）
  └─ DTI 脑图开始从后方淡入（fiberFade 起点）
```

- **棋盘**：`latticeFade = … × (1 − ss(p, 0.74, 0.88))`，节点 `nodeFade` 同步淡出
- **脑图**：`dtiMat.uOpacity = 0.85 × (fiberFade + 0.15 × brainReveal)`，纯透明度淡入
- **纤维束**：`rootGroup.visible = false`——**代码里有一套"节点扎根"纤维束（42 节点 × 3 条贝塞尔），但已被淘汰隐藏，当前一帧都不渲染**

### 1.2 三个核心缺口

1. **"约束"从未发生**：棋盘在 0.74 开始消失，而（被隐藏的）纤维束即便启用也要到 0.90 才长完——纤维束还没碰到节点，棋盘已经没了。两个层从未在视觉上"接触"。
2. **脑图是"贴图"而非"结构"**：DTI 是一张 2D 参考图淡入，与棋盘的 42 个节点没有任何对应关系，观众看不出"哪个脑区约束哪个维度"。
3. **叙事断裂**：RCT3 讲的是"功能层 = 42 维状态空间"，RCT4 讲的是"神经层 = 白质纤维束"。当前转场只是"一个淡出、一个淡入"，没有回答 PRD 提出的核心问题——**功能层的几何结构如何被神经回路塑造？**

### 1.3 理论约束（必须守住）

INTRE 是**功能层心理学**：功能层真实存在、不可还原为神经层，但**受神经层约束**。因此转场绝不能表达成"功能层消失/被脑吸收"（那是还原论），而应表达成"**功能层被锚定/被塑形，但依然在场**"。这是评判一切方案的最高标准（见 §5"理论保真度"一列）。

## 2. 技术底座盘点（现有可复用资产）

设计前先清点代码里已有的"积木"，四个方案全部建立在这些资产之上，**无需引入新依赖**：

| 资产 | 位置 | 能力 | 可复用于 |
|---|---|---|---|
| `rootFibers` | L1543-1594（已隐藏） | 42 节点 × 3 条二次贝塞尔纤维束，带 `growDelay`（中心早→边缘晚）、逐条 `Line` + 可选圆柱 | A/B/D 的"纤维束生长" |
| `brainSDF` / `sampleInBrain` | L1601-1615 | 大脑轮廓 SDF（大脑/颞叶/小脑三椭圆并集），可在脑内采样任意点 | 所有方案的"脑区靶点" |
| `dtiMat.uPulsePos/uPulseRadius/uPulseStrength` | L1470-1472 + frag shader | DTI 平面上从某点向外扩散的环形脉冲波 | D 的"脑区点亮" |
| `makeChannelPoints` / `updateChannel` | L1634-1700 | 沿 CatmullRom 曲线流动的点粒子（UPLS/UNIS/UBMS 三色） | A/C/D 的"信号粒子" |
| `nodes[]` + `writeLatticePairs` | L1369-1418 | 42 个独立 Mesh，位置每帧动态写入，连线自动跟随 | B 的"形变"（改 position 即可，连线免改） |
| `nodeDelay` | L1382-1383 | 中心→边缘的错峰系数（0~0.20） | 所有方案的"逐节点 stagger" |
| `curves[]`（120 条脑内弧线） | L1596-1632 | 脑内白质弧线，供通道粒子流动 | C 的"脑内循环" |

**关键几何事实**（设计时反复用到）：

- 棋盘：6 列 × 7 行圆柱，半径 5.5，y ∈ [−4.5, 4.5]，z ∈ [−5.5, 5.5]
- 脑：中心约 y = −14，DTI 平面 14×18，`position.y = lookPos[1]`（随相机注视点下移）、`z = −6`
- 相机：K3b(0.74) `(0,0,19)` → K4(0.84) `(0,−6,26)` → K5(1.0) `(0,−15,32)`——**相机在转场中垂直下潜 15 个单位**

> 💡 **电影感机会**：相机下潜路径（y: 0 → −15）正好平行于"棋盘层（y≈0）→ 脑层（y≈−14）"的连线方向。任何连接两层的纤维束，在相机下潜时都会被"侧面掠过"，形成极强的纵深叙事。**纤维束应当是"垂直的线"，相机沿着线下潜。**

## 3. 方案 A：突触接驳（Synaptic Docking）

### 3.1 核心隐喻

**约束 = 可见的 1:1 连接。** 脑区像突触一样"长出"纤维束，向上攀爬，逐一接驳到棋盘的 42 个节点；接触瞬间节点被"点亮"。观众第一次看清：**每个功能维度，都对应一个神经底座。**

### 3.2 叙事时间轴（替换现有 0.72–0.92）

```
p 0.70 ──── 0.80 ──── 0.86 ──── 0.94 ──── 1.00
   │          │          │          │          │
   │ 纤维束生长 │ 节点接驳点亮 │ 信号下行  │ 相机下潜   │
   │ 脑→棋盘   │ 错峰闪琥珀   │ 光点沿束入脑│ 束成垂直线 │
   └ 脑图先透出 └ 棋盘不减反亮 └ 节点转通道色└ 棋盘幽灵化 │
```

- **0.70–0.80 纤维束生长**：复用 `rootFibers` 的贝塞尔 + `growDelay`，但把终点从"向后随机"改为**脑区靶点**（`sampleInBrain()` 采样，映射到 y=−14 平面）。每条束从脑端向节点端生长（`uGrow` 控制可见段）。
- **0.80–0.86 接驳点亮**：束尖触达节点的瞬间，该节点触发一次脉冲——scale 1→1.6→1，颜色从 Navy-50 闪到**琥珀**再落到所属通道色（UPLS 绿 / UNIS 蓝 / UBMS 棕，按列分配）。复用 `nodeDelay` 做中心→边缘错峰。
- **0.86–0.94 信号下行**：节点的光"分流"进纤维束——小光点沿束从节点端滑向脑端（复用 `makeChannelPoints`，方向设为节点→脑）。**寓意：功能活动被神经连接所承载、所约束。**
- **0.94–1.00 收尾**：相机下潜，纤维束成为连接两层的垂直丝线；棋盘节点缩至 0.4 倍、透明度 0.35（**幽灵态，不消失**），脑图满显。

### 3.3 代码改动点

| 改动 | 说明 | 工作量 |
|---|---|---|
| 重建纤维束终点 | `rootFibers` 终点改为 `sampleInBrain()` + y=−14 平面投影；每节点 1–2 条（42–84 条，非 126 条，减负） | 小 |
| 启用 + 重定时 | `rootGroup.visible = true`，`uGrow = ss(p, 0.70, 0.80)`，替换 `latticeFade` 的 0.74 起点 | 小 |
| 节点接驳脉冲 | 给 `nodes[i].material` 加 per-node 颜色/缩放动画（42 个 Mesh 各自材质，本就独立） | 中 |
| 下行光点 | 新建一组 `Points`，沿节点纤维束曲线运动（复用 `updateChannel` 逻辑） | 中 |

### 3.4 权衡

- ✅ "约束"第一次被**看见**（1:1 连线），叙事冲击强
- ✅ 复用度高（rootFibers + growDelay + channelPoints 全是现成的）
- ✅ 相机下潜时"沿束滑行"，电影感最佳
- ⚠️ 42×2 条束 + 下行光点，需严格控制透明度层级，否则视觉过载
- ⚠️ "接驳点亮"的错峰节奏要和 `pace()` 对齐，否则像随机闪烁

## 4. 方案 B：约束形变（Constraint Morphing）

### 4.1 核心隐喻

**约束 = 几何被塑形。** 棋盘不消失——它被"拉"向大脑。每个节点逐渐移向其对应脑区的投影位置，规则的 6×7 圆柱棋盘**扭曲成一个脑形星座**。"棋盘的形状由大脑决定"——这是"神经回路塑造功能层几何"最字面、最有力的表达。

### 4.2 叙事时间轴

```
p 0.72 ──── 0.80 ──── 0.92 ──── 1.00
   │          │          │          │
   │ 纤维束接驳 │ uConstraint 0→1 │ 变形棋盘融入脑轮廓 │
   │ （同方案A）│ 节点被拉向脑区  │ 成为"脑的星座"    │
   └ 脑图透出   └ 连线跟随形变   └ 相机下潜          │
```

- **0.72–0.80**：纤维束接驳（同方案 A 第一段），建立"谁拉谁"的对应关系。
- **0.80–0.92 形变**：`nodes[i].position = mix(原位, 脑靶点, ease(uConstraint × stagger_i))`。**连线零改动**——`writeLatticePairs()` 每帧从 `nodes[].position` 重算，自动跟随。棋盘从"圆柱"渐变成"脑形点云"，连线网络随之扭曲。
- **0.92–1.00**：变形后的"脑形星座"与 DTI 脑图重叠，节点淡至 0.5，成为脑轮廓上的"42 个锚点"。

### 4.3 脑靶点计算（预计算，非实时）

对 42 个节点，各求一个脑表面靶点：
- 按列（6 个模块）映射到脑的 6 个纵向分区，按行（7 个子维度）映射到深度
- 用 `brainSDF` 把靶点约束到脑轮廓内（`brainSDF(x,y) < 0`）
- 保留 z ∈ [−2, 2]（脑的"厚度"），避免全压到一个平面

### 4.4 权衡

- ✅ **概念纯度最高**：几何被塑形 = 理论的字面可视化，一眼读懂"神经塑造功能"
- ✅ 连线形变零成本（writeLatticePairs 已动态）
- ✅ 棋盘"在场"，无还原论风险
- ⚠️ 42 个点交叉移动，中间帧可能混乱（需精心设计靶点布局避免连线打结）
- ⚠️ 棋盘"棋谱/规则"的隐喻在形变中被削弱（变成了"星群"）
- ⚠️ 脑靶点布局需要反复调参（美学 + 解剖合理性），调参成本最高

## 5. 方案 C：共振廊道（Resonance Corridors）

### 5.1 核心隐喻

**约束 = 持久的关系，而非一次性事件。** 不做"转场动画"，而是建立一种**持续存在的结构**：每个节点与对应脑区之间有一条半透明"廊道"（管状），廊道里信号粒子**双向流动**——脑→节点（自下而上的约束）与节点→脑（自上而下的调节，呼应 REVER）。棋盘变暗但永不消失，与脑图**永久共存**。

### 5.2 叙事时间轴

```
p 0.72 ──── 0.84 ──── 1.00（并持续到 RCT4 全程）
   │          │          │
   │ 廊道逐条浮现 │ 双向粒子流启动 │ 三层共存稳态 │
   │ （错峰）    │ （脑⇄节点）   │ 棋盘幽灵+脑满显│
```

- **0.72–0.84**：42 条廊道（细管或粗线，Navy-400，透明度 0.25）错峰浮现。
- **0.84 起**：粒子双向流动。下行（约束）用 UNIS 蓝，上行（调节）用 UPLS 绿——**顺带把三通道叙事延续到 RCT4**。
- 棋盘 `nodeFade` 下限从 0.3 提到 0.4，连线保留 0.2——**功能层始终在场**。

### 5.3 权衡

- ✅ **理论保真度最高**："约束是状态，不是事件"——功能层永远被约束，从未消失。最贴合 INTRE 反还原论立场
- ✅ 实现最简单（无生长动画、无形变、无脉冲序列，只有"浮现 + 粒子"）
- ✅ 双向流为 REVER（自上而下调节）埋下视觉伏笔
- ⚠️ 缺乏"时刻"（no moment）——转场张力平淡，更像一个静态增强层
- ⚠️ 42 条廊道 + 棋盘 + 脑图三层同屏，信息密度高，需做减法（如只对 6 个模块代表节点建廊道）

## 6. 方案 D：维度坍缩 → 锚定（Dimensional Anchoring）

> ⚠️ 原构思叫"坍缩"，但"坍缩/吸收"有**还原论误读风险**（仿佛功能层消失了）。保留其"光点沿束入脑 + 脑区点亮"的戏剧性，但把结局从"棋盘清空"改为"棋盘锚定"——节点的光沉入脑区，但节点的"座"留在原处。**所以本方案落地时应叫"锚定"而非"坍缩"。**

### 6.1 核心隐喻

**约束 = 功能活动内化于神经底座。** 接驳完成后，每个节点把一部分"光"沿纤维束注入对应脑区，脑区被逐一点亮（DTI 脉冲环）。**42 维没有消失，它们在脑里有了"回声"。** 呼应 RCT1 公式芯片 `Ψ(t) ∈ ℝ⁴²`——状态向量"落"进了神经基底。

### 6.2 叙事时间轴

```
p 0.72 ──── 0.82 ──── 0.94 ──── 1.00
   │          │          │          │
   │ 纤维束接驳 │ 节点注光入脑 │ 脑区依次点亮 │ 棋盘留座，脑满显 │
   │ （同方案A）│ 光点沿束下行 │ uPulse 环扩散│ 节点幽灵化      │
```

- **0.72–0.82**：纤维束接驳（同方案 A）。
- **0.82–0.94 注光**：节点 scale 1→0.5（**不清零**），同时一个亮色光点从节点出发沿束滑向脑端。
- **光点抵达瞬间**：触发 `dtiMat.uPulsePos = 脑区UV, uPulseRadius 0→0.3, uPulseStrength 1→0`——DTI 图上该脑区荡开一圈脉冲环。**复用现成 shader，零新增。**
- **0.94–1.00**：42 个脑区陆续点亮完毕，脑图满显；棋盘节点留在原处（0.5 倍、0.3 透明），成为"锚座"。

### 6.3 权衡

- ✅ **戏剧性最强**："注光—点亮"是四个方案里最有"时刻感"的
- ✅ 复用 `uPulse` 现成基础设施，脑区点亮零成本
- ✅ "锚座"结局守住了反还原论（节点还在，只是光进了脑）
- ⚠️ 42 次脉冲若太密集会像"烟花"，需控制节奏（建议分 6 批，每批一个模块的 7 个节点）
- ⚠️ "光沉入脑"仍可能被误读为还原——**必须靠 RCT4 文案锚定**（见 §8）

## 8. 推荐方案：A + D 两幕混合（"接驳 → 锚定"）

### 8.1 为什么是混合

单一方案都有短板：A 有连接但无"时刻"，D 有"时刻"但连接建立得太快，C 太平，B 太险。**A 和 D 恰好互补**——A 负责"建立约束"（连接可见），D 负责"内化约束"（活动入脑）。合起来是一个完整的两幕叙事：

> **第一幕（接驳）**：神经层长出纤维束，接住每一个功能维度——"功能层不是凭空悬浮的，它被神经连接托住。"
> **第二幕（锚定）**：功能活动沿约束注入神经底座，脑区逐一点亮——"功能层的每一次运作，都在神经层留下回声。"

## 9. 风险与已决问题

1. **纤维束密度**：42 节点 × 几条束？1 条太稀疏、3 条太密。建议先做 1 条/节点（42 条）看效果，不够再加到 2 条。
   → ✅ 已决：42×1（每节点 1 条主束），先做 42 条看效果，不够再对 RES-D 首行加辅束（共 48 条）。(D38)
2. **脑区靶点布局**：6 个模块如何映射到脑的分区？需要一张"模块→脑区"的对应表（可先用占位布局，标注"示意"，避免伪科学精确性）。**这是 B 和 A+D 共同的前置工作。**
   → ✅ 已决：用"模块→脑叶"粗映射（空间分区而非解剖对应），标注"示意映射"。M1 具身→顶叶，M2 认知→前额，M3 意志→前扣带，M4 情绪→颞叶/杏仁核区，M5 言语→左颞-额，M6 行为→运动/小脑。实现上用分区约束采样（brainSDF + x/y 范围限制）。
3. **通道色分配**：接驳点亮时节点闪哪个通道色？按列（模块）还是按行（子维度）？涉及三通道叙事在 RCT4 的延续，需与 PRD 对齐。
   → ✅ 已决：按行分配三色。RES 行=UPLS 绿 #5A8270，DSP 行=UNIS 蓝 #5B7080，STR 行=UBMS 棕 #8B7360。(D36)
4. **性能预算**：42 条束 × 18 段 + 42 个下行光点 + 6 批脉冲，在移动端（粒子已限 400）是否吃得消？需要在目标机上实测帧率。
   → ✅ 已决：42 条 Line × 18 段 + 42 个下行光点 + 6 批脉冲。移动端粒子已限 400，纤维束用 Line 不用 Cylinder（D38），性能可控。需实测。
5. **reduced-motion 降级**：整个"生长→注光→点亮"序列在 `prefers-reduced-motion` 下如何降级为静帧？（现有 fallback 是纯 2D 静帧，转场序列需要一个"约束态静帧"。）
   → ✅ 已决：定格 p=0.86（接驳完成态）。(D37)
6. **与 RCT4 脑图缩放的协调**：脑图 `brainScale` 在 0.72–1.0 从 1.0→2.1，纤维束靶点是否要跟随脑图缩放？（否则束尖会"脱靶"。）**这是最容易翻车的点，务必在实现时处理。**
   → ✅ 已决：纤维束终点锚定在脑轮廓归一化坐标上，每帧乘以 brainScale，确保束尖永远贴在脑区上。
