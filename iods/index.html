IODS

INTRE 本体定义系统 · L0 本体（P7 两对外系统之一）定义系统
IODS 是 INTRE 管线体系 L0 本体——为整条管线（L0→L5）提供命名空间与合法性：42 维 M-R-D-S 状态坐标系、G-M-A-R 操作语法、PCUI/PSL 知识基础设施。L0 文档族由三份组成：IODS（本文档） + 01-M-08 G-M-A-R 操作语法 + 01-M-09 S-P 环境参照系。IODS 是原 UPLS 定义身份（UPLP-A）的整体继承者，不含运行时、无 API、不含动力学方程——它是所有观测、估计、规划与执行的静态参照系。

一、M-R-D-S 内感架构（状态坐标系）

M-R-D-S 是 INTRE 描述心理系统内部状态的诊断语法。完整 42 维坐标系：6 模块（M） × 7 维度（R-D-S），状态向量 Ψ ∈ ℝ⁴²。

1.1 六功能模块（M1-M6）

M1 · EMB

具身

物理基座与能量引擎。为所有心理活动提供生物能量与稳态；约束其他模块的运行上限。

M2 · COG

认知

建模引擎与知识库。构建关于世界、自我和未来的内部模型；进行推理与预测。

M3 · VOL

意志

中央调度器。在冲突目标间做出决策并调度系统资源；设定优先级与启动前台进程。

M4 · EMO

情绪

价值评估中心。对内外刺激赋予效价，生成动机优先级；在 D 矩阵中居枢纽地位。

M5 · LIN

言语

符号接口与社会连接。负责内部叙事、逻辑符号操作和外部沟通；UPLP 编译与解码的载体。

M6 · BEH

行为

外部执行器。将内部意图转化为物理行动并收集反馈；UBMP 测量通道的输出端。

1.3 42 维坐标系

状态空间由 6 模块 × 7 维度张量积构成，每一模块包含 RES-D / RES-B / DSP-F / DSP-B / STR-R / STR-C / STR-S 七个维度，共 42 个基本诊断维度。

// 状态向量定义
Ψ ∈ ℝ⁴²
Ψ = { Mᵢ-X : i ∈ [1,6]，X ∈ {RES-D, RES-B, DSP-F, DSP-B, STR-R, STR-C, STR-S} }
分量命名：模块前缀 + 维度名（如 M4-DSP-B、M2-STR-R）

1.4 示例：抑郁向量的 M-R-D-S 表示

// 抑郁状态的 M-R-D-S 向量表示
{
  M1: { RES-D: 20, RES-B: 35 }, // 能量极低
  M2: { STR-R: "自我否定信念", STR-C: "失败→无价值" }, // 规则偏差 + 病态连接
  M3: { DSP-F: 0.3, DSP-B: 0.8 }, // 前台调度薄弱，后台反刍
  M4: { 效价: -0.7, 唤醒度: 0.2 }, // 负性低唤醒
  M6: { 行为抑制: 0.9 } // 行为输出受阻
}

二、G-M-A-R 操作架构

G-M-A-R 是 INTRE 的操作语法——四种原子操作（GATE / MODULATE / ALIGN / RELINK）回答"针对这个状态，能做什么"。各操作有严格的靶点合法性矩阵，非任意对应。完整定义、靶点矩阵、D→R→S 干预序列、组合规则见专项文档 01-M-08 L0-G-M-A-R 操作语法。

GATE · 门控

通道开关：启动、抑制或重定向目标进程。调节激活阈值，不改变进程内容。

直接合法靶点：DSP-F / DSP-B / 运行中的 STR-S 序列

MODULATE · 调节

数量调节：注入或节约能量，改变资源存量水平与可用性。

直接合法靶点：RES-D（唯一直接合法）

ALIGN · 校准

规则修正：改写错误的、不合理的信念或决策算法。

直接合法靶点：STR-R（规则内容）

RELINK · 重联

联系重构：解除病态的情感绑定或建立新的价值连接。

直接合法靶点：STR-C（连接结构）

靶点合法性：四种操作与 R-D-S 各层级之间存在严格的对应关系。L4 规划生成的任何操作序列，其每一操作必须落在对应操作的直接合法靶点集内（01-M-08 §3.1 矩阵）。

D→R→S 干预序列：系统性干预默认遵循"调度稳定 → 资源恢复 → 结构重建"三阶段（工程指南，非自然定律；01-M-08 §四）。

三、结构约束

结构约束定义状态空间必须满足的形式化规则，回答"什么存在、什么和什么有关"，属结构规律（不可被数据修订）。

3.1 D 矩阵存在性

存在一个 6×6 模块间依赖矩阵 D，定义 M1-M6 之间的功能影响关系：

性质定义
维度D 为 6×6 方阵，行/列对应 M1-M6
有向加权D[i][j] 表示模块 i 对模块 j 的功能影响强度
枢纽结构M4（情绪）在结构上占据枢纽位置（最高出度+入度），M3 次之
有向无环依赖关系构成有向图，循环依赖不属于定义范围

D 矩阵的边强度数值与概率分布不在 L0 定义，属 L3 参数子层（SPSM-L 结构机制库）。

3.2 STR 三分

S 层（结构）分为三类稳定配置，STR-R / STR-C / STR-S 在功能上互斥且联合覆盖结构层：

类别对象功能角色
STR-R规则内容决定"如何评估"（解释模型、信念、决策算法）
STR-C连接关系决定"什么与什么绑定"（情感连接、概念关联、意义绑定）
STR-S序列程序决定"按什么顺序执行"（习惯脚本、行为序列、作息节律）

3.3 跨层依赖公理

R-D-S 三层之间存在三条跨层依赖公理：

  • 调度依赖资源：DSP 持续运行消耗 RES-D；调度能力受资源水平约束。
  • 结构塑造调度：STR 决定 DSP 的触发条件与执行路径。
  • 资源约束结构：STR 的改变需要充足 RES，属高能耗操作。

3.4 级联规则

跨模块级联指一个模块或层级的异常经 D 矩阵与跨层依赖传导至其他模块/层级的过程：

  1. 级联存在性：M1-M6 通过共享资源池、互为输入输出的信号通路与层级化控制依赖实现功能耦合。
  2. 典型传导机制（功能层推导示意，非经验校准值）：资源供给受限（M1 → M3/M2）、调度控制降级（M3 → M6/M4/M2）、结构性错误归因（M4/M6 → M2 → M5）。
  3. 级联路径开放性：典型机制未穷尽所有级联可能性，是否存在其他重要传导机制是开放的理论与实证问题。

3.5 六条动力学约束

以下六条"动力学约束"是结构规律的操作化表述（非动力学方程本身）：

序号约束结构语义
1资源流守恒模块间资源消耗、转移与补充构成总量约束下的闭合回路；可动用资源总量存在结构上限
2恢复不对称消耗速率与恢复速率在结构上不对称——恢复慢于消耗
3级联阈值模块间影响存在触发阈值；未越过时为局部扰动，越过时放大为跨模块级联
4改变耗时结构性改变（STR 层）时间尺度慢于资源层与调度层——层间变化速率存在数量级分离
5弹性回滞偏离基线后的恢复路径存在回滞：去程与回程不完全重合，需额外能量越过恢复阈值
6系统-环境耦合系统与环境双向耦合：环境经 S-P 参照系驱动系统，系统经行为输出反作用于环境

结构规律的操作化表述，非动力学方程：L0 只定义上述六条约束的存在性与结构语义，方程形式与参数数值在 L3 动力学层（方程子层 + 参数子层）展开。修订条件为架构级（A-16 四条件），参数数据不能直接修订结构约束。

四、知识基础设施

IODS 的概念编码体系由两个核心库构成：PSL-L 词汇库（自然语言接口）与 PCUI-L 概念映射库（核心概念层）。两者协作完成异质化语言输入到 42 维坐标系的标准化。

4.1 PCUI-L · 心理概念统一映射库（核心概念层）

为每个心理学概念分配唯一的结构化 PCUI 编码（Psychological Concept Unique Identifier），将不同流派的术语统一定位到 M-R-D-S 坐标上。

PCUI 编码格式

// PCUI 编码格式（核心定义层）
{FunctionalCode}.UPLP.v{Version}.{Sequence}#{ModuleSignature}
// ModuleSignature 角色标签：C=Core（核心，M4）、I=Impact（受冲击，M2/M3）、
// S=Support（支撑，M1）、O=Output（输出通道，M6）

PCUI 条目六要素

组成内容
核心定义理论中立的功能性定义（提取自多流派共识）
坐标映射完整的 M-R-D-S 坐标映射（模块 × 层级 × 参数范围和分布）
多流派解释CBT、精神分析、人本主义、神经科学等视角，标注证据等级
干预指引推荐的 G-M-A-R 操作序列（合法性受 01-M-08 靶点矩阵约束）
文化变体各文化的表达差异与坐标权重调整语义
验证记录专家共识度、临床验证数据、异议记录

PSL-L 定义异质化语言输入（临床口语、流派术语、文化隐喻、躯体化表达）与标准化 PCUI 标识符、M-R-D-S 坐标之间的词汇映射关系。

核心定义层 vs 术语实例层：PCUI/PSL 编码体系与五层词汇结构属核心定义层（架构级 A-16 四条件，极慢）；具体术语词条增补、归属调整属术语实例层（数据驱动，由 L1-S 通过知识生产流水线管理，详见 01-M-07）。

五、跨流派整合

不同流派的心理学概念不再是不可通约的"语言游戏"，而是同一套形式化语法（M-R-D-S、G-M-A-R）的不同参数配置。下表给出主要流派到 IODS 坐标系的典型映射：

心理学流派核心概念IODS 映射
CBT（认知行为疗法）自动化思维、核心信念M2-STR-R（规则结构）+ ALIGN
DBT（辩证行为疗法）情绪调节、痛苦耐受M4（情绪模块）+ M3-DSP-F（前台调度）+ MODULATE
ACT（接纳承诺疗法）认知解离、接纳GATE(DSP-B) + ALIGN(STR-R)
EFT（情绪聚焦疗法）情绪转化M4 + RELINK(STR-C)
精神分析防御机制、潜意识DSP-B（后台调度）+ GATE 门控
人本主义自我实现、价值条件M3-RES-B（基底资源）+ STR-R

IODS 的整合价值：流派概念可映射到同一套形式化语法的不同参数配置，使心理学知识的累积、跨流派对话与系统化干预成为可能。不同流派不再是竞争性范式，而是同一坐标系下不同参数化路径。

六、S-P 环境参照系（外感架构）

S-P（Source-Pattern）是 INTRE 的外感架构，与 M-R-D-S 内感架构构成完整参照系。完整定义（含 S 层六系统、P 层命名规则、ELI 概念语义）见专项文档 01-M-09 L0-S-P 环境参照系。

6.1 内感 / 外感分类

侧架构回答的问题内容
内感M-R-D-S（§一）"系统内部正在发生什么"42 维状态空间、R-D-S 三层结构
外感S-P（01-M-09）"系统处于什么环境中，环境如何影响系统"S 层环境来源、P 层影响模式

6.2 S 层六系统环境来源

S 层采用并拓展布朗芬布伦纳生态系统理论：

S 层核心定义
微系统个体直接、面对面互动的环境（家庭、职场、同伴群体）
中系统微系统间的相互作用与连接（家校联系）
外系统个体未直接参与但间接受影响的环境（父母工作环境、政策）
宏系统广阔的文化、价值观、意识形态背景
时序系统环境事件与随时间的变化（生命转折事件、时代变迁）
数字系统数字信息环境（社交媒体、算法推荐、即时通讯）

6.3 ELI 环境负荷指数

ELI（Environmental Load Index）是环境负荷的统合量度：对给定时间窗内，由 S 层环境来源经 P 层模式作用于 M-R-D-S 各单元的净负荷标度。ELI 区分方向（资源消耗 vs 资源补充）、分层（短期 RES-D 与长期 RES-B/STR）、作用面定位（任何 ELI 值都对应明确的 P 层单元集合）。其数值与阈值属 L3 参数子层（SPER-L 环境识别库）。

S-P 报告格式（静态层面）：S-[层次]:[来源] → P-[M-R-D-S 单元][作用方向]。示例：S-微系统:职场-高压项目组 → P-M3-RES-D-（职场高压消耗意志资源）。S-P 报告直接定位至特定 M-R-D-S 诊断单元，使环境因素从"背景噪声"变为"可定位的参照系条目"。

七、强反例协议

IODS 的核心主张是可证伪的。若出现满足 A-16 四条件（稳定性、不可归约性、增量预测力、非操作性不足导致）的强反例，相应主张应被修正或放弃：

ID主张证伪条件
SC1M1-M6 完备性若发现一种对人类生存和适应至关重要、且在功能上无法被现有 M1-M6 任何模块及其交互所解释的心理能力，则模块完备性被证伪
SC2R-D-S 充分性若发现一个心理状态的关键属性，无法被归类为资源（R）、运行进程（D）或结构规则与连接拓扑（S）之一，则三层结构的充分性被质疑
SC342 维坐标完备性若发现某功能性心理状态无法被（M, R-D-S）张量积空间合理映射，且该缺口经标准化流程后仍不可归约，则坐标系的完备性被证伪
SC4结构约束若出现稳定可重复的经验证据表明六条动力学约束或级联规则中的某一结构语义与观测系统性冲突（排除操作化不足后），则对应约束应被修订或放弃
SC5概念编码核心定义层若发现一类心理学知识在 PSA-L 架构约束下无法被合理表示为 PCUI 条目，且该表示缺失是架构本身的结构性限制而非编纂不完整，则核心定义层被质疑

与 UPLP 的边界：IODS 定义"是什么"（状态坐标系、操作语法、知识基础设施）；UPLP 编译"怎么观测"（自然语言 → 语义似然的五层编译流水线 S1-S5）。IODS 不可用则编译无降级——UPLP 作为 PSE 感知层 L1-S 语义输入端口，强依赖 IODS；IODS 不可用时 UPLP 无可编译的坐标系，编译无降级路径。IODS 与 UPLP 并列，共同构成 L0 + L1-S 的静态-观测分层。
