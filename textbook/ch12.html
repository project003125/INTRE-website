第12章 PSE 总览：六级管线与双工程

学习目标：完成本章后，你应能够：(1) 说出 L0–L5 每级的一句话职责；(2) 区分知识治理五层与计算执行六级；(3) 复述级间契约的四要素；(4) 说明 L1 三端口的统一契约；(5) 解释三架构建在管线中的贯穿范围。

12.1 L0–L5 管线与每级职责

六级管线不是六个并列系统，而是一条按依赖方向串联的计算链。每一级消费上一级的输出与相邻级的契约，不越级改写上游。L0 定义基底，L1 产生观测，L2 估计当前状态，L3 推演未来，L4 搜索干预，L5 执行并回传反馈。

级 一句话职责 核心产物
L0 本体 定义坐标系、词汇、语法与结构约束 静态定义，无运行时
L1 观测 把原始观测编译为带不确定度的结构化向量 三模态观测块 {y, σ}
L2 状态估计 贝叶斯融合三模态观测与先验转移 Ψ 的 42 维后验与协方差
L3 动力学 用动力学假设与参数推演状态演化 未来分布、级联路径、风险时点
L4 规划 在约束下搜索最优操作序列 操作序列、成功概率、时间窗
L5 执行 执行序列并采集反馈数据 执行记录与依从性数据

管线化的核心判断是：用管线组织功能，而不是用并列系统组织功能。把不同阶段包装成独立系统，会制造“参数归谁管”“一个组件有双重身份”“两级到底并列还是依赖”这类伪问题。管线化之后，参数跟着级走，定义与观测分开，依赖方向明确。

L2 与 L3 之间存在局部双向耦合。L2 需要 L3 的转移先验，L3 需要 L2 的初始状态。耦合按分层组合处理：运行时 L2 消费 L3 的 BMA 加权预测分布，做加权模型迭代滤波；校准期把模型权重与状态一次性联合推断。双向耦合是滤波问题的固有结构，不取消两级的独立地位。

L5 到 L1 构成闭环。执行记录、依从性、复诊量表与日常 EMA 回到 L1，成为新的行为观测。闭环使管线不是一次性开环计算，而是可持续校准的系统。

管线的顺序不是任意的。观测必须先于估计，估计必须先于预测，预测必须先于规划；反过来做，规划就没有当前状态与未来轨迹作为输入。顺序也不是严格串行：L2 与 L3 迭代滤波，L5 反馈回到 L1，局部形成环路。

12.2 双工程：知识治理五层与计算执行六级

PSE 由两套切法共同构成。知识治理工程按知识类型并列分箱，回答“我们知道什么、怎么分类、怎么修订”；计算执行工程按计算依赖串联分级，回答“信息怎么流动、怎么一步步算完”。两套切法描述同一对象，互不否定。

维度 知识治理工程 计算执行工程
核心问题 知道什么，如何分类与治理 信息如何流动，如何算完
核心动作 分类、版本化、修订 计算、变换、闭环
组织原则 按知识类型并列分箱 按计算依赖串联分级
结构形态 架构层、算法层、参数层、方法论层、协议层 L0 本体到 L5 执行
层间关系 并列互斥、联合覆盖、无时序依赖 单向依赖，加局部耦合与闭环
评价标准 概念清晰度、术语追溯、可评议性 契约闭合、参数可校准、预测可验证
彼此供给 提供参数定义权与合法性来源 提供验证通道与经验反馈

知识治理五层是并列的：架构层管边界与依赖，算法层管算法选择，参数层管归属与修订，方法论层管估计与选择，协议层管调用入口。五层没有先后顺序，它们是对同一知识体的五种分类。计算执行六级是串联的：信息从 L0 定义出发，经 L1 观测、L2 融合、L3 推演、L4 规划，到 L5 执行，再由反馈回到 L1。

两套工程通过两条契约咬合。知识治理向下提供参数定义与合法性：符号“k_M4_社交”之所以有意义，是因为治理侧定义了 M4 与 RES-B 的语义。计算执行向上提供验证与反馈：概念分类是否有效，最终由预测与干预效能裁决。

IODS 是知识治理工程产出的核心工件，但不是知识治理工程本身。IODS 是本体，回答“有什么”；知识治理是制度，回答“怎么分类、怎么修订”；计算执行是引擎，在 IODS 划定的格子里跑信息。三者各归其位。

知识治理的五层不是按时间排序的流程。架构层、算法层、参数层、方法论层与协议层可以在同一时期并行维护；它们的区别是知识类型，不是先后步骤。计算执行的六级才有明确的时序依赖。把两套切法的“层”混为一谈，是理解双工程时最常见的错误。

12.3 级间契约：输入、输出、参数与降级

级间契约是管线可分离验证的前提。每级明确输入、输出、参数归属与降级模式。契约不是接口文档的附属说明，而是级与级之间的责任边界：上游不越级承诺，下游不越级索取。

级 输入 输出 参数 降级模式
L0 本体 无，定义文档 坐标系、词汇、语法、结构约束 不是参数 不适用，无运行时
L1 观测 文本、量表与 EMA、EEG/fNIRS/PPG 三模态观测块与不确定度 仪器参数 缺一模态则输出无信息编码
L2 状态估计 L1 观测 + L3 转移先验 42 维后验与协方差 无独立参数 融合失败则退单模态最大后验
L3 动力学 L2 后验 + 环境驱动项 转移先验、未来分布、级联与风险 系统参数与模型选择参数 模型不确定则由 BMA 加权消化
L4 规划 当前状态、预测轨迹、约束 操作序列、成功概率、时间窗 规划参数 无可行解则退保守方案并报告
L5 执行 操作序列与剂量建议 执行记录与依从性数据 执行参数 执行受阻则中止并回滚重规划

参数跟着管线级走，每级有唯一管理权。L0 不是参数，它是定义与约束；L1 持有仪器参数，包括编译置信度、观测函数形状、IRT 桥接系数与映射权重；L2 不持有独立参数，只消费 L1 与 L3 的参数；L3 持有系统参数与模型选择参数；L4 持有规划参数；L5 持有执行参数。唯一管理权消除了“参数归谁管”的争议。

契约还规定“不越级承诺”。L1 不承诺状态后验，L2 不承诺干预方案，L3 不承诺执行结果。每级只对自己的输出负责，把不确定性向下传递。下游收到的是分布与不确定度，不是被抹平的点值。

降级模式是契约的必要组成。心理观测天然稀疏，缺模态是常态而不是故障。L1 把不可用模态写成均匀分布的无信息编码，使融合自动退化为剩余模态加先验，而不是让整条管线停摆。降级必须显式可见，不能静默省略，也不能用非均匀值伪造。

12.4 L1 统一观测契约与三端口

L1 是接口统一的复合系统。三个端口共享一个输出契约，内部实现、专业领域与修订条件各不相同。“统一”发生在输出格式层面，不发生在算法层面。

统一输出契约规定：每个端口输出一个观测块，包含 42 维观测向量 y 与 42 维不确定度 σ；y 的每一维取值于 \([0,1]\)，σ 取值于 \([0,1/\sqrt{12}]\)；不可用或不可编译的维度写入无信息编码 \(y=0.5\)、\(\sigma=1/\sqrt{12}\)；维度索引遵循 \(\mathrm{idx}(m,s)=(m-1)\times 7+s\)；数值以双精度浮点传输，不做舍入截断。σ 的语义是标准差：σ 越大，对应似然越平坦，在融合中权重越低。

端口 内部层 输入 输出 似然 核心机制
UPLP 语义 S1–S5，五层 临床叙述、量表文本、自由陈述 语义观测块 {y_s, σ_s} p(y_s|Ψ) 词汇匹配、坐标映射、置信加权
UBMP 行为 B1–B5，五层 量表分、EMA 条目、数字表型 行为观测块 {y_b, σ_b} p(y_b|Ψ) 注册库、语义对齐、IRT 桥接、个体化
UNIP 神经 N1–N6，六层 EEG、fNIRS、PPG 神经观测块 {y_n, σ_n} p(y_n|Ψ) 采集规范、信号校准、特征定义、映射

三路似然在 L2 融合。核心推断为：

\[ p(\Psi_t \mid y_t) \propto p(y_s\mid \Psi_t)\, p(y_b\mid \Psi_t)\, p(y_n\mid \Psi_t)\, p(\Psi_t \mid \Psi_{t-1}) \]

行为模态有一个额外的契约前置：数值桥接前必须先经语义对齐。两个量表只有在语义端口确认它们锚定同一 M-R-D-S 构念后，才能进入 IRT 跨工具等价转换。PHQ-9 主要锚定 M4-RES-D 与 M2-STR-S，GAD-7 主要锚定 M3-DSP-B 与 M4-RES-D；两者临床高度共病，但功能层锚定不同，不能直接等价换算。

三端口共享契约，但不共享修订节奏。语义端口的词条可以随知识生产快速增补；行为端口的桥接参数要等工具对积累；神经端口的特征与映射要等采集与建模完成。统一契约让三者可以异步演进，而不必等最慢的端口。

12.5 复杂度论证：七个维度

心理系统比自动驾驶系统复杂。复杂度对照给出七个维度，既有量的差异，也有质的差异。

维度 自动驾驶系统 人类心理系统 量级估计
状态空间维度 约 6–12 维 42 维状态向量 约 4–7 倍
动力学非线性 物理定律已知，方程形式确定 26 条动力学假设，方程形式待验证 质的差别
理论无关性 雷达测距与理论解耦 p(y_b|Ψ) 由理论构成，观测与理论耦合 质的差别
地面真值 存在可独立测量的物理真值 不存在独立于框架的心理真值 质的差别
主体干预性 车辆被动响应 人主动响应、学习、抵抗 质的差别
个体差异 同型号车辆差异极小 个体差异是主要变异源 约 \(10^2\)–\(10^4\) 倍
环境耦合 道路环境相对结构化 社会文化环境动态且语义加载 约 10–\(10^3\) 倍

观测模态数在两边都约为三到五种，这一项不构成主要差异；真正的差异在单模态内部的异质性——心理语言的多义性、行为工具的版本分化、神经信号的个体差异，都远高于雷达或摄像头。综合各维度，心理系统的整体复杂度较自动驾驶高出约 \(10^2\)–\(10^6\) 倍。这个区间是量级说明，不是精确计算。

六级切分是匹配该复杂度的合理下限。状态维度更高、没有地面真值、动力学形式不确定，意味着每级必须窄到可理解、可验证、可分配。L2 与 L3 必须分开：描述“当前是什么”与预测“未来将怎样”是不同问题；合并会让状态估计误差直接污染预测，在无地面真值的系统里尤其危险。L1 必须分成三个端口：语义、行为与神经分属完全不同的专业知识与方法传统，合并会让校准节奏互相阻塞。

复杂度论证是存在性论证，不是精确测量。它说明为什么六级是合理下限，而不是证明六级最优。级数太少，单级要同时承担异质任务；级数太多，契约成本会吞掉分工收益。六级落在当前工程颗粒度的可行区间内。

管线的级数也服务于修订隔离。L1 仪器参数的变化不应触发 L3 方程修订；L3 模型权重的更新不应改写 L1 观测格式；L4 规划策略的改进不应回写 L0 坐标系。级间契约把这类隔离写成可检查的边界。

12.6 三架构在管线中的贯穿范围

三套架构——M-R-D-S、G-M-A-R、S-P——是管线坐标系，不是管线中的某一级。它们各自在适用范围内贯穿管线，但并非每一级都直接使用全部三套架构。

架构 L0 L1 L2 L3 L4 L5
M-R-D-S 定义 42 维空间 观测锚定到 42 维 状态向量为 42 维 动力学在 42 维上演化 间接关联，在空间中规划 间接关联，在空间中执行
G-M-A-R 定义四种操作 间接关联，观测提供前提 间接关联，估计提供输入 预测干预效果 搜索最优序列 执行具体操作
S-P 定义环境参照系 环境数据作为输入 环境状态纳入估计 环境作为驱动项 E(t) 环境约束纳入规划 环境适配执行

贯穿范围可概括为三句：M-R-D-S 直接贯穿 L0 到 L3，在 L4 与 L5 间接关联；G-M-A-R 直接贯穿 L0 与 L3 到 L5，在 L1 与 L2 间接关联；S-P 贯穿全部六级。这里的“直接”指该级的输入输出显式使用该架构的构件，“间接”指该级只消费其他级转译后的结果。

三架构不占管线级，而是横切管线。同一个 L1 观测块，在 M-R-D-S 下是 42 维坐标读数，在 S-P 下带有环境上下文；同一个 L4 操作序列，在 G-M-A-R 下是四种原子操作的组合，在 M-R-D-S 下是靶点坐标的集合。管线级回答“在哪一步”，架构回答“用什么语法”。两者正交，不能互相替代。

架构与管线的关系可以用一句话概括：管线回答“什么时候做”，架构回答“按什么语法做”。同一级可以同时受多套架构约束，同一套架构也可以横跨多级。把架构误当成管线级，会制造“架构层”这种不存在的层级。
