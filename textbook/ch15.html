第15章 L1-N 神经接口：UNIP

学习目标：完成本章后，你应能够：(1) 复述 N1–N6 六层职责；(2) 说出采集规范与信号校准要点；(3) 解释 NFM 的约束语义；(4) 区分先验库与仪器参数；(5) 说明实时引擎的正反通道。

15.1 六层：N1 NAP → N6 RTE

神经信号离功能状态最远。头皮电压、血氧变化与心率变异本身不携带“焦虑”或“反刍”的语义，必须经过格式统一、信号清洁、特征定义、功能映射、先验约束与在线推理，才成为可融合的似然。UNIP 用六层完成这条链，前五层离线，第六层在线。

六层的编号与管线级编号独立。N1–N6 是端口内部层级，不对应 L0–L5；N5 与 L3 参数层有交界面，但 N5 仍属 L1-N。把内部层号与管线级号混用，会让层级指称产生歧义。

编号 层名 阶段 输入 → 输出 验证对象
N1 NAP 神经采集规范 离线 原始数据 → 标准化数据集 格式、同步等级、元数据完整性
N2 SCL 信号校准层 离线 标准化数据集 → 清洁信号 伪影去除、滤波、时间同步
N3 NFD 神经特征定义 离线 清洁信号 → 标准化特征 NFI 特征定义与参考实现一致性
N4 NFM 神经-功能映射 离线 NFI 特征 → p(y_n|Ψ) 模型 映射拟合度与泛化
N5 NPL 神经先验库 离线 生理与统计约束 → 先验分布 先验可校准性
N6 RTE 实时引擎 在线 实时神经流 → 观测块 {y_n, σ_n} 推理延迟、在线校准稳定性

六层的划分依据是“每个阶段是否非平凡”。神经信号从采集到功能读数，六个阶段各自有独立的学科归属与验证方法：实验物理管采集，信号处理管清洁，神经方法论管特征，认知神经科学管映射，神经生理学管先验，工程实现管实时。合并任意相邻两层，都会让两个验证对象混在一起。

不再拆成七层，是因为 NFD 的“定义与计算”拆分会产生极薄层：计算在 RTE 在线执行，定义在 NFD 离线维护。NPL 拆成“硬约束与软先验”同样会得到两个验证对象重叠的薄层。六层是当前颗粒度的自然边界。

前五层离线完成，输出的是标准与模型；第六层在线消费这些产出。N6 不在每次推理时重新训练映射，也不在每次推理时重新定义特征；它只执行已经登记与校准的映射，并做有限的个体化微调。离线与在线分开，使模型更新与实时服务互不阻塞。

六层之间通过标准化数据契约通信。N1 输出数据集，N2 输出清洁信号，N3 输出 NFI 特征，N4 输出似然模型，N5 输出先验，N6 输出观测块。每层的输出格式可独立校验，失败定位不需要跨层猜测。

离线层的产出是标准与模型，在线层的产出是观测块。标准与模型可以版本化、可以回滚；观测块只属于当前窗口，不承担版本管理。两类产物的生命周期不同，所以必须在不同层处理。

15.2 采集规范与信号校准

采集规范决定数据能不能进入管线。N1 规定数据格式、同步等级与元数据标准；格式不统一、时间不同步、元数据缺失的数据集，在后续层无法被可靠比较。神经数据的个体差异大，设备与导联布局差异更大，采集层不统一，映射层就无法跨样本训练。

同步等级不是标签装饰。Tier-S 表示硬件级同步，Tier-A 表示事件级对齐，Tier-B 表示事后对齐；等级越低，时间误差越大，跨模态融合时的窗口就必须越宽。把低同步数据标成高等级，会让融合把时间错位当成状态变化。

要素 规定 作用
数据格式 统一目录结构与字段命名 跨设备、跨研究可读
同步等级 Tier-S、Tier-A、Tier-B 三级 标明时间对齐精度
事件标记 刺激、反应、分段的统一定义 支持分段与对齐
元数据 设备、采样率、导联、过滤设置 复现与差异诊断
质量标记 信噪比、伪影比例、坏道记录 决定可用性
校验文件 逐记录的质量报告 审计与降级依据

N2 做三件事：去伪影、滤波、时间同步。眼电、肌电、运动伪影会污染脑电；呼吸与运动会影响近红外与心率变异。滤波参数、去伪影方法与同步窗口必须登记，不能在不同样本上随意变化。质量标记低于阈值时，该记录按模态不可用处理，而不是带着噪声进入映射。

去伪影没有普遍最优方法。眼电回归、独立成分分析、阈值剔除各有适用条件；方法选择要随设备与任务登记。滤波同样如此：低通截止频率影响高频特征，高通截止频率影响慢波成分。参数不登记，跨样本比较就没有共同基准。

标准化的做法是复用成熟生态：数据格式沿用 BIDS，数据流同步沿用 LSL，模型交换沿用 ONNX，预处理沿用 EEGLAB 与 MNE。UNIP 只增加功能层所需的最小扩展，例如同步等级字段、质量报告文件与 NFI 编码。复用降低工程成本，也让神经端口不必重新发明数据格式。

采集与校准都属于离线阶段，但它们的产物直接影响在线推理。采集错误无法靠滤波补救，滤波过度又会抹掉特征；两者的参数必须一起登记，不能分开维护。

采集规范还要处理坏道与缺失段。坏道不能简单插值补平，插值会制造看似连续的伪信号；缺失段要么标记为不可用，要么在特征层按缺失规则聚合。质量报告的作用，是让下游知道哪一段可以信、哪一段不能信。

质量报告还记录修复动作。哪一段被剔除、哪一段被插值、哪一段被标记缺失，都要可追溯；只写最终信噪比、不写处理过程，复现时无法判断差异来自数据还是来自处理。

15.3 神经—功能映射：NFM 的约束语义

NFM 存储从 NFI 特征到功能似然的预测模型。它不是“输入脑电、输出诊断”的黑箱分类器，而是受约束的条件分布模型：给定状态，特征应该呈现什么分布；给定特征，哪些维度可以被更新，哪些不能。

NFM 的模型可以是线性映射、核方法或深度网络，形式不固定；固定的是约束语义与输出契约。模型选择属于离线验证，不改变端口对外承诺。端口对外只承诺两件事：覆盖哪些维度，以及每维的不确定度如何表达。

约束 内容 违反的后果
覆盖约束 只在已验证的维度上输出观测值 未验证维度被伪观测污染
生理硬约束 先验库给出不可越过的生理边界 映射输出违反基本生理事实
统计规律约束 输出分布需符合参照样本的统计形态 模型在尾部失控
仲裁优先级 领域专用优先、近期校准优先 多模型冲突时输出不稳定
不确定度约束 σ_n 必须反映映射与校准不确定度 下游把猜测当读数
离线训练约束 在线只执行已登记模型 实时推理不可审计

覆盖约束是最重要的一条。NFM 只对经过验证的特征—维度对输出观测值；未覆盖维度写无信息编码。一个模型在 M2-RES-D 上验证过，不代表它也能读 M4-STR-C。把未验证维度填上预测值，会让神经通道看起来覆盖很广，实际是在制造伪信息。

约束语义还要求输出可复算。给定同一段清洁信号、同一版 NFI 定义与同一组 NFM 权重，在线推理应得到同一观测块；随机性只能出现在已声明的采样环节。不可复算的输出无法进入审计，也无法用于校准。

覆盖约束也约束训练。一个 NFM 模型只能在有足够标注的维度上训练；没有标注的维度不能靠迁移学习“顺带”输出。跨维度的共享表征可以提高效率，但不能替代每个维度的验证。没有验证的维度，一律按未覆盖处理。

多个 NFM 模型对同一维度给出冲突输出时，按优先级仲裁：领域专用模型优先于通用模型，近期校准的模型优先于历史校准模型。冲突持续时产生仲裁事件并记录审计日志，交由融合层按贝叶斯模型平均处理。仲裁规则不改变模型本身，只决定当前观测采信哪一路。

约束语义的最终落点是观测块的形状。NFM 输出不是点估计，而是带 σ_n 的分布参数；σ_n 由映射不确定度与在线校准状态决定。若模型只给点值，端口必须自行补上不确定度，否则下游会把点值当成确定读数。

仲裁优先级解决的是模型冲突，不解决模型错误。若两个模型都系统性偏离，仲裁只会选出一个更接近的错值。模型错误的发现依赖离线验证与在线残差监控，不能靠仲裁规则。

N5 的先验库为映射提供边界。生理硬约束是不可越过的范围，例如某维度的取值不能超出对应生理量的可行区间；统计规律约束给出参照分布形态。先验库不是 L1 仪器参数，它的产出流向 L3 参数层，作为先验输入参与系统参数的整合与校准。

15.4 先验库与实时引擎

N5 是 L1-N 与 L3 参数层的交界面。它存储生理硬约束与统计规律约束，产出先验分布，交给 L3 参数层与仿真先验一起整合。N5 不归入 L1 仪器参数；它不设定“这次观测的权重”，而设定“这个参数可能取什么范围”。两者属于不同层级：前者是仪器校准，后者是系统参数的先验来源。

先验库与仿真先验是两条来源。仿真先验来自规则编码智能体的演化统计，先验库来自生理约束与参照样本的统计规律；两者在 L3 参数层整合，再经临床数据做后验校准。N5 只负责产出与格式，不负责整合。

这种分工避免了循环定义：如果 N5 同时产出先验并决定先验如何消费，先验就会在自己的消费规则里自我确认。交给 L3 整合，使先验必须与仿真先验和临床后验竞争，接受统一校准。

参数 所属层 归属 作用
NFI 特征定义 N3 NFD L1 仪器参数 定义标准特征与编码
NFM 映射权重 N4 NFM L1 仪器参数 决定特征到似然的映射
RTE 校准参数 N6 RTE L1 仪器参数 在线个体化微调
NPL 先验分布 N5 NPL L3 参数层交界面 为系统参数提供先验输入

N6 是在线层。它消费 N1–N5 的产出，把实时神经流转换为观测块，并在个体化校准中微调映射参数。前向通道是 `/func_likelihood`：输入神经生理信号，输出 42 维观测块。反向通道是 `/calibration_feedback`：把融合与校准阶段的残差送回实时引擎，用于在线微调。

前向端点返回的观测块必须通过契约校验：长度 42、值域合法、σ 不超过上界。不符合者按无信息处理并记录审计日志，不能带着坏块进入融合。

反向通道携带四个关键字段：校准目标、残差、残差不确定度、来源校准阶段。目标可以是某个 NFI 特征、某个 NFM 映射条目或某个 RTE 参数。闭环使神经端口能利用融合层的全局信息，而不是只靠端口内部的局部拟合。反向通道的协议必须在闭环试验中验证后才转正；在此之前，它只作为设计接口存在。

反向通道的残差不是标签。它是融合后状态与端口观测之间的差异，可能来自映射偏差、个体差异或上游观测噪声。RTE 只能在自己的参数范围内微调；若残差持续指向模型形式错误，应回到离线层重修映射，而不是在线硬调。

降级规则与另外两个端口一致。神经数据流中断、质量不达标或主动禁用时，观测块整体写无信息编码；NFM 不支持某维度时，该维写无信息编码，其余维度正常输出。降级必须显式声明，不得静默省略，也不得用非均匀值填充。

三端口降级规则一致，是为了让 L2 不需要按模态写分支。L2 只检查 available 与 σ，不关心缺失来自设备、质量还是覆盖；统一的无信息编码把工程差异挡在端口内部。

降级类型 触发场景 处理
模态级 数据流中断、质量标记低于阈值、主动禁用 整体写 \(y=0.5\)、\(\sigma=1/\sqrt{12}\)
维度级 NFM 不支持某维度的功能映射 该维写无信息编码，其余正常
组合降级 多模态同时不可用 各模态分别写无信息编码

15.5 当前工程状态

工程现状：N3（NFD）的 NFI 名册缺少可用参考实现，N5（NPL）与 N6（RTE）尚未实现；神经端口当前只能以无信息编码参与融合。
