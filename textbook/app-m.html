附录M 数学速成

读懂状态范式不需要整本数学分析。五个工具够用：函数、导数、概率、贝叶斯更新、递归滤波。每个工具只需要知道它在管线里替哪一步说话。

M.1 函数与映射

函数是输入到输出的对应。状态范式里常见三种映射：观测映射把状态变成读数，转移映射把上一刻状态变成下一刻状态，干预映射把操作变成状态改变。

\[ y = h(\Psi, E) + \varepsilon \] \[ \Psi_{t+1} = f(\Psi_t, E_t, u_t) + \eta_t \]

h 是观测函数，E 是环境项，u 是操作项，ε 与 η 是噪声。线性形式 \(y = ax + b\) 只适合做局部近似；状态量有阈值与饱和，常用非线性形式，例如 S 形函数

\[ \sigma(x) = \frac{1}{1 + e^{-x}} \]

它的作用是把任意实数压到 0 与 1 之间。观测值域用 [0,1]、呈现尺用 0–100，两者之间只做线性换算，不改变形状。

M.2 导数与变化率

导数衡量瞬时变化率。一元形式是

\[ f'(x) = \lim_{\Delta x \to 0} \frac{f(x+\Delta x) - f(x)}{\Delta x} \]

多元函数对某一个变量求偏导 \(\partial f / \partial x_i\)，把所有偏导排成向量就是梯度 \(\nabla f\)。梯度指向函数上升最快的方向；在规划里，它用来判断往哪个维度加操作最省力。

资源方程是最常用的一阶动态：

\[ \frac{dR}{dt} = S(t) - cR(t) \]

它的解是 \(R(t) = R^* + (R_0 - R^*)e^{-ct}\)，其中 \(R^* = S/c\)。参数 c 越大，恢复越快；c 越小，恢复越慢。恢复不对称就是消耗项与恢复项的 c 不相等。

M.3 概率与分布

随机变量把取值与概率连起来。离散情形用分布列 \(p(x)\)，连续情形用密度 \(p(x)\)。期望与方差分别是

\[ \mathbb{E}[X] = \sum_x x\,p(x), \qquad \mathrm{Var}(X) = \mathbb{E}[(X-\mathbb{E}[X])^2] \]

高斯分布是最常用的近似：

\[ p(x) = \frac{1}{\sqrt{2\pi}\,\sigma} \exp\left(-\frac{(x-\mu)^2}{2\sigma^2}\right) \]

μ 是中心，σ 是宽度。σ 越大，分布越平，信息量越低。观测契约里的不确定度就是 σ；无信息编码取均匀分布 \(U(0,1)\) 的均值 0.5 与标准差 \(1/\sqrt{12}\)。

M.4 贝叶斯更新

贝叶斯公式把先验与似然合成后验：

\[ p(\Psi \mid y) = \frac{p(y \mid \Psi)\,p(\Psi)}{p(y)} \]

分母是与 Ψ 无关的归一化常数，实际计算常写成正比形式：

\[ p(\Psi \mid y) \propto p(y \mid \Psi)\,p(\Psi) \]

在状态估计里，先验来自上一刻的转移预测，似然来自当前观测块。三模态融合就是三个似然相乘再归一化。先验太强会压住新证据，似然太强会让估计追逐噪声；σ 决定谁说话更响。

M.5 递归滤波

滤波把贝叶斯更新重复到时间轴上。每一步分两段：预测与更新。

\[ p(\Psi_t \mid y_{1:t-1}) = \int p(\Psi_t \mid \Psi_{t-1})\,p(\Psi_{t-1} \mid y_{1:t-1})\,d\Psi_{t-1} \] \[ p(\Psi_t \mid y_{1:t}) \propto p(y_t \mid \Psi_t)\,p(\Psi_t \mid y_{1:t-1}) \]

预测段用转移模型把昨天的后验推到今天，更新段用今天的观测修正。线性高斯情形有闭式解，非线性高维情形用近似。状态范式里 42 维、强非线性、无地面真值，近似是常态而不是例外。

使用顺序按问题定：问“这是什么”用观测映射；问“会怎么变”用导数与转移；问“证据够不够”用概率与 σ；问“证据来了怎么改”用贝叶斯；问“连续来证据怎么办”用滤波。工具箱不是知识点清单，是五类问题的对应表。
