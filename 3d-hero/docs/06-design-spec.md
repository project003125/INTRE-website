## 0. 阅读约定

- 命名：代码内部用 `act-1..act-4` 标识，用户向命名统一为 **RCT1..RCT4**（RCT = "Roll Call / Timestamp"，仅为顺序标记，不代表学名）
- **滚动进度 `p`** ∈ [0, 1]：从页面顶部 (p=0) 到滚到最底 (p=1)，由 `window.scrollY / max(scrollHeight - innerHeight)` 派生
- **节奏区间**：除非另注，[a, b] 表示 "从 p=a 开始，到 p=b 结束" 的线性（内部实际是 smoothstep）
- **"满显"** = 该幕内容完整可读、无任何透明度
- **"稳态"** = 视觉元素已经完成入场进入静止/呼吸，等退场
- **"永驻"** = 一旦满显就不退场（直到页面刷新）

## 3. HTML 文本层的 4 幕（`#act-1..act-4`）

> 每幕在视觉上是：**左下角 6vw × 12vh 起、宽 ≈ 480px、纵向浮起的文字浮岛**。  
> 幕自身 `opacity` 恒为 1（不再承担淡入），**子元素按节奏分层淡入**  
> `kicker`（小标）→ `head`（h1/h2）→ `body`（副/正文）—— 大约 200ms 一级延迟。

### 3.1 节奏表

| 幕 ID | 命名 | 显示区间 (p) | 淡入 (inA–inB) | 淡出 (outA–outB) | 稳态区间 |
|---|---|---|---|---|---|
| `#act-1` | **RCT1 · 开场** | 0 → 0.24 | 立即 1（instant） | 0.16–0.24 | 0–0.16 |
| `#act-2` | **RCT2 · 现象层** | 0.26 → 0.52 | 0.26–0.34 | 0.44–0.52 | 0.34–0.44 |
| `#act-3` | **RCT3 · 功能层** | 0.52 → 0.82 | 0.52–0.60 | 0.74–0.82 | 0.60–0.74 |
| `#act-4` | **RCT4 · 神经层** | 0.80 → 1.0 | 0.80–0.88 | **永不淡出**（out=9 表示不退出） | 0.88–1.0 |

> **满显阅读窗**（给用户的"主阅读时间"）：
> - RCT2：p ∈ [0.34, 0.44] ≈ 整页 10%  
> - RCT3：p ∈ [0.60, 0.74] ≈ 整页 14%  
> - RCT4：p ∈ [0.88, 1.00] ≈ 整页 12%  
>
> RCT1 没有专门的"稳态"——它一上来就在屏幕上，淡出后让位给 RCT2。

### 3.2 幕内子元素节奏（统一公式）

对当前幕透明度 `o = actOpacity(p, ACT_RANGES[i])`：

- `kicker.style.opacity = o`
- `head.style.opacity = clamp01((o - 0.1) / 0.9)`（延迟 10%）
- `body.style.opacity = clamp01((o - 0.2) / 0.8)`（延迟 20%）
- 所有 `extras`（徽章、legend）跟随 body

`transform` 整体上还有 12px 内 translateY 动画（视角色深度），连同 `visibility: hidden`（当 o ≤ 0.001）避免背景渐变叠盖其他幕。

## 4. 按幕分述

### 4.1 🎬 RCT1 / `#act-1` 开场

**视觉位置**：屏左下，~480px 宽，文字浮岛纵向居中偏下  
**节奏区间**：p ∈ [0, 0.24]，instant 出现，0.16 起淡出，0.24 退场

**文本内容**：
- **小标**：`FUNCTIONAL LAYER PSYCHOLOGY`（小字号英文 EYC 大写）
- **主标题**：**INTRE**（h1，最大字号 ≈ 64px）
- **副文**：在现象与神经之间，建立可计算的功能层
- **右上方芯片**：`Ψ(t) ∈ ℝ⁴² · 6 × 7`（独立元素，链接到术语表）

**3D 场景**：
- 相机极远高
- 120 颗暗星点构成天幕
- 星场随机粒子数 400（v2.1 Q8 性能优化：1800→400，目标 LCP < 2.5s）
- **无晶格、无纤维、无粒子**——开场是纯深空感

**隐喻 / 关键词**：深空、等待、信息未注入。

---

### 4.2 🎬 RCT2 / `#act-2` 现象层

**视觉位置**：屏左下，同上文字浮岛  
**节奏区间**：p ∈ [0.26, 0.52]，kicker 0.26 → 标题 0.30 → 正文 0.32 → 稳态 0.34–0.44 → 退场 0.44–0.52

**文本内容**：
- **小标**：`01 · 现象层`
- **标题**：**从无限到有限**（h2 ≈ 32px）
- **正文**：漫天繁星被心智勾勒为星座——大五人格、认知类型、行为模式。人类模式识别，是从无限特征到有限标签的第一步。

**3D 场景**（视觉主轴："星空收敛"）：
- p ≈ 0.22–0.32：暗背景星淡至 0.2 倍，星点变亮 — **120 颗暗星里的 ~50 颗目标星被亮恒星光球连接为星座**（~110 条实连线）
- p ≈ 0.38–0.58：星座随 `uConverge`（0→1 smoothstep）同步收敛向中心：每颗恒星的 `aPhase` 角向中央轴挤压
- p ≈ 0.50–0.72：`uLatticeSpread` 0→1，星辰从汇聚漏斗位置散开铺满棋盘平面（x: ±7, y: ±6, z: ±0.6），寓意现象层各种现象被吸收后投射到各子维度
- 星辰延续：uStarFade = 1 - ss(p, 0.72, 0.92)，星辰贯穿晶格满显期，随脑图透出慢慢淡出；uDimFade 在晶格期回升至 1.0 恢复满天星辰
- p ≈ 0.55–0.68：星座整体淡出，让位给下一幕的圆柱态 → 蜂巢态

**隐喻 / 关键词**：星空 → 星座 → 收敛。人类心智把无限的信号凝练成有限标签。

### 4.3 🎬 RCT3 / `#act-3` 功能层（核心展示环节）

**视觉位置**：屏左下，同上文字浮岛  
**节奏区间**：p ∈ [0.52, 0.82]，kicker 0.52 → 标题 0.56 → 正文 0.58 → 稳态 0.60–0.74 → 退场 0.74–0.82

**文本内容**：
- **小标**：`02 · 功能层`
- **标题**：**六模块 × 七维度**（h2 ≈ 32px）
- **正文**：M1 具身 · M2 认知 · M3 意志 · M4 情绪 · M5 言语 · M6 行为。每一个节点都可被测量、被定位、被干预。
- **左下角徽章**：`42 / 42 可数`（胶囊，链接到教材页）—— 强调"6 × 7 = 42，一个都不能少"

**3D 场景**（视觉主轴："晶格从圆柱 → 蜂巢 → 棋谱"）：

- **6 列 × 7 行 = 42 节点晶格**（M1-M6 × R-D-S 三层七维度）
- 入场曲（p=0.56–0.72，v2.4 统一幕边界后 inA 0.52→0.56 / inB 0.60→0.66）：
  - 圆柱态：节点绕中心柱呈环状分布（半径 5.5）
  - uLattice 0→1，节点从环柱位置 lerp 到网格位置（行高 1.7，列宽 2.4，世界中心 y=−0.85）
  - **蜂巢 ⇄ 棋谱连线 crossfade**：uLattice ∈ [0.30, 0.62] 时，蜂巢态（六边形斜管，列环绕）透明度由 1→0，棋谱态（横平竖直矩形网格）透明度由 0→1
  - 节点落位：中心 (r=3) 先出现，边缘按欧氏距离延迟，最迟 p=0.72
  - 缓转：uLattice < 0.5 时晶格绕轴缓慢自转，≥0.5 时阻尼归零保证正面可读
- 稳态（p=0.66–0.74）：
  - 节点呼吸：3% 振幅，4s 周期正弦，逐节点相位差
  - **HTML 列标签浮出**：uLattice > 0.7 时 opacity 由 0→1（每个标签跟随对应节点的屏幕投影坐标）；字号 `var(--type-label)` / weight 600 / `--intre-navy-50` 亮色 + `text-shadow` 描边保证深色场景可读
  - **HTML 行标签浮出**：RES-D / RES-B / DSP-F / DSP-B / STR-R / STR-C / STR-S 7 个；字号 `var(--type-label)` / weight 500 / 同色同描边
  - 鼠标 hover：节点阻尼趋近 1.65×（v2.4，原 1.5 瞬跳）+ 整列亮起 Amber 500；点击跳转术语表
- 退场（p=0.74–0.82）：
  - 节点透明度渐出（保留 30%），晶格线 0.74 起开始明显消失
- **3 条通道粒子**（大地色系，v2.4 对齐品牌规范 v2.3）从下方/上方细束上下穿，形成 UPLP/UNIP/UBMP 三通道的视觉化（先于晶格出现并贯穿）
  - UPLP：下行 `#5A8270` 大地绿
  - UNIP：上行 `#5B7080` 大地蓝
  - UBMP：下行 `#8B7360` 大地棕
  - 粒子流速：UPLP 0.0018 · UNIP 0.0014 · UBMP 0.0016（按 sign 区分上下方向）

**隐喻 / 关键词**：从发散的圆柱 → 有结构的蜂巢 → 可数的棋谱。可测量、可定位、可干预。

### 4.4 🎬 RCT4 / `#act-4` 神经层（终极隐喻）

**视觉位置**：屏左下，同上文字浮岛；但**背景透传**，让 3D 场景的脑图成为视觉主体  
**节奏区间**：p ∈ [0.80, 1.0]，kicker 0.80 → 标题 0.84 → 正文 0.86 → 稳态 0.88–1.00 → **永驻**

**文本内容**：
- **小标**：`03 · 神经层`
- **标题**：**向下扎根**（h2 ≈ 32px）
- **正文**：功能层不是终点。UPLP 统一语义，UBMP 校准行为，UNIP 对接神经——三通道似然经 PSE 贝叶斯融合，更新状态后验。
- **底部 legend 行**：三个 channel 项 + 色点
  - 🟢 UPLP 语义通道
  - 🔵 UNIP 神经通道
  - 🟠 UBMP 行为通道

**3D 场景**（视觉主轴："纤维束沿脑轮廓生长"）：

- 入场曲（p=0.75–0.92）：
  - 相机沿 y 轴从 (1.0, 19) 行进到 (−15, 30)
  - **纤维束淡入**（`fiberFade` = smoothstep(p, 0.75, 0.92)）
  - 纤维分布遵循 `brainSDF(x, y)`：三个椭圆的 sdf 取最小（大脑/颞叶/小脑）
  - 脑图平面 14×18 单位，宽高比匹配 PNG 原图 482:636
  - **DTI 风格明亮纤维**只渲染明亮纤维束（smoothstep 阈值抠像，背景透明）
- 稳态（p=0.92–1.00）：
  - **脑图微提亮**（`brainReveal` = smoothstep(p, 0.92, 1.0)，额外 15% 透明度加成）
  - 脑图始终 `y = lookPos[1]`、`z = -6`（在棋盘 z=0 后方 6 单位，形成纵深层次）、scale 渐变 1.0→2.1（在 1.4 基础上放大 50%），**居中于相机注视点**
  - DTI 脉冲：鼠标点击时脑面发出淡光脉冲扩散（半径 0.6/帧，指数衰减）

**脑图参数**：
- PlaneGeometry：14（宽）× 18（高）
- SDF 缩窄补偿：`BRAIN_SX = 14/16`，对应"原图坐标系（16 单位宽）→ 当前 plane"的 x 缩放还原
- 缩放：`dtiPlane.scale = (brainScale, brainScale, 1)`，`brainScale = 1.0 + 1.1 * ss(p, 0.72, 1.0)`（透出时 1.0 不抢占棋盘，满显时 2.1 在 1.4 基础上放大 50%，占屏 ~79%）
- 模型比例：大脑半轴 9 × 8、颞叶半轴 3.5 × 3（位于右下方）、小脑半轴 2.8 × 2.5（位于左下方）

**隐喻 / 关键词**：从符号 → 神经。贝叶斯后验。根在深处。

## 11. 设计图谱（mental model）

把整页想象成**一段 5 段式的电影**：

- **RCT1 · 序幕**（星空）：从极远的高空俯瞰，深空等待。
- **RCT2 · 起承**（星空 → 收敛）：人类心智把无限凝练为有限，星座浮现然后向中心汇聚。
- **RCT3 · 主体**（晶格）：从发散到蜂巢到棋谱——把星座"压"成 42 节点可被测量的晶格。
- **RCT4 · 收尾**（神经）：晶格向下扎进大脑皮层，长成纤维束。
- **RCT5 · 隐形式永驻**（无限）：用户停止滚动，停留在神经层（rct4 永驻），与功能层（晶格、永驻的姿态）形成视觉闭环。

> 严格说，页面只有 4 幕（RCT1..RCT4），但用户感知到的是"5 节音乐"：开 · 起 · 承 · 转 · 合。
