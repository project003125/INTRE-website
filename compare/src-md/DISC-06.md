## 引言：一个需要方法学回答的问题

DISC-01 至 DISC-05 分别处理了：根节点（D1）、全景对比（D2）、K1/K2 边界（D3）、K2 风险（D4）、K3 代价（D5）。它们留下一个共同的问题：

> **两套范式的关系是什么——替代、竞争、还是分工？**

这个问题不能靠叙事直觉回答。它需要一套可复现的比较方法。本文用六步比较框架——目的、可比性、标准、权重、判定、边界——重新回答这个问题。

结论不变：**两套范式是分工关系**。但论证从“叙事判断”升级为“方法学推导”。

---

## 步一：目的——为什么比较？

| 项 | 内容 |
|---|---|
| 比较目的 | 确定两套范式各自的能力边界，以便在心理学实践中判断“什么问题该用哪套” |
| 比较产物 | 能力边界地图，非“谁更优”的排序 |
| 明确不采用 | 排序目的——若以排序为目的，权重会随偏好任意设置，结论不可复现 |

**为什么先定目的**：目的决定后续标准与权重。若目的是排序，标准会偏向某一方；若目的是能力边界，标准必须中立。

---

## 步二：可比性——能不能比？

| 判据 | 变量范式 | 状态范式 | 判定 |
|---|---|---|---|
| 是否同一层级 | 现象层（变量间关系） | 现象层+功能层（状态→观测→关系） | **不完全同级**——状态范式多一层 |
| 是否同一类对象 | 变量（观测读数的统计抽象） | 功能状态 Ψ + 观测函数 h | **不同类**——一个是统计构造，一个是功能角色实体 |
| 是否同一评价目标 | 描述/解释/预测/控制 | 描述/解释/预测/控制 | **同一目标** |

**结论：部分可比。**

| 可比的面 | 不可比的面 |
|---|---|
| 在“四目标”上可并排对照——两者都声称能描述、解释、预测、控制 | 在“内部构件”上不可互判——不能用状态范式的 G-M-A-R 去判变量范式“缺件” |
| 在“可表达性”上可对照——各自数学对象能承载什么 | 在“本体论地位”上不可直接比较——一个是统计构造，一个是功能角色实体 |

**若强行全面可比，会犯两类范畴错误**：用状态范式构件判变量范式不及格；用变量范式标准判状态范式不必要。DISC-01/07 已论证这是范畴错误，不是分析结论。

## 步三：标准（含覆盖）——用什么标准比？

### 3.1 选定标准

| 标准 | 定义 | 为何中立 |
|---|---|---|
| **描述** | 当前状态是什么？ | 心理学通用四目标之一，非任一范式私有 |
| **解释** | 为什么状态是这样？ | 同上 |
| **预测** | 不干预未来会怎样？ | 同上 |
| **控制** | 应该做什么？做了之后效果如何？ | 同上 |
| **可表达性** | 该框架的数学对象能承载哪些输出？ | 数学层面判据，不依赖任一范式的具体构件 |

### 3.2 覆盖检验

| 关键维度 | 是否被覆盖 | 若未覆盖会怎样 |
|---|---|---|
| 描述/解释/预测/控制 | ✅ 四目标全覆盖 | — |
| 数学对象承载边界 | ✅ 可表达性覆盖 | — |
| 实证表现 | ❌ 未覆盖 | 两套范式当前均处理论阶段（P 级），实证对比无法进行——明确排除 |
| 工程成本 | ❌ 未覆盖 | 非本比较目的（目的是能力边界，不是成本效益）——明确排除 |
| 伦理/社会影响 | ❌ 未覆盖 | 已由 META-06 单独处理，本比较不重复——明确排除 |

**结论：对“能力边界”这一目的，四目标+可表达性已充分覆盖；实证表现、工程成本、伦理影响明确排除，并声明排除理由。**

### 3.3 与 03-A-07 §11.1 的关系

03-A-07 §11.1 已论证：状态范式对变量范式是**观测依赖**，不是**本体依赖**——它取变量范式的测量产物（因子结构、效应量、相关矩阵），但拒绝采纳其本体假设（变量=实体）。

这与步二“部分可比”一致：在“测量产物”层面可比（状态范式可用），在“本体假设”层面不可比（状态范式不用）。**标准选择因此限定在“测量产物可用性”与“四目标能力”两个可比面上。**

## 步四：权重——怎么设权重？

### 4.1 关键判断：不设统一权重

| 理由 | 说明 |
|---|---|
| 目的决定权重 | 若目的是“预测个体轨迹”，状态范式权重大；若目的是“估计群体平均效应”，变量范式权重大 |
| 设统一权重会掩盖分工 | DISC-06 的结论是分工，不是排序——统一权重会把分工压成排序 |
| 允许不等权 | 四目标本身不等权——取决于具体应用场景 |

### 4.2 分场景权重表

| 应用场景 | 描述权重 | 解释权重 | 预测权重 | 控制权重 | 更适配的范式 |
|---|---|---|---|---|---|
| 群体流行病学调查 | 高 | 中 | 低 | 低 | 变量范式 |
| 个体化轨迹预测 | 中 | 中 | 高 | 中 | 状态范式 |
| 干预方案设计 | 中 | 高 | 高 | 高 | 状态范式 |
| 现象层规律发现 | 高 | 中 | 中 | 低 | 变量范式 |
| 跨流派技术转译 | 低 | 高 | 低 | 中 | 状态范式 |

### 4.3 分工的操作化边界

**什么情况下用变量范式**：

| 场景 | 理由 |
|---|---|
| 观测层关系描述 | 变量范式擅长描述变量间的相关、中介、调节 |
| 处理效应估计 | RCT、IV、RDD、DID、PSM 在特定假设下高度可靠 |
| 横截面或少数时点数据 | 变量范式的统计工具在此成熟 |
| 不需要个体化状态轨迹 | 群体平均效应足够时，变量范式更经济 |
| 探索阶段，尚不清楚功能机制 | 先用变量范式建立现象层规律，再考虑功能层建模 |

**什么情况下用状态范式**：

| 场景 | 理由 |
|---|---|
| 轨迹预测 | 需要状态空间模型 + 贝叶斯滤波 |
| 最优控制 | 需要搜索最优 G-M-A-R 操作序列 |
| 个体化状态估计 | Ψ 后验分布 + 层级贝叶斯 |
| 干预靶点定位 | G-M-A-R 靶点合法性矩阵 + D→R→S 序列 |
| 级联路径分析 | D 矩阵 + 级联规则 |

**什么情况下两者配合**：

| 场景 | 变量范式的角色 | 状态范式的角色 |
|---|---|---|
| 冷启动先验 | 提供因子结构、效应量、相关矩阵 | 作为观测函数 h 和状态方程参数的初始估计 |
| 观测材料 | 提供密集纵向数据（EMA、DSEM） | 作为状态估计的观测输入 |
| 局部生成模型 | 提供计算精神病学模型（强化学习、DDM） | 映射到统一功能坐标系 |
| 外部校验 | 提供 RCT 处理效应估计 | 作为干预效果的独立验证 |

**结论：权重随场景变化，不设统一权重；分场景权重表替代统一权重，避免把分工压成排序。**

## 步五：判定规则（含敏感性）——结果怎么读？

### 5.1 四目标判定表

| 标准 | 变量范式能承载 | 状态范式能承载 | 判定 |
|---|---|---|---|
| 描述 | 变量间关系 | 状态本身 | **有差异**——描述单位不同 |
| 解释 | 方差解释 | 生成解释 | **有差异**——数学对象不同 |
| 预测 | 条件均值 E(Y\|X) | 轨迹分布 | **有差异**——条件均值是数，轨迹是分布 |
| 控制 | 处理效应 | 操作序列 | **有差异**——处理包是整体，操作序列可分解 |
| 可表达性 | P(Y)/P(Y\|X) 可表达；轨迹/级联/操作序列不可表达 | h: Ψ→y、f: Ψₜ→Ψₜ₊₁ 可表达；条件均值可表达但非其核心输出 | **有差异**——可表达集合不同 |

### 5.2 敏感性检验

| 问题 | 检验 | 结论 |
|---|---|---|
| 权重微调后，判定会不会翻转？ | 四目标各有明确的能力差异，非权重敏感型差异 | **不会翻转**——差异源自数学对象，非权重设置 |
| 换一套标准，判定会不会变？ | 若换成“统计显著性”标准，变量范式占优；若换成“轨迹预测精度”标准，状态范式占优 | **会变**——所以标准选择本身需声明（已在步三声明） |
| 结论是否依赖“两套范式当前均处理论阶段”这一前提？ | 若状态范式实证成功，其预测/控制优势从“理论可承载”变为“实证已验证”，判定增强；若实证失败，其优势降为“理论可承载但未兑现” | **结论方向不变，强度变化**——敏感性已标注 |

**结论：判定在四目标上均有明确差异，且对权重不敏感（差异源自数学对象而非权重）；但对标准选择敏感（换标准会变），对实证进展敏感（强度会变）。**

### 5.3 判定规则的可靠性——回应 DISC-03

DISC-03 问：功能层内部检验程序怎么保证客观性？会不会变成“自己检验自己”？

**回应**：功能层检验不是“自己检验自己”，而是**在功能层自身的可观测输出上接受检验**（04-A-03 §3.2）：

- 动力学轨迹偏差：系统在 Ψ 状态空间中的实际演化轨迹系统性偏离预测。
- 行为输出模式不符：在严格控制的操作条件下，行为输出模式与预测方向相反或无关。
- ROI 差异不成立：不同干预路径在预期靶点上产生的 ROI 差异不存在。

这些检验是**可观测的、可重复的、可被独立研究者验证的**。判定规则因此是公开的，不是自证的。

### 5.4 判定规则的可操作性——回应 DISC-04

DISC-04 问：强反例的可操作性怎么保证？谁来判断“强反例”还是“测量误差”？

**回应**：01-M-02 §1.4 的 A-16 四条件给出了判据：

1. **稳定性**：现象具有稳定的测量方式，可重复出现。
2. **不可归约性**：经标准化流程后仍无法被现有架构解释。
3. **增量预测力**：残余现象能提供独立于已有维度的增量预测力。
4. **非操作性不足导致**：已排除测量误差、编码培训不足、操作化不足等替代解释。

四条同时满足，才构成强反例。这不是“谁说了算”，而是“四条判据说了算”。**判定规则在“什么算差异”之后，还规定了“什么算推翻”。**

## 步六：边界（含适用范围）——结论在哪里成立？

### 6.1 本比较框架的失效条件

| 失效条件 | 说明 |
|---|---|
| 若状态范式的 Ψ 被证明不可辨识 | 状态范式在预测/控制上的“可承载”降为“理论可承载但不可兑现”——比较结论需重写 |
| 若变量范式发展出新的数学对象（超越概率结构） | 四目标框架可能需要重新评估——变量范式的可表达集合可能扩大 |
| 若出现第三套范式 | 本比较框架只覆盖两套，需扩展 |
| 若两套范式之一进入实证阶段 | 比较从“理论可承载”变为“实证已验证/未验证”——强度变化，方向不变 |

### 6.2 本比较结论的适用范围

| 适用范围 | 说明 |
|---|---|
| 适用于 | 心理学框架的能力边界判断；两套范式的分工定位 |
| 不适用于 | 判定“哪套范式更正确”；判定“哪套范式应该被淘汰”；替代具体实证研究 |
| 结论强度 | 理论层面的能力边界判断（P 级），非实证结论（E 级） |

### 6.3 结论强度的诚实声明——回应 DISC-05

DISC-05 问：技术成熟之前，状态范式的结论有多少可信度？

**回应**：状态范式对自己的结论有明确的证据分级（IET v3.0 八级体系）：

- 定义类（D）：定义性陈述，不依赖实证。
- 推导类（L）：从公理推导，逻辑有效但待实证。
- 预测类（P）：理论推导的候选假说，尚未系统检验。
- 实证类（E）：已有实证支撑。

当前状态范式的大部分结论处于 **P 级**（预测类），尚未进入 E 级。这是诚实的证据分级，不是过度承诺。

在技术成熟之前：

- 状态范式的结论应被理解为**理论推导的候选假说**，而非已证实的结论。
- 变量范式在现象层的结论仍然是可靠的观测材料。
- 两者配合：变量范式提供观测基础，状态范式提供理论框架，共同等待实证检验。

### 6.4 两层共存规则（原 §四 内容）

| 规则 | 内容 |
|---|---|
| **不混用** | 现象层用变量语言，功能层用 Ψ 语言，不互相替换 |
| **不还原** | 功能层不被还原为现象层，现象层也不被还原为功能层 |
| **可互译** | 通过观测函数 h 连接：现象层观测 y = h(Ψ, E) + ε |
| **可配合** | 变量范式提供观测材料和先验；状态范式提供功能架构和生成模型 |

**注意**：现象层的稳定结构不等于功能层的生成机制；功能实在论不是“功能组件永恒不变”（04-A-01 §7.1 诚实声明）。

### 6.5 共存规则的哲学基础

§6.4 给出了四层共存规则（不混用、不还原、可互译、可配合）。但规则需要基础——为什么“不混用”不是妥协，而是各自成立？为什么“不还原”不是回避，而是层级独立？

本节补上这两条哲学基础。它们不是比较方法的一部分，而是比较结论成立之后、两套范式如何共处的前提。

#### 6.5.1 现象层：变量实在论仍然有效

在现象层，变量/构念是对现象层模式的真实描述。量表分数、行为频率确实反映了某些稳定的现象结构。

**这不是让步，是承认。**

变量范式的测量工具、因果推断方法、统计建模工具，在现象层是**有效的、可靠的、不可替代的**。状态范式不主张“变量范式过时了”——它主张的是：变量范式在现象层有效，但现象层的有效不等于功能层的充分。

**但要注意一个关键区分**：

| 命题 | 是否成立 |
|---|---|
| 现象层的稳定结构是真实的 | ✅ 成立 |
| 现象层的稳定结构 = 功能层的生成机制 | ❌ 不成立 |

**同一个功能机制，可能在不同测量情境下产生不同的现象层投影；同一个现象层投影，也可能来自不同的功能机制。**

这就是为什么“变量在现象层有效”和“变量不能承载功能层任务”可以同时成立——它们说的是两件事。

#### 6.5.2 功能层：功能实在论

在功能层，功能组件（M1-M6、R-D-S 七子维）是功能因果网络中的角色实体——不是神经实体，不是统计构造，而是“在功能因果网络中扮演特定角色”的实体。

**“角色实体”的含义**：

| 它是什么 | 它不是什么 |
|---|---|
| 功能因果网络中的位置 | 神经解剖分区 |
| 由功能架构定义 | 由观测协方差定义 |
| 有动力学、有干预对应 | 静态统计构造 |

**但要注意：功能实在论不是“功能组件永恒不变”。**

04-A-01 §7.1 已诚实声明：M1-M6 的精确边界、42 维的具体维度数，是**经验性资产**，会在实证校准中被修正。

这意味着：

| 命题 | 是否成立 |
|---|---|
| 功能层是独立描述层级 | ✅ 成立（这是 K3 的核心） |
| 功能组件的精确边界已确定 | ❌ 不成立（经验性资产，待校准） |

**功能实在论承诺的是“功能层作为描述层级是实在的”，不是“每个功能组件的边界都是永恒正确的”。** 这两件事常被混淆——前者是本体论承诺，后者是经验假设。

#### 6.5.3 两层共存为什么成立

把 6.5.1 与 6.5.2 合起来看：

| 层面 | 实在论立场 | 有效性范围 | 边界 |
|---|---|---|---|
| 现象层 | 变量实在论 | 观测读数之间的关系 | 不等于功能层生成机制 |
| 功能层 | 功能实在论 | 功能因果网络中的角色 | 组件精确边界待校准 |

**两层各自成立，互不否定。**

- 现象层的变量实在论成立——所以变量范式不是“假的”。
- 功能层的功能实在论成立——所以状态范式不是“多余的”。
- 但两者不互相还原——所以 §6.4 的“不还原”规则不是妥协，是层级独立的必然。

**这就是“分工”的哲学基础**：不是“两套范式各让一步”，是“两套范式各自在各自层面成立”。

## 结论：分工关系

六步走完，结论是：

> 两套范式不是替代关系，不是竞争关系，而是**分工关系**。现象层用变量范式（变量实在论仍然有效），功能层用状态范式（功能实在论），通过观测函数 h 连接，通过变量范式提供观测材料和先验来配合。K3 是主要矛盾——它决定了两套范式各自的工作层面和基本单位。但这不是范式不可通约，而是**目标决定基本单位**。

**六步框架对结论的贡献**：

| 步 | 贡献 |
|---|---|
| 目的 | 明确比较产物是能力边界，不是排序 |
| 可比性 | 限定比较在四目标与可表达性上，不越界到内部构件互判 |
| 标准（含覆盖） | 四目标+可表达性；排除项声明理由 |
| 权重 | 不设统一权重，用分场景权重表替代 |
| 判定（含敏感性） | 四目标上均有明确差异；对权重不敏感，对标准选择和实证进展敏感 |
| 边界 | 失效条件四条；适用范围三条；已知局限四条 |

## 一句话

> 两套范式能共存。变量范式在现象层有效（变量实在论），状态范式在功能层有效（功能实在论），通过观测函数 h 连接。不是替代，不是竞争，是分工。六步框架让“分工”从叙事判断升级为方法学推导：目的定边界、可比性限范围、标准保中立、权重随场景、判定有差异、边界标局限。K3 是主要矛盾，但它不导致范式不可通约——它只说明：目标决定基本单位，基本单位决定范式。
