状态面板

Status · 读表

R-D-S 三维状态语法的读表位：资源、调度、结构三轴表盘全部空置，只有定性状态与实质说明。

表盘轴位与监测面状态

  • R资源轴 · Resources

    监测可调度存量 RES-D 与基底存量 RES-B：Token 预算剩余、上下文窗口占用、API 调用配额与时间预算。读数位空置，资源调节归 MODULATE 唯一直接靶点。

    Locked · 锁空

  • D调度轴 · Dispatch

    监测前台控制流 DSP-F 与后台自动化流 DSP-B：当前子任务状态、Agent Loop 当前步骤、优先级与重试/回滚记录。中止、暂停与执行通道切换归 GATE 激活面。

    Locked · 锁空

  • S结构轴 · Structure

    监测规则结构 STR-R、连接结构 STR-C 与序列结构 STR-S：系统提示词内容、工具依赖图、记忆索引与权限/沙箱规则。注入规则与切换连接分别对应 ALIGN 与 RELINK 靶点。

    Locked · 锁空

操作面板

Control · 干预

G-M-A-R 四原语的拨杆示意位：只画工序，不通电；每路标注 INTRE 靶点。

拨杆工序与说明靶点

  • GATE

    中止、暂停、恢复与执行通道切换；激活面为限定靶点。
    DSP ／ STR-S

  • MODULATE

    限 Token、调配额、调温度一类资源调节；唯一直接靶点。
    RES-D

  • ALIGN

    注入规则、改系统提示、改偏好；含 STR-S 内容面归约。
    STR-R

  • RELINK

    切换模型、重载插件、载入记忆；唯一直接靶点。
    STR-C

  • GATE · 启动判据

    过门判据前置；未裁定不出卷、不派发。
    Empty Anchor · 空锚锁空
