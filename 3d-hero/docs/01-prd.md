## 0. 项目背景速览

INTRE = 功能层心理学（Functional Layer Psychology, FLP）。它在"神经层"（大脑回路）与"现象层"（主观体验）之间建立一个新的"功能层"，用形式化的状态语法 M-R-D-S（6 模块 × 7 子维 = 42 维状态向量 Ψ(t) ∈ ℝ⁴²）与操作语法 G-M-A-R 描述心理系统的结构与变化。核心目标：让心理状态可描述、可仿真、可干预。

**已交付实体**：理论文档库（10 大模块数百篇 md）、导论教材（29 章 + 14 附录，已上线静态网站）、4 篇预印本（PSE/UPLP/UNIP/UBMP，发布于 Zenodo 有 DOI）、官方网站（-website/，GitHub Pages 部署，含首页 + 5 模块子站 + 教材 + 术语表）、品牌视觉规范（完整设计 token 系统）、3D 交互首页（intre-3d-hero/，1170vh 滚动叙事（含非线性节奏重映射））、验证测试体系（16 项核心组件替代测试 + 320+ 替代方案 + 对比矩阵）。

**当前阶段**：v2.0 理论蓝图，核心框架已通过多轮逻辑审查与替代测试。

## 1. 一句话目标

### 1.1 项目是什么

> **INTRE 3D 交互首页是一个 1170vh 的 WebGL 滚动叙事页（非线性节奏：RCT1→2 紧凑快切，RCT2/3/4 满屏 sticky 停留），用 Three.js 把"现象层 → 功能层 → 神经层"的三层心智模型以 4 幕（开场 → 现象层 → 功能层 → 神经层）依次呈现给访客，作为整个 INTRE 开放知识体系的沉浸式入口。**

### 1.2 这一页要解决的核心问题

访客通常在 30 秒内决定去留。INTRE 是一个高门槛的理论框架，传统学术首页（纯文字 + 论文链接）难以在短时间内传达"三层架构"这一核心心智模型。3D 交互首页通过滚动叙事，在 2-3 分钟内让访客**直观感知 INTRE 是什么、为何比现有方案更好、走下去会得到什么**——这通过空间化的视觉隐喻完成，不靠文案堆叠。

### 1.3 与 2D 网站的关系

3D 首页是**入口与概念可视化**，不是内容替代。所有深度内容（模块详解、教材章节、术语检索、预印本）由 2D 网站 `project003125.github.io/INTRE-website/` 承载。3D 首页的角色是：用沉浸式体验建立心智模型 → 引导访客进入 2D 网站深度阅读。

## 3. 核心场景

### 场景 A（主场景，约 50%）：学术研究者从社交链接点入，判断是否真东西

> 一个认知科学博士生在推特/知乎上看到有人分享"INTRE 功能层心理学"的链接，点进来。她面前是一个深色 3D 场景，滚动后看到"现象层 → 功能层 → 神经层"的三层结构依次展开，42 维状态向量以晶格形态呈现，贝叶斯融合公式以芯片形式浮现。她在 2 分钟内看完 4 幕，判断"这不是包装，有形式化基础"，点击公式芯片进入术语表，进一步阅读核心纲要。

**成功条件**：访客完成 4 幕全程滚动，并点击至少 1 个出口链接进入 2D 网站。

### 场景 B（次场景，约 30%）：工程实践者从 GitHub 链接点入，评估工程价值

> 一个 AI 安全方向的工程师从 GitHub 仓库链接进入 3D 首页。他快速滚动到第三幕（功能层），看到 Ψ(t) ∈ ℝ⁴² 的状态向量晶格和 G-M-A-R 操作标签，判断"这有可计算框架的雏形"。他点击三通道图例中的 PSE，进入 2D 网站的 PSE 计算引擎子站，查看蒙特卡罗仿真与贝叶斯校准的规格。

**成功条件**：访客滚动到第三幕（功能层）后点击进入对应模块子站。

### 场景 C（低频高价值场景，约 20%）：潜在合作者从邮件/引用点入，完整了解全貌

> 一个心理学教授从同事邮件中的引用链接点入。她有 5 分钟耐心，完整看完 4 幕滚动叙事，然后点击顶部导航进入教材首页，浏览 29 章目录结构，判断这是一个值得深入评估的框架。她记下 Zenodo DOI，准备在下一篇论文中引用。

**成功条件**：访客完成全程体验，进入教材或预印本页面，产生引用/收藏行为。

## 4. 北极星指标 / 成功度量

### 4.1 北极星指标（NSM）

INTRE 是学术项目，非商业 SaaS。北极星指标不衡量"转化率"或"留存"，而衡量**理论被引用、采用与讨论的程度**。

> **NSM = 框架引用与采用信号**
>
> 具体定义为三层漏斗：
> 1. **接触层**：3D 首页完成 4 幕全程滚动 + 点击进入任意 2D 子页的访客数（月度）
> 2. **采用层**：教材章节阅读量 + 术语表搜索量（月度）
> 3. **引用层**：4 篇预印本的 Zenodo 引用数 + DOI 被外部文献引用次数（季度）

NSM 的核心逻辑：3D 首页负责"接触层"的最大化——让尽可能多的目标用户在最短时间内理解 INTRE 的核心心智模型，并进入深度内容。

### 4.2 次要指标（3D 首页层面）

| 指标 | 类型 | 衡量什么 | 量度方式 |
|------|------|----------|----------|
| 完成 4 幕全程滚动 | 行为 | 体验深度 | `window.scrollY >= max × 0.95` 触发，记录事件 |
| 点击进入子页 | 转化 | 兴趣转化 | 出口链接点击数（三通道图例 / 导航 / 公式芯片 / 节点面板） |
| 滚动到 RCT3（功能层）的人数占比 | 漏斗 | 关键幕留存 | 滚动进度 ≥ 0.55 的事件数 / 总访问数 |
| 平均停留时长 | 体验 | 沉浸度 | 页面停留时间中位数（目标 ≥ 90s） |
| 7 日内回访率 | 黏性 | 价值认同 | 回访访客占比 |
| 站外分享数 | 传播 | 影响力 | 分享按钮点击 + 链接复制事件 |
| 移动端 vs 桌面端流量分布 | 兼容性 | 设备覆盖 | User-Agent 统计 |

### 4.3 反指标（避免的事）

| 反指标 | 阈值 | 原因 |
|--------|------|------|
| 桌面端 30 秒内跳出率 | > 70% | 说明首屏未能吸引目标用户 |
| 移动端页面无法打开 | WebGL 不可用且无 fallback | 移动端流量不可忽略 |
| 弹窗跳出率 | 100% | 学术项目不应有弹窗 |
| 平均停留 < 30s | 中位数 < 30s | 说明用户未进入叙事就离开 |

### 4.4 目标阈值

- 桌面端跳出率 < 40%
- 移动端（WebGL fallback 模式）跳出率 < 60%
- 完成 4 幕全程滚动的占比 > 25%
- 点击进入 2D 子页的占比 > 15%

⏳ 待确认（指标阈值需上线后用实测数据校准，当前为基于经验的目标值）

## 5. 用户旅程

### 5.1 全路径：从首次接触到深度参与

```
[外部入口]
  │  来源：知乎/推文分享、GitHub README、论文引用、邮件签名、搜索引擎
  ▼
[3D 首页 · RCT1 开场]
  │  深色场景 + INTRE 字标 + "功能层心理学"一句话定义
  │  用户行为：30 秒内决定是否继续滚动
  ▼
[3D 首页 · RCT2 现象层]
  │  展示可观测心理现象（行为、语义、主观体验）
  │  数字滚动："42 / 42 可数"徽章从 0 跳到 42
  │  用户行为：开始理解"现象层是可观测的"
  ▼
[3D 首页 · RCT3 功能层] ⭐ 关键停留
  │  42 维状态向量晶格展开（6 模块 × 7 子维）
  │  G-M-A-R 操作标签浮现
  │  贝叶斯融合公式芯片 Ψ(t) ∈ ℝ⁴²
  │  用户行为：点击晶格节点查看维度详情；或直接滚动
  ▼
[3D 首页 · RCT4 神经层]
  │  DTI 脑图纤维束渲染
  │  三通道状态灯（UPLP/UNIP/UBMP）脉冲呼吸
  │  用户行为：理解"三层 + 三通道"全景
  ▼
[出口选择] ← 3D 首页的终点，2D 网站的起点
  │
  ├──→ 点击三通道图例 → UPLP/UNIP/UBMP 模块子站（工程实践者路径）
  ├──→ 点击公式芯片 → 术语表检索"状态向量"（学术研究者路径）
  ├──→ 点击 42 徽章 → 教材第 8 章"42 维表示与动力学"（深度学习者路径）
  ├──→ 点击顶部导航 → 教材首页 / PSE / REVER（系统浏览路径）

  ▼
[2D 网站 · 深度内容]
  │  核心纲要（01-M-00）→ 替代测试报告（05-V-17）→ 导论教材（29 章）
  ▼
[长期参与]
  │  引用预印本 / 在论文中采用框架 / 提出学术反馈 / 跨学科合作
```
