核心架构术语

N-S-R | Need-Structure-Realization — 元公理：需要→结构→实现的循环
M-R-P | Module-Ring-Playbook — 通用架构：模块-控制环-剧本
M-R-D-S | Module-Resource-Dispatch-Structure — 状态语法：模块-资源-调度-结构
M1–M6 — 六模块：M1具身 / M2认知 / M3意志 / M4情绪 / M5言语 / M6行为
42维状态向量 — Ψ(t)：6模块 × 7子维度(R:2 + D:2 + S:3) = 42维
RES-D | Dispatchable Resource — 调度资源：即时可用的心理能量
RES-B | Basal Resource — 基底资源：长期心理资本
DSP-F | Foreground Dispatch — 前台调度：需意识参与的目标导向进程
DSP-B | Background Dispatch — 后台调度：无需意识努力的自动进程
STR-R | Rule Structure — 规则结构：系统的规则库
STR-C | Connection Structure — 连接结构：系统的权重网络
STR-S | Sequence Structure — 序列结构：系统的时间序列协议
三层架构 — 基质实现层（旧称神经层）/ 功能系统层（旧称功能层）/ 现象呈现层（旧称现象层），功能系统层为工程核心
三通道融合 — 行为似然·语义似然·神经似然 → 贝叶斯乘积融合 p(y|Ψ)=p(y_b)·p(y_s)·p(y_n)
S-P | Source-Pattern — 外部架构：环境源流与影响模式
S层六层 — 微系统 / 中系统 / 外系统 / 宏系统 / 时序系统 / 数字系统
P+ / P– — 资源增强型 / 资源消耗型环境模式

操作语法 (G-M-A-R)

操作算子 — G-M-A-R 四类原子操作的集合名：GATE 门控 / MODULATE 调制 / ALIGN 校准 / RELINK 重联
GATE — 门控操作：调节目标进程的激活阈值，不改变进程内容、资源与连接；靶点 DSP-F、DSP-B、STR-S
GATE+ — 降低激活阈值（更易被触发）
GATE– — 提高激活阈值（更难被触发）
MODULATE — 调制操作（正名「调制」，调节为非正式别称）：调节资源水平，目标 RES-D
MODULATE+ — 补充资源
MODULATE– — 消耗资源
ALIGN — 校准操作：修正规则结构，目标 STR-R
RELINK — 重联操作：重组连接网络，目标 STR-C
D-R-S — 干预序列之一：调度→资源→结构（默认阶段顺序；非唯一，危机例外可越序）

心理系统计算引擎 (PSCE)

PSCE | Psychological System Computational Engine — 心理系统计算引擎：承担 L1-L5 全部计算（看→想→算→规划→执行→反馈）
MCT | Mental Compilation Theory — 心智编译理论：语义 → 数值转译（L1-S 观测编译）
MTT | Mental Topology Theory — 心智拓扑理论：模块依赖矩阵与级联（L3）
MKT | Mental Kinetics Theory — 心智动力学理论：状态演化规律（L3）
MDT | Mental Dispatch Theory — 心智调度理论：资源调度时序（L4 干预规划）
MPT | Mental Plasticity Theory — 心智可塑性理论：结构改变的物理条件（L3）
MET | Mental Ecology Theory — 心智生态理论：环境耦合与生态位（L3 E(t) 驱动项）
心智六论 — 教学/叙事标签体系（非独立架构层）：MCT + MTT + MKT + MDT + MPT + MET
VTS-P | Variable-to-State Protocol — 观测→状态入口：临床评估数据 → M-R-D-S 状态向量
ETS-P | Environment-to-State Protocol — 环境→动力学入口：环境信息 → S-P 影响向量 + E(t) 驱动项
SID-P | System Integrated Diagnosis Protocol — 系统集成诊断协议
MMD-P | Multi-Dimensional Meta-Dispatch Protocol — 多维元调度协议
STO-P | Structure-to-Operation Protocol — 结构到操作协议
PSCE-I/M/P/C — PSCE 四阶段：I 理论注入 → M 蒙特卡罗仿真 → P 先验提取 → C 真实世界校准

知识基础设施 (IODS)

IODS | INTRE Ontology Definition System — INTRE 本体定义体系：L0 本体；静态、无运行时、无 API；定义 42 维 M-R-D-S 状态语法、G-M-A-R 操作语法、PCUI/PSA/PSL 知识基础设施；S-P 环境参照系全部静态定义；与 UPLP 边界——IODS 定义"是什么"，UPLP 编译"怎么观测"
UPLP | Unified Psychological Language Port — PSCE 感知层 L1-S 语义输入端口；五层编译流水线 S1-S5；定义侧内容归 IODS
PCUI | Psychological Concept Unique Identifier — 心理概念唯一标识符（IODS 知识基础设施）
PSA | Psychological Semantic Architecture — 心理语义架构（IODS 知识基础设施）：概念间关系与结构约束定义；推理执行随 UPLP 编译流水线（L1-S）
PSL | Psychological Specialist Lexicon — 心理专项词汇库（IODS 知识基础设施；论文/教材历史译名：心理专家词典）：自然语言 → PCUI 映射

神经接口系统 (UNIP)

UNIP | Unified Neural Interface Port — PSCE 感知层 L1-N 神经输入端口：神经输入通道（EEG/fNIRS/PPG，含 HRV）→ 神经似然 p(y_n|Ψ)，六层递进 N1-N6
NAP | L1 Neural Acquisition Protocol — 神经采集规范：规定 BIDS 格式、同步等级、元数据标准
SCL | L2 Signal Calibration Layer — 信号校准层：去伪影、滤波、时间同步
NFD | L3 Neural Feature Definition — 神经特征定义：频带功率、ERP 成分、连接性指标提取
NFM | L4 Neural-Functional Mapping — 神经-功能映射：神经特征 → 42 维功能坐标
NPL | L5 Neural Prior Library — 神经先验库：群体神经先验分布，约束个体映射（与 L3 参数层交界面）
RTE | L6 Real-time Engine — 实时引擎：在线实时处理，输出 p(y_n|Ψ)；含 RTE-Infer 推断（UNIP→PSCE）与 RTE-Cal 校准（PSCE→UNIP）
NFI | Neural Feature Identifier — 神经特征标识符，如 NFI.EEG.v1.002
BIDS | Brain Imaging Data Structure — 神经数据组织标准，UNIP L1 采用
LSL | Lab Streaming Layer — 实时数据流同步协议，UNIP L6 采用
ONNX | Open Neural Network Exchange — 模型跨框架交换格式，UNIP L4 采用
神经似然 — UNIP 标准化输出 p(y_n|Ψ_t)，参与 PSCE 三通道贝叶斯融合
仲裁合约 — UNIP ↔ PSCE 双向通信接口：/func_likelihood（前向）+ /calibration_feedback（反向）
通道分歧 — 行为/语义/神经三通道对同子单元估计出现系统性分歧时的诊断信号

行为测量系统 (UBMP)

UBMP | Unified Behavioral Measurement Port — 统一行为测量端口：FSP 行为通道基础设施，将结构化行为观测转化为行为似然；PSCE 感知层 L1-B 行为输入端口；五层架构 B1-B5（v1.1.0 由 3 层扩展）
BHI 标识符 | Behavioral Health Indicator — 行为健康指标标识符，格式 BHI.[DOMAIN].v[VER].[SEQ]，如 BHI.DEPRESSION.v2.003
BHI 条目 — B1 注册库中 BHI 标识符对应的完整记录（含观测函数、信效度、桥接参数等）
BHI 注册库 — B1 中所有 BHI 条目的集合
B1 BMR | Behavioral Measurement Registry — 行为测量注册库：登记 BHI 条目（观测函数、信效度矩阵、桥接参数、数字表型协议、版本元数据）
B2 BAL | Behavioral Alignment — 行为语义对齐：消费 L1-S 对齐服务，裁决两个 BHI 是否锚定同一 M-R-D-S 构念；对齐失败则禁止下游桥接
B3 BLK | Behavioral Linking — 行为跨工具桥接：在语义对齐前提下执行 IRT 跨工具等价转换（二参数 IRT、共同条目锚定、等百分位方法）
B4 BCI | Behavioral Calibration & Individualization — 行为校准与个体化：应用观测函数 p(y_b\|Ψ) 将校准分数映射为 42 维坐标观测 + 层级收缩个体化 + 漂移检测
B5 BLI | Behavioral Likelihood Interface — 行为似然接口：`/behavioral_likelihood` 端点，按 L1-I §2.4 契约输出观测块 {y_b, σ_b}
UBMP 观测函数 | h_b(x) — 行为通道观测函数：将测量分数 x 映射到功能状态子维度似然（方向：x→y_b），定义于 B1（BMR）、由 B4 应用
行为似然 — B5 标准化输出 p(y_b|Ψ_t)，必须经 /behavioral_likelihood 端点获取，参与 PSCE 三通道融合
UPLP 语义对齐前置 — UBMP 核心约束：两个 BHI 条目须经 L1-S（UPLP）确认同一 M-R-D-S 组件后方可进入 B3 IRT 桥接；B2 门控执行
工具桥接 | Instrument Linking — 不同 BHI 条目对同一 M-R-D-S 组件的分数等价转换，由 B3 BLK 执行
数字表型协议 | Digital Phenotype Protocol — B1 可选字段：从原始传感器数据到数字表型特征的完整处理链定义
IRT | Item Response Theory — 项目反应理论：B3 跨工具等价转换的方法论基础
CTT | Classical Test Theory — 经典测量理论：B1 信度指标的方法论基础
PSCE-M 内嵌子层 — UBMP 前身：行为测量作为 PSCE-M 蒙特卡罗仿真阶段内部子模块的历史形态

FSP 学科体系

FSP | Functional State Psychology — 功能状态心理学（旧称功能层心理学／FLP；限定全称 State-Centered Functional System Layer Psychology）：INTRE 框架的学科统称，含五大支柱学科
PFIM | Psychofunctional Input Metrology — 功能层输入测量学：多通道 p(Ψ|y) 估计
PFD | Psychofunctional Dynamics — 功能层动力学：状态演化规律与级联分析
PFI | Psychofunctional Intervention — 功能层干预学：靶点明确的干预设计与优化
PFM | Psychofunctional Metascience — 功能层元科学：知识质量保障与证伪制度化
PDE | Psychofunctional Developmental Ecology — 功能层发展生态学：生命周期与跨文化维度
DMD | Default Mode Dispatch Therapy — 从 G-M-A-R 语法空位生成的结构化心理干预
CI+AI — 协同建构方法论：人类晶核 + AI 展开

伦理引擎 (REVER)

REVER | Relational Ethics via Verified Engineered Response — 关系伦理验证工程化响应：独立伦理护栏（不属 IODS/PSCE），覆盖 L0-L5 全级与反馈回环
Dₛ — 依赖分数：量化用户依恋程度
六门控一回环 — G0 定义 → G1 观测 → G2 估计 → G3 动力学 → G4 规划 → G5 执行 ＋ EC 伦理回环

证据等级标签 (IET v3.0)

D — 定义类：术语如何被规定/界定
L — 推导类：从前提可推出什么
F — 描述类：事实是什么
X — 解释类：为什么会发生
P — 预测类：未来会发生什么
N — 规范类：应该怎样
E — 证据类：有什么证据支持
R — 关系类：事物之间有什么关系
示例标签 — D1a(规定性定义) / L1a-p(必然推演) / P2i-m(假说,间接可检验) / E1a+(RCT强证据)

范式与边界视图

变量范式 | variable-centered paradigm — 以变量为单位（观测协方差结构）：承担现象呈现层的观测、测量与检验；旧称「结构范式」已停用
状态范式 | state-centered paradigm — 以功能状态向量 Ψ(t) 为单位：在功能系统层补充状态描述与干预语法，经观测函数与变量范式分工相连
接入层 | Access Layer — 全局边界视图第 1 层：外部应用域（UI 应用）所在层，人类接入面，INTRE 交付物之外，经协议层编程接入 PSCE
智能体状态工程 | Agent State Engineering — 硅基路线限定（不设简称）：推理环外以「外挂状态机」对智能体作遥测与截断控制——观测 M-R-D-S、控制 G-M-A-R；与 Agent OS（架构蓝图）互为表里
