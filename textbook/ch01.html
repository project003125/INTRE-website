第1章 双范式总览：K3 分岔与两套纲领

学习目标：(1) 说清两套范式共享的实证底线与真正的分岔点；(2) 用 K1–K5 判断哪些分歧是次要的、哪些是根节点；(3) 用六大差异与纲领七维表定位两套数学对象的承载范围；(4) 把 MOD、SMOD、DISC、META 四系映射到本书章节。

1.1 两套范式与 K3 分岔

心理学在二十世纪建立了一套以变量为中心的技术体系：量表编制、因子分析、回归、结构方程、潜在结果框架。它把心理现象拆成可测量的构念，再用协方差与实验设计估计构念之间的关系。这套体系解决了“如何把主观体验变成可比较的数字”，也留下了三个长期问题：构念越造越多、测量不变性脆弱、跨情境复制率偏低。

状态范式保留这套体系的实证底线，只更换描述单位。变量由观测协方差定义，换一套量表、换一个样本，变量的含义可能漂移；功能状态 \(\Psi\) 由功能架构定义，是 6 个功能模块 × 7 个状态维度的 42 维向量。换一套测量工具，改变的是观测函数 \(h\) 的参数，不是状态坐标本身。

分岔点在 K3。K1 要求知识建立在可检验事实上，K2 要求概念可操作化，这两层两套范式都能通过，差别只在“可检验”的外延与“可操作化”的定义来源。K3 问的是更靠前的问题：基本单位是变量，还是功能状态 \(\Psi\)。K4、K5 是 K3 的下游：因果对象从处理效应变为状态演化与干预靶点；理论网络从变量关系网变为功能架构加观测函数。

把 K3 当根节点，后面的差异才能排成一条链；否则六个差异会像六场互不相干的争论。变量范式在其单位内是一套完整闭环：从本体论预设、测量、设计、统计、因果识别一直走到制度批判。状态范式增加的是一个功能描述层，不是在现象呈现层宣布旧工作作废。

1.2 K1–K5 总对比

层次 变量范式 状态范式 关系类型 矛盾地位
K1 实证主义 知识须建立在可观察事实上；“可观察”在实践中等价于量表分数、行为频率、自我报告 知识须建立在可检验事实上；“可检验”扩展为预测—干预效能，并接受基质层的硬约束、软约束与兼容性信号 同一原则的不同外延：都要求经验检验路径，检验对象不同 次要矛盾
K2 操作主义 概念的意义 = 测量它的操作；“智力”就是智力测验所测到的东西 概念的意义 = 在功能架构中的因果角色；“焦虑”= M4-DSP-B 高唤醒 + M2-STR-R 威胁偏向 + M1-RES-D 下降 保留可操作化精神，换定义来源：测量操作 → 功能架构 次要矛盾（含方向性转变，K3 前奏）
K3 变量实在论 变量与潜变量是真实存在的心理属性，具有因果力；基本单位 = 变量，由观测协方差定义 功能组件是功能因果网络中的角色实体；基本单位 = 功能状态 \(\Psi\)，由功能架构定义，42 维 = 6 模块 × 7 维度 换基本单位：现象呈现层仍可用变量实在论，功能系统层换功能实在论 主要矛盾——根节点
K4 因果推断假设 潜在结果、可忽略性、SUTVA、DAG、IV/RDD/DID/PSM；节点 = 变量；核心对象 = 处理效应 状态演化 + 干预算子；do(G-M-A-R) 作用于 \(\Psi\)；节点 = 功能组件；核心对象 = 状态演化与干预靶点 换因果对象：处理效应 → 状态演化与干预靶点 次要矛盾（由 K3 决定）
K5 构念定义·法则网络 构念通过理论网络中的位置定义；节点 = 现象呈现层观测读数或构念；网络 = 变量关系网 功能架构 + 观测函数 \(h\)：功能组件生成架构（D 矩阵、STR 三分、级联规则、六条动力学约束）+ 观测映射 \(y = h(\Psi, E) + \varepsilon\) 换网络类型：变量关系网 → 功能架构 + 观测函数 次要矛盾（由 K3 决定）

读表分三步。K1、K2 是同一实证传统内的外延变化与定义来源变化，双方都能通过。K3 换单位，是根节点。K4、K5 是 K3 的自然延伸，不是新的独立分叉点。

反向检查同样成立：基本单位的挑战不能追溯到更上游的本体论立场、描述层级或范式基质。本体论立场与基本单位互为表达，描述层级差异是基本单位差异的层级表达，范式基质本身已经包含基本单位的选择。

1.3 六大差异与判据所在层

六项常见差异看似独立，逐一追溯都会回到 K3。下表把每项差异与它的判据层并列，避免把“数学对象的承载范围”误读为“某一方缺构件”。

差异 变量范式 状态范式 判据所在层
数学对象 \(P(Y)\)、\(P(Y\mid X)\)：观测变量的概率结构 \(h:\Psi\to y\)、\(f:\Psi_t\to\Psi_{t+1}\)：状态映射与演化 第二层：变化率是否带功能语义
因果定义 处理效应 \(P(Y\mid do(X))\) do(G-M-A-R) 作用于 \(\Psi\)，输出状态转移与干预靶点 第三层：约束与靶点合法性是否绑定功能分量
测量方式 构念 → 指标；测量对象由观测协方差定义 状态 → 观测；测量对象由功能架构定义 第二层：换量表后状态身份是否保持
时间维度 离散快照、离散时点，时间轴上动的是变量 连续轨迹，时间轴上动的是 \(\Psi\)，有动力学方程 第二层：先后关系是否具有功能方向
干预方式 处理包；靶点是变量 G-M-A-R 操作序列；靶点是功能状态分量 第三层：操作能否与靶点合法性矩阵耦合
复制危机解释 方法、制度、样本问题；归因于情境未控制 描述单位与数学对象错位；归因于观测函数的情境漂移未被建模 第二层：单位是否随测量程序漂移

不同维度，同一把尺。判断不以任一方的构件清单为尺。四目标——描述、解释、预测、控制——是心理学通行框架，两套范式都在这把尺上被量。问法固定为：这套数学对象能承载哪一个目标、承载到什么精度、在什么条件下失效。

按这把尺，变量范式在现象呈现层描述、群体效应估计、外部效度检验上强；状态范式在个体状态估计、轨迹预测、约束下的干预规划上强。差异的本质是承载范围不同，不是“谁缺构件”。

判据分三层。第一层只作中性判定：双方都通过实证与可操作化，不映射差异维度。第二层问数学对象是否具有状态变量身份，变化率是否带功能语义。第三层问约束是否锚定功能分量，靶点是否可与干预耦合。判据所在层的作用，是防止用第一层的“都通过”抹平第二、三层的承载差异，也防止用第三层的构件清单反过来否定第一层。

1.4 科学研究纲领七维表

K1–K5 给出哲学承诺轴，下表给出科学纲领速览轴。两套纲领共享实证主义底色，在基本单位处分岔；各自的硬核不同，保护带也不同。

维度 核心问题 变量范式 状态范式 分岔点 / 关系
纲领定位 这套科学纲领怎么组织？ 以“变量”为基本单位的概率—统计纲领 以“功能状态 \(\Psi\)”为基本单位的状态空间—动力学纲领 共享实证主义底色；K3 换基本单位，是根节点
本体论 研究对象“是什么”？ 心理现象可分解为变量与潜变量；变量是真实心理属性、有因果力；默认在现象呈现层内工作 心理现象可描述为 42 维功能状态；功能系统层是独立描述层级；功能组件是功能因果网络中的角色实体 变量 vs \(\Psi\)；变量实在论在现象呈现层有效，功能实在论在功能系统层有效
认识论 我们“如何知道”？ 可观察 → 操作定义 → 测量 → 统计推断 → 因果识别；构念效度、法则网络、潜在结果、DAG “可检验”扩展为预测—干预效能 + 基质层约束；观测函数、逆问题、多模态一致性、强反例协议 变量范式偏“观测层关系证成”；状态范式要求生成机制、干预效能与约束共同证成，认识论负担更重
方法论 用什么方法获得证据？ CTT/IRT/CFA、信效度、测量不变性、回归/ANOVA/SEM/HLM、DSEM/RI-CLPM、RCT/IV/RDD/DID/PSM、开放科学 M-R-D-S 状态语法、G-M-A-R 操作语法、S-P 环境参照、L0–L5 计算管线、L1 三端口、L2 融合、L3 动力学、L4/L5 规划执行 统计方法构成变量范式方法论的核心；状态范式核心是状态建模 + 状态估计 + 干预规划 + 治理；方法论层可部分整合
目的论 为什么研究？达到什么目标？ 描述变量间关系、解释方差、预测条件均值、控制处理效应；服务群体平均效应与现象呈现层规律发现 描述状态、解释生成机制、预测轨迹分布与风险时点、规划最优操作序列；服务个体化轨迹与功能系统层干预 变量范式在现象呈现层描述与群体效应上强；状态范式在功能系统层轨迹预测与最优控制上强；目标决定基本单位
失败模式与修正 各自怎么失败？ 失败多在硬核层：节点本体不清、构念膨胀、复制危机、WEIRD 样本；保护带修正难根治 失败多在保护带层：逆问题、高维、参数校准、可辨识性；可通过算法、数据、治理逐步缓解，实证仍在推进 变量范式问题偏结构性；状态范式问题偏技术性、收敛式，但不能说已兑现
总体关系 两套范式能不能共存？ 现象呈现层用变量范式：变量实在论仍有效；提供观测材料、先验、外部校验 功能系统层用状态范式：功能实在论；提供功能架构、生成模型、状态估计、干预规划 分工关系：基本单位不同时承认，不还原；可互译但有成本；通过观测函数 \(h\) 连接

七维表不给两套纲领打分，只标出各自把什么问题放在硬核、把什么问题放在保护带。变量范式的硬核是“基本单位 = 变量”；状态范式的硬核是“基本单位 = \(\Psi\)”。两套硬核都由方法论决策保护，不能被单条经验直接推翻；可修正的是外围的保护带。

差别在失败模式。变量范式的结构性困难集中在基本单位与节点本体；状态范式的技术性困难集中在逆问题、高维估计与参数校准。前者难以靠更好的统计技巧根治，后者可以靠算法、数据与治理逐步收敛。这个判断不否定变量范式在测量、因果识别与制度批判上的技术成就。

1.5 一句话总图：分工而非替代

变量范式 = 现象呈现层的变量—概率—统计纲领；状态范式 = 功能系统层的 \(\Psi\)—状态空间—动力学纲领。二者共享实证主义，在 K3 换基本单位处分岔；目的论上分别承载“群体 / 现象呈现层关系”与“个体 / 功能系统层轨迹与控制”，因此总体是分工而非替代。

分工的接触面在保护带。变量范式提供观测材料、测量工具、群体先验与外部校验；状态范式提供功能坐标、生成模型、状态估计与操作规划。连接件是观测函数 \(y = h(\Psi, E) + \varepsilon\)：同一个 \(\Psi\) 在不同测量接口上产生不同读数，读数之间的关系不自动等于状态之间的关系。

互译有成本。现象呈现层构念通常是多维、语境依赖的，投影到 42 维坐标会损失主观质感与文化意味；功能系统层状态投影回现象呈现层读数，也会丢失分量间的结构信息。承认成本，才能把翻译做成有置信度分级、有边界注释的局部映射，而不是宣布两套语言等价。

不还原，也不混同。基本单位不同时，两套范式各自在自己的层级上成立；把变量读数直接当作功能组件，或把功能状态直接当作量表分数，都会跨过 K3 划出的边界。

1.6 四系到本书：MOD、SMOD、DISC、META 的章节映射

双范式对比材料按四系组织。MOD 系讲变量范式的七个模块，SMOD 系讲状态范式的十个模块，DISC 系处理专题争论，META 系从元层审视两套纲领的关系。本书把四系压缩为可教学的章节顺序。

系列 内容 本书对应 读法
MOD 变量范式七模块：哲学预设、构念测量、设计抽样、统计推断、因果识别、计算建模、制度批判 第1章（总对比与压缩）+ 第4章（边界与吸纳） 先看七模块的完整闭环，再看它在哪些目标上承载不足；不把模块清单当作攻击靶子
SMOD-01 本体论与层级：三层架构、约束功能主义、多重实现、描述层级 第2章 先立层级合法性，再谈状态语法
SMOD-02 / 03 状态语法与操作语法：M-R-D-S、42 维、D 矩阵、STR 三分、G-M-A-R、靶点合法性矩阵 第3章（总览）+ 第5章、第8章（展开） 第3章看对偶结构，第5章逐维展开，第8章落到操作
SMOD-04 环境参照：S-P、环境负荷、E(t) 第7章 环境不是背景变量，是动力学驱动项
SMOD-05 / 06 / 07 动力学与计算引擎、测量与观测、干预与验证 引擎：第12、16–20章；测量：第6、13–15章；干预：第8–10、20章 按“观测 → 估计 → 动力学 → 规划 → 执行”顺序读
SMOD-08 治理与证据：证据分级、预注册、隔离机制、边界登记 第24章 把治理当作知识生产的一部分，不是附录
SMOD-09 / 10 跨基质与智能科学、元方法与建构 第21章、第23章、第25章 跨基质问题放在框架稳定之后再读
DISC 专题讨论：K3 根节点、全景对比、可检验边界、功能角色定义风险、\(\Psi\) 代价、共存分工 第1章与第4章 DISC-01 是根节点论证，先于其他专题
META 元层专题：硬核与保护带、整合可能性、失败模式、翻译成本、伦理规范、历史演化 第1章（纲领表）+ 第4章（吸纳）+ 第25章（未决与范式对话） 元层不提供新事实，只改变看事实的方式

阅读顺序按“先根节点，后分支”：第1章建立 K3 与七维纲领；第2章立三层合法性；第3章给 IODS 与 PSE 的总图；第4章处理影子、中介与当代方法的边界；第5章起进入状态坐标系。MOD 系的完整七模块在第1、4章被压缩取材，SMOD 系的十模块在后文按语法、引擎、治理、跨基质依次展开。

本章把双范式对比压成一条链：K3 换单位 → 六差异是同一根节点的投影 → 七维纲领标出硬核与保护带 → 总体是分工而非替代。记住这条链，后文的每个构件都能找到它在对比中的位置。
