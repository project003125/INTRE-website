PSE · 心理系统计算引擎

一次主诉，走完六级管线

PSE 把心理系统的处理拆成六级：先在 L0 定义坐标与词汇，在 L1 接住语义、行为、神经三类观测，L2 估计当前状态，L3 推演未来轨迹，L4 搜索干预序列，L5 执行并把结果送回 L1。下面这张图是整条路线的最小版本。

模拟走查：林晓的八周

从主诉到下一轮观测

模拟数据 · 非临床结论
L0 · ONTOLOGY

先把“说什么”固定下来

林晓，28 岁，产品经理。近三个月入睡困难、白天耗竭、对未来反复担忧。L0 不处理这些句子，只规定用哪套坐标描述它们：6 个功能模块 × 7 个状态维度，共 42 维。

坐标

M1–M6 六模块；RES / DSP / STR 三轴七维

词汇

“入睡困难”落到 M1 资源与 M4 唤醒；不新造概念

边界

不新增维度；术语与结构约束在这一层固定

这一层没有运行时。它只回答“用什么尺子量”，不回答“量出来是多少”。
L1 · PERCEPTION

三类观测同时进来

同一周内，三个端口各给一组带不确定度的读数。它们不是三套结论，而是三组证据。

UPLP · 语义

“最近总睡不好，白天撑不住，脑子停不下来。”

UBMP · 行为

入睡潜伏期 95 分钟；PHQ-9 = 12；日均步数下降 28%

UNIP · 神经

夜间心率变异性偏低（示例读数；在线层尚未实现）

合并输出：结构化观测向量 yt，每个分量附不确定度。某个端口缺失时，该分量标为“无信息”，其余端口照常工作。

L2 · STATE ESTIMATION

把三组证据合成一个当前状态

L2 做贝叶斯融合，并与 L3 给出的转移先验迭代，得到 Ψt 的后验分布。下图只展示六个关键分量，条形长度是后验均值，右侧是区间。

42 ± 7

L2 不判断“她是什么病”，只回答“当前状态在哪、有多确定”。诊断标签不在这里产生。
L3 · DYNAMICS

不干预会怎样，干预会怎样

L3 用当前状态推演未来八周。红线是“不改变环境与行为”的基线，蓝线是“前两周先稳住调度、再恢复资源”的模拟轨迹。阴影区间标出风险时点。

不干预基线先稳调度、再补资源阴影：风险时点（第 4–6 周）

这一步给出：未来状态分布、级联路径、风险时点，以及“若现在动手，哪一段最值得改”。

L4 · PLANNING

在约束下选一条序列

L4 拿到预测轨迹后，在资源预算、操作组合规则与伦理门控下比较候选方案。下表是三条候选，选中的不是“效果最大”，而是“当前资源下最稳”。

候选前两周动作八周成功概率资源代价取舍
A · 先稳后补GATE 抑制反刍 + MODULATE 补资源0.62低先恢复可执行性，再谈结构改变
B · 直接改信念ALIGN 规则修正0.48中资源不足时容易做不动
C · 环境重联RELINK + 环境调整0.55高需要家庭与工作场景配合
方案 A 不是唯一正确解。它是在“当前资源 28/100、八周窗口、伦理约束”下的推荐解；换约束，排序会变。
L5 · EXECUTION

做下去，并把结果送回来

执行层记录剂量、依从性、异常事件与阶段结果。它不是终点：每一次记录都要回到 L1，成为下一轮观测的一部分。

第 1–2 周

依从率 85%；入睡潜伏期 95 → 70 分钟；无异常事件

第 3–4 周

资源后验 28 → 47；开始加入 1 次 ALIGN 会谈

第 8 周

潜伏期 40 分钟；反刍时长下降；进入维持期

闭环：L5 的记录包回传 L1 → L2 重新估计 → L3 重算轨迹。一次走查结束，下一轮从新的观测开始。

六层各自回答什么

层它回答的问题交付物做不下去时
L0 本体用什么坐标、词汇和结构描述坐标系、词汇、约束不适用（无运行时）
L1 观测现在能采集到什么证据带不确定度的观测向量缺失端口标“无信息”
L2 状态估计当前状态在哪、有多确定42 维后验与协方差退化为单模态最大后验
L3 动力学不干预会怎样、干预会怎样轨迹分布、级联、风险时点多模型加权，不假装唯一解
L4 规划在约束下先做什么、后做什么操作序列、成功概率、时间窗无可行解时退回保守方案
L5 执行做成了没有、下一步改什么执行记录、依从性、反馈中止并回滚到 L4 重规划

三个输入端口

UPLP · 语义

把主诉、访谈与自由文本编译成语义似然。它处理“人怎么说”，不替人下诊断。

UBMP · 行为

接量表、EMA、睡眠与活动数据，输出行为似然。它处理“人怎么做、做了多少”。

进入 UBMP 页面 →

UNIP · 神经

接 EEG、fNIRS、PPG 等信号，输出神经似然。当前在线层尚未实现，缺失时按“无信息”处理。

进入 UNIP 页面 →

能看到什么，不能看到什么

这套管线能给出

  • 当前状态的后验与不确定度
  • 未来数周到数月的轨迹分布与风险时点
  • 在资源与伦理约束下的候选干预序列
  • 执行后的反馈，以及下一轮如何修正

它不承诺

  • 不替代临床诊断与危机处置
  • 不在未校准参数上外推“疗效”
  • 不把模拟案例当成真实临床结果
  • 不把“算得出”当成“已经验证”
