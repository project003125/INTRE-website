第3章 框架总览：从元公理到 IODS＋PSE

学习目标：(1) 复述 N-S-R → M-R-P → M1-M6 的推导链；(2) 说明状态语法与操作语法如何在 7 个维度上对偶；(3) 区分 IODS（L0）与 PSE（L1–L5）；(4) 说明知识治理五层与计算执行六级的关系；(5) 用四目标映射判断各级职责。

3.1 N-S-R → M-R-P → M1-M6

N-S-R 是框架性公理，不是从更基础前提推出的必然结论。它描述任何自适应系统的循环：需要（Need）→ 结构（Structure）→ 实现（Realization）→ 新的需要。N 是价值评估后的差距信号，S 是为弥合差距而调用的模型与方案，R 是把方案转成行动并回收反馈。

M-R-P 把 N-S-R 中的“结构”环节操作化。M 是模块库，回答系统“能做什么”；R 是控制环，回答目标如何转成行动；P 是剧本，回答特定情境下“具体怎么做”。M-R-P 不是新公理，而是对 S 环节的通用结构法则。

M1-M6 把 M-R-P 的模块层落到人类心智的功能分解。M1 具身是能量与稳态基座，M2 认知是建模与知识库，M3 意志是中央调度器，M4 情绪是价值评估中心，M5 言语是符号接口与社会连接，M6 行为是外部执行器。六个模块覆盖“能量—建模—调度—估值—符号—执行”六类必要功能。

层级 内容 回答的问题 操作化结果
N-S-R 需要 → 结构 → 实现 → 新需要 系统为何持续运行？ 循环的存在条件
M-R-P 模块、控制环、剧本 结构环节由哪些部件组成？ 通用组织法则
M1-M6 具身、认知、意志、情绪、言语、行为 人类心智需要哪些功能单元？ 功能模块分解
R-D-S × M1-M6 每个模块按资源、调度、结构展开 每个模块内部状态如何描述？ 42 维状态坐标系

推导是功能意义的，不是解剖意义的。缺少 M1，系统失去能量来源；缺少 M2，系统无法建模；缺少 M3，冲突目标无法仲裁；缺少 M4，价值标记与动机生成失效；缺少 M5，符号协调断裂；缺少 M6，意图无法转成行动。六个模块是当前颗粒度下覆盖充分且互斥的工程分解，不是“所有智能体都必须具备六个模块”的公理断言。

3.2 状态语法 ∥ 操作语法

状态语法回答“系统现在是什么”，操作语法回答“能对它做什么”。两套语法共享同一组维度，构成对偶：每一个状态维度都有对应的操作类型，每一类操作都有合法的靶点集合。

状态空间是 6 个模块 × 7 个维度的张量积：

\[ \Psi \in \mathbb{R}^{42},\qquad \Psi=\{M_i\text{-}X: i\in[1,6],\ X\in\{\text{RES-D, RES-B, DSP-F, DSP-B, STR-R, STR-C, STR-S}\}\} \]

七个维度沿 R-D-S 展开：R 层是存量，含 RES-D 调度资源与 RES-B 基底资源；D 层是流量，含 DSP-F 前台调度与 DSP-B 后台调度；S 层是结构，含 STR-R 规则、STR-C 连接、STR-S 序列。每个模块重复这七个维度，42 个基本诊断维度由此形成。

状态维度 状态语义 对应操作 靶点合法性
RES-D 调度资源 快速波动的心理燃料，时间尺度小时至天 MODULATE 唯一直接作用于资源存量的操作
RES-B 基底资源 缓慢变化的心理资本，时间尺度周至年 MODULATE 同上，作用于存量水平而非流量
DSP-F 前台调度 需意识参与的目标导向进程，高能耗 GATE 通断控制，启动、抑制或切换进程
DSP-B 后台调度 无需意识参与的自动化进程，低能耗 GATE 通断控制，主要抑制失控的自动化进程
STR-R 规则结构 “如果 X 则 Y”的算法库与信念规则 ALIGN 规则修正，改写评估与决策算法
STR-C 连接结构 X 与 Y 的连接强度与情感绑定 RELINK 联系重构，解绑或建立连接
STR-S 序列结构 “先 X 再 Y”的固定程序与节律 GATE 作用于序列的激活面，属通断控制

对偶的计数正好闭合：2 个资源维度由 MODULATE 覆盖，2 个调度维度加 1 个序列维度由 GATE 覆盖，1 个规则维度由 ALIGN 覆盖，1 个连接维度由 RELINK 覆盖，2 + 3 + 1 + 1 = 7。六个模块重复同一模式，得到 42 维的完整覆盖。

对偶不是“一个维度只能配一个操作”的机械表。GATE 同时作用于 DSP 与 STR-S，因为二者共享激活态结构；ALIGN 对 STR-S 内容面有归约关系，但 STR-S 的激活面归 GATE。靶点合法性矩阵的作用，是防止操作越界：MODULATE 不能改规则，ALIGN 不能改连接，RELINK 不能替代资源补充。

两套语法还共同约束干预顺序。D 层失控会持续消耗 R 层，R 层枯竭会让 S 层重建失去能量预算。推荐序列是先稳定调度，再恢复资源，最后重建结构。这个序列是工程优先原则，其最优性仍待实证检验。

3.3 两系统：IODS（L0）＋ PSE（L1–L5）

对外系统边界是两个系统：IODS 负责定义，PSE 负责计算。IODS 是 L0 本体定义体系，只含静态定义——坐标系、词汇、语法、结构约束；它不是系统，不需要运行时，不需要 API。PSE 覆盖 L1–L5，承担观测、估计、动力学、规划与执行。

级 系统 一句话职责 输入 → 输出
L0 本体 IODS 定义坐标系、词汇、语法与结构约束 无输入 → 42 维坐标、D 矩阵、STR 三分、级联规则、六条动力学约束
L1 观测 PSE 感知层 三端口把原始观测编译为带不确定度的观测向量 语义/行为/神经 → \(y_t=(y_s,y_b,y_n)\) 与不确定度
L2 状态估计 PSE 融合层 贝叶斯融合三模态似然与先验转移 观测 + 先验 → \(\Psi_t\) 后验与置信区间
L3 动力学 PSE 动力学层 用假设、参数与模型选择推演未来演化 \(\Psi_t\) + 环境驱动 → 未来分布、级联路径、风险时点
L4 规划 PSE 规划层 在约束下搜索最优 G-M-A-R 操作序列 状态 + 预测 + 约束 → 操作序列、成功概率、时间窗口
L5 执行 PSE 执行层 执行操作并采集反馈，闭环回到 L1 操作序列 → 执行记录、依从性数据

L1 的三个输入端口是 PSE 内部模块，不是对外独立系统：UPLP 语义端口输出 \(p(y_s\mid\Psi)\)，UBMP 行为端口输出 \(p(y_b\mid\Psi)\)，UNIP 神经端口输出 \(p(y_n\mid\Psi)\)。三路似然只有在 L2 融合后才产生状态意义。

L2 与 L3 存在双向依赖：L2 需要 L3 的转移先验，L3 需要 L2 的状态估计作为初始条件。运行时采用加权模型迭代滤波，L2 消费 L3 的 BMA 预测分布；校准期采用联合推断，一次性确定模型权重与状态。模型不确定性在 L3 内部消化，L2 保持独立级地位。

观测函数与动力学方程是整条管线的两个核心数学对象：

\[ y = h(\Psi, E) + \varepsilon,\qquad \frac{d\Psi}{dt} = \sum_k w_k f_k(\Psi, E) \]

前者把状态映射为读数，后者把状态推向未来。描述、解释、预测、控制四个目标，分别落在这两个对象的不同使用方式上。

3.4 双工程：知识治理五层＋计算执行六级

PSE 有两套切法，同时成立、互不否定。知识治理工程管“我们知道什么、怎么分类、怎么修订”，按知识类型并列分箱，共五层：架构层、算法层、参数层、方法论层、协议层。计算执行工程管“信息怎么流动、怎么一步步算完”，按计算依赖串联分级，共六级：L0 到 L5。

维度 知识治理工程 计算执行工程
核心问题 我们知道什么？怎么分类、怎么治理？ 信息怎么流动？怎么一步步算完？
组织原则 按知识类型并列分箱 按计算依赖串联分级
结构形态 架构层 / 算法层 / 参数层 / 方法论层 / 协议层 L0 本体 → L1 观测 → L2 估计 → L3 动力学 → L4 规划 → L5 执行
层间关系 并列互斥、联合覆盖，无时序依赖 单向依赖 + 局部耦合：L2-L3 双向，L5→L1 闭环
评价标准 概念清晰度、术语追溯、同行可评议性 契约闭合、参数可校准、预测可验证
相互供给 向下提供参数定义权与合法性来源 向上提供验证通道与经验反馈

IODS 是知识治理工程产出的核心工件，但不是治理工程本身。IODS 是本体，回答“有什么”；知识治理是制度，回答“怎么分类、怎么修订”；计算执行是引擎，在 IODS 划定的格子里跑信息。三者各归其位，不能把本体论地位泛化到整个五层。

两条契约把双工程咬合。向下：每个符号之所以有意义，是因为 IODS 定义了模块与层级；参数的定义权在知识治理，计算执行只负责先验生成与后验计算。向上：概念与分类是否有效，最终由预测—干预效能裁决；临床校准数据反向为知识治理提供经验反馈。

3.5 31 个编号工程地图

00–30 是 31 个工程编号，不是 31 套本体论。它们分属阅读、理论、论证、对接、验证、治理、计算、学科与端口九类工作；对外系统边界仍只有 IODS＋PSE 两个系统。

31 个编号的读法是“分工图”，不是“本体清单”。理论、论证、验证、治理各自解决不同问题；学科与端口工程把框架接到外部世界；28–30 三个端口工程是 PSE 感知层的工程线，端口本体规范仍在核心理论中，不因立工程而升为对外独立系统。

编号之间没有上下级本体关系。00 号不定义心理结构，30 号不产生独立于 PSE 的输出。贯穿全部编号的定义源是 IODS；贯穿全部计算的是 PSE 的 L1–L5。

3.6 四目标映射

四个目标不是四个口号，而是四级职责。描述、解释、预测、控制各自对应管线中的不同位置，混淆它们会让状态估计与动力学推演互相污染。

目标 实现级 回答的问题 典型输出
描述 L2 当前心理状态是什么？ \(\Psi_t\) 后验、置信区间、分量读数
解释 L3 为什么状态是这样？哪些因素在驱动？ 级联路径、驱动项分解、机制假设
预测 L3 如果不干预，未来会怎样？ 未来状态分布、风险时点、轨迹区间
控制 L4 + L5 应该做什么？做了之后效果如何？ 操作序列、成功概率、执行记录与反馈

描述与解释、预测分属 L2 与 L3，是管线切分的核心依据。L2 回答“现在是什么”，L3 回答“为什么”与“将怎样”。合并两级，会让状态估计误差直接传播到预测，也会让模型选择污染状态后验。控制横跨 L4 与 L5：L4 在约束下搜索方案，L5 执行并采集反馈。

四目标也是范式评估的中立尺。判断一套数学对象能承载什么，不看它有没有对方的构件，而看它在这四个目标上各自能做到什么精度、在什么条件下失效。状态范式在描述、解释、预测、控制上给出完整级映射；变量范式在描述与群体效应上强，在个体轨迹与约束下控制上承载有限。

本章的总图可以压成一条线：N-S-R 说明系统为何运行，M-R-P 说明结构如何组织，M1-M6 给出功能模块，R-D-S 把模块展开为 42 维状态，G-M-A-R 给出对应操作，IODS 固定 L0 定义，PSE 承担 L1–L5 计算，双工程分别治理知识与执行计算，四目标把各级职责钉在描述、解释、预测、控制上。
