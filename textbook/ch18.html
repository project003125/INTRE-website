第18章 L4 干预规划

学习目标：(1) 列出 L4 的五类输入与四类约束；(2) 说明 P1–P5 的职能与验证对象；(3) 写出预算硬约束下的序列搜索问题；(4) 解释四类输出字段的含义；(5) 判断无可行解时的降级路径与门控状态。

18.1 输入与约束

L4 做的是决策，不是估计，也不是预测。它收到的状态与轨迹已经由 L2、L3 算出，自己的任务是在约束下选出一串可执行的操作。状态估计错了、轨迹偏了，是上游的问题；方案违反语法、超出预算、绕过伦理，是本级的问题。

输入 来源 内容 缺失后的处理
状态后验 \(\Psi_t\)L242 维均值与协方差无法定位靶点，规划中止
预测轨迹L3未来状态分布、级联路径、风险时点退化为当前状态快照规划
资源预算L3 参数层与当前 RES-D可支配的认知与执行资源按最低预算处理
环境约束S-P 环境参照系环境层级、方向模式、风险阈值采用中性环境假设并标记
伦理约束REVER脆弱性等级、门控状态、透明性要求按最高保护等级处理

约束分为四类。语法约束来自操作体系：每个操作必须落在直接合法靶点集内，系统性干预遵循 D 层稳定、R 层恢复、S 层重建的阶段顺序，组合遵循主靶点原则。预算约束来自资源状态：当前 RES-D 决定一天能做多少事，高能耗操作在序列中的位置受资源限制。环境约束调制优先级与风险阈值，同一套方案在高压职场与支持性环境下的可接受度不同。伦理约束收窄合法空间，并决定哪些方案必须走审批。

约束 来源 性质 违反后果
G-M-A-R 组合规则操作语法（L0）硬约束，定义级方案语法非法，不可执行
资源预算L3 参数与当前 RES-D硬约束，参数级执行中断、依从性崩塌
环境约束S-P 环境参照系情境调制方案与现实不匹配，效果衰减
伦理约束REVER 门控接口位，硬拦截高风险方案被冻结或驳回

硬约束与调制约束必须分开处理。硬约束违反时没有“打折执行”的选项，只能重规划；调制约束违反时可以在方案内调整优先级与剂量。把伦理约束当成软约束，等于把最需要拦截的方案放进了执行队列。

L4 也不拥有独立参数。成功概率、时间窗参数与 ROI 分布来自参数子层的调度控制库与操作转化库，L4 消费的是校准后的后验，不是自己另建一套估计。规划算法的修订与参数库的修订因此可以分开进行。

18.2 内部层 P1–P5

L4 内部按“约束装配、序列生成、评估、优化、封装”五个阶段组织。每层有独立输入、输出与验证对象，五层覆盖从预测轨迹到方案包的完整变换。

编号 缩写 中文全称 职能 输入 → 输出 验证对象
P1PCA规划约束装配汇集四类约束，按脆弱性等级收窄合法操作空间状态、轨迹、约束源、依赖雷达评估 → 合法空间约束完整性、空间正确性
P2PSG规划序列生成在合法空间内生成候选序列，遵循阶段顺序，剪除不可行分支合法空间 → 候选序列集搜索完备性、剪枝正确性
P3PEV规划评估对候选序列评分：成功概率、时间窗、预期效果与风险候选序列 → 带评分候选评分准确性、参数来源可追溯
P4POP规划优化在预算硬约束下选最优序列，处理效果、风险与依从性的多目标权衡带评分候选 + 约束 → 最优与备选最优性、约束满足性
P5PPK规划方案输出封装方案包与可读说明，提交伦理门控后交给 L5最优序列 → 方案包格式合规、可解释性、门控通过

P3 与 P4 不能合并。评分标准是“用什么尺子量”，选择策略是“怎么在候选里挑”，换 ROI 公式不应迫使换优化算法。P1 与合法空间定义是同一问题的两面：约束决定空间，不存在“先装约束、再单独定义空间”的中间步骤。P5 独立，是因为方案封装还包含可解释性生成与门控检查，验证对象不同于优化。

P1 的合法空间由四个乘子决定：靶点合法性矩阵、当前 RES-D 预算、环境调制、脆弱性等级。四个乘子任一为零，该操作就不可进入候选。P2 在这个空间里做组合搜索，并按阶段顺序剪枝。P3 给每个候选打分，P4 在已剪枝的集合上选最优。

D→R→S 的顺序是工程指南，不是自然规律。先做 D 层稳定，是为了让系统有足够的调度能力承接后续操作；先做 R 层恢复，是为了给结构层干预提供能量预算；最后做 S 层重建，是因为结构改变需要更长的持续投入。顺序反过来，在资源枯竭时直接做认知重构或深层结构干预，失败率与二次创伤风险都会显著上升。

18.3 资源预算硬约束下的操作序列搜索

规划问题可以写成一个带约束的最大化：

\[ \max_{a_{1:n}}\ \mathbb{E}\bigl[U(a_{1:n})\mid \Psi_t\bigr] \quad\text{s.t.}\quad \sum_{i=1}^{n}c(a_i)\le B(\Psi_t),\quad a_{1:n}\in\mathcal{A}_{\text{legal}},\quad \text{REVER}=\text{passed} \]

目标函数是序列的期望效用，约束分别是总能耗不超过当前认知预算、序列落在合法空间内、伦理门控通过。四个操作在 D、R、S 三阶段上的组合空间是 \(4^n\)，序列一长就爆炸。架构层面用三条硬限制收住搜索：单次序列不超过八步，单阶段操作数不超过三个，预算不可行的分支在生成阶段直接剪除。

搜索约束 取值或规则 依据 违反后果
序列长度上限不超过 8 步，初始建议值八步方案的预测依从率约 28%执行脱落，方案作废
阶段内操作上限每阶段不超过 3 个，初始建议值资源预算的自然推论单阶段过载，后续阶段无资源
预算剪枝不可行分支在生成阶段剪除计算效率搜索超时，候选质量下降
搜索时限超时输出当前最优候选并标记实时性要求无输出，临床流程中断
伦理前置门控未通过的方案不进入执行队列REVER 硬拦截高风险方案被误执行

八步方案依从率约 28% 这个数字，直接决定了长度上限。一个理论上更优但没人能做完的十二步方案，实际效果低于一个六步、能完成七成的方案。搜索的目标不是理论最优，而是在预算与语法之内找到可执行的最优。

一个常见的搜索过程是这样：当前 RES-D 为 0.34，日预算上限十分钟。候选序列里，先做深层 RELINK 的分支在 P1 就被脆弱性等级挡掉；先做 ALIGN 的分支在 P2 因阶段顺序被剪除；剩下的 GATE 与 MODULATE 组合进入 P3 评分。P4 在评分最高的三到五条序列里比较总能耗与预期效果，选出一条不超过预算、能在两周内完成的序列。

时间窗的识别来自相变窗口。系统在临界点附近对干预更敏感，某些时段做同一件事的边际效果显著高于平常。设计口径中，危机后三到七天的窗口有约四倍的效果放大；这是待验证的仿真取值，不是临床实测常数。规划时把它当作候选窗口排序依据，而不是当作承诺。

18.4 输出：序列、成功概率、时间窗、预期效果

L4 的输出是一个方案包，不是一句建议。方案包要能让 L5 直接执行，也要能让临床工作者看懂并否决。

输出字段 内容 用途
操作序列排序的 G-M-A-R 列表，含操作类型、靶点坐标、组合编码L5 逐步执行
成功概率序列整体与逐操作的预测成功概率风险沟通与备选排序
时间窗各操作的推荐执行时段相变窗口捕捉，安排节奏
预期效果序列级 ROI 与级联效应预测效果与成本的比较
可读说明操作、靶点、依据、预期效果的临床可读文本临床工作者理解与否决
门控状态通过、待审或驳回L5 决定是否执行
降级标记是否为保守方案审计与后续重规划

成功概率是分布，不是确定结论。同一个序列在不同初始状态、不同环境假设下的成功率不同，方案包给出的是当前条件下的预测值。预期效果包含级联放大：作用在枢纽模块上的操作，效果会沿依赖关系扩散到相邻模块，ROI 计算必须把这一部分算进去，否则会系统性低估高杠杆操作。

可读说明与门控状态不是装饰字段。临床工作者保留对方案整体或任一操作的否决权，否决理由进入审计日志并回流到伦理回环。没有可读说明，否决权无法行使；没有门控状态，L5 无法判断哪些操作可以开始。

方案包通常带一条主序列与两三条备选。备选不是冗余，而是给执行层留出替换空间：主序列的某个操作因现场条件无法执行时，L5 可以取同一阶段内评分次高的操作，而不必整包回退。备选序列的评分与主序列同源，审计时能看出替换是否降低了预期效果。

18.5 降级：无可行解时的保守方案

搜索空间在硬约束下可能为空。预算不足以支撑任何高能耗操作、阶段顺序无法满足、伦理门控直接驳回、搜索超时，都会导致无可行解。此时不强行输出高风险方案，而是退到风险最低的可执行子集，并显式报告降级原因。

降级场景 降级动作 报告内容
预算不足只保留低能耗的 GATE 与 MODULATE 操作预算缺口、被剔除的高能耗操作
阶段顺序不可满足输出当前阶段可做的稳定化子集，暂缓后续阶段缺失的前置条件
伦理门控驳回回退 P4 重优化，移除被驳回操作驳回理由与替代方案
搜索超时输出当前最优候选并标记未完成搜索已探索空间与剩余时限

降级方案必须带标记，不能伪装成正常方案。临床看到的应是一份“现在只能做这些”的清单，而不是一份被悄悄削弱的完整方案。降级不级联放大：L4 降级不触发 L5 降级，L5 照常执行保守方案；L5 回滚也不触发 L4 降级，L4 在重规划时正常搜索。

18.6 与 REVER 的接口：门控审批与透明度

伦理门控位于 P5 方案输出与 L5 输入之间，是级间检查点，不是 L4 的内部层。它检查的对象是方案包，不是状态估计；它回传的是约束与审批状态，不接管规划计算。

脆弱性等级先收窄空间，再谈审批。E0 到 E1 不收窄；E2 禁止 RELINK 作用于深层 STR-C，ALIGN 限浅层规则；E3 只允许 GATE 与 MODULATE，并强制外部转介；E4 方案须人工批准；E5 暂停自动规划，仅由人工处理。等级由依赖雷达五维与依附风险代理向量合成，任一命中即入档，就高不就低。

门控状态 含义 L5 可否执行 后续动作
passed一级红线未命中，或审批链已完成并获得批准可以执行进入 E1 剂量校准
pending审批链未完结，或超时自动转待审不可执行冻结执行，补充材料或等待终审
rejected一级红线拦截，或人工终审驳回不可执行回退 L4 重优化

审批链分四级：一级红线即时判定，命中即拦截；二级评估出具伦理意见；三级做前置核查；四级人工终审。三级与四级都有时限，超时方案自动转待审并冻结，不存在超时自动放行。这条规则把“没人处理”变成“不能执行”，而不是“默认通过”。

透明度要求落在可读说明的伦理子字段：命中哪些敏感标签、脆弱性等级多少、收窄了什么、为何仍可接受。临床工作者可对方案整体或任一操作行使否决，系统不能覆盖这一否决。门控规则属于伦理资产，修订不触发管线计算内核的修订；两边的版本与审计各自独立。
