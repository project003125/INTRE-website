## 关键经验

### 用户反馈链

1. **v3 → v7**：用户提出"需要更美"
2. **v7 → v8**：用户提出"颜色去掉，否则看不清"，并提出"晶格形式不止一种"
3. **v8 → v9**：用户要求"参考 DTI 图重画"，明确指出"5 种晶格都不满意"
4. **v9 → v10**：用户选择"球面网格"，希望尝试更多样式
5. **v10 → 回归 2D**：用户最终决定放弃 3D

### 设计教训

- **3D 不能替代视觉清晰度**：晶格在 3D 中难以数清节点
- **彩色干扰理解**：6 模块配色让用户无法分辨"哪个是节点"
- **DTI 纤维密度过度**：2000 条纤维虽然参考图风格，但反而让大脑形态模糊
- **晶格形态的探索**：42 节点在 3D 中无论球面/立方/树状都不够清晰
- **极简回退失败**：v9 单色处理后依然"不好看"

### 为何回归 2D

| 维度 | 3D 表现力 | 2D 表现力 |
|------|---------|---------|
| 节点数得清 | ❌ 透视遮挡 | ✅ 平面投影 |
| 关系可读性 | ❌ 旋转才看清 | ✅ 一眼读懂 |
| 视觉冲击力 | ✅ 沉浸感 | ⚠️ 需靠设计弥补 |
| 抽象概念表达 | ❌ 受几何限制 | ✅ SVG/CSS 灵活 |
