第3章 框架总览：INTRE核心资产与子系统

管线重构注记（2026-07）：本章成文于旧版"四系统并列"表述阶段。自 2026-07 管线体系更新后，UPLP / UBMP / UNIP 不再以"四大核心基础设施"形式独立并列，而是统一归属为 PSE 感知层 L1 的三个 IODS 输入端口（L1-S 语义端口 / L1-B 行为端口 / L1-N 神经端口），PSE 自身作为状态层（L2+）执行融合与动力学推理。本章 §3.2、§3.6 小结、FAQ 等处已按新边界做最小修订，保留学术内容与论证结构；具体新表述见 01-M-05/06/07 主页与 app-g 附录 G。

学习目标：完成本章后你应能够：(1)列举INTRE六大核心资产并按方法论/工程化/研究纲领三档分级；(2)描述 UPLP/UBMP/UNIP 三个 PSE 感知层输入端口的分工与协作关系，以及 PSE 状态层、REVER 伦理层的独立定位；(3)解释四阶范式转变框架及INTRE在其中的定位；(4)阐述框架的三层主张结构和版本演化协议；(5)识别IET v3.0的八级证据分类体系及其标注原则。

3.1 资产分级：方法论、工程化与研究纲领

INTRE框架包含六项核心资产，它们在理论地位和实证成熟度上并不等重。理解这种不等重性，是正确评估整个框架的前提。

第一项资产：功能层定位。这是INTRE最具诊断价值的贡献——它明确指出心理学需要一个介于神经层与现象层之间的功能描述层。这一判断即使未来M-R-D-S的具体版本被大幅修订也仍然成立，因为它是对学科结构性缺口的识别，而非某一具体理论的命题。功能层定位的稳健性来源于三条独立路径的收敛（系统科学、认知科学、工程实践）。

第二项资产：M-R-D-S状态语法。这是功能层的具体描述语言——六个模块(M1-M6)、三个维度(资源R、调度D、结构S)、42个子单元。M-R-D-S提供了将模糊的临床构念（如“焦虑”“抑郁”）分解为可定位的功能组件组合。然而，M-R-D-S的具体维数、模块边界和维度划分是可修订的工程选择，而非不可动摇的本体论真理。它的实证成熟度有待A/B/C三类子单元的测量工具开发和校准验证。

第三项资产：G-M-A-R操作语法。这是从M-R-D-S的状态空间中推导出的原子干预操作集——门控(GATE)、调制(MODULATE)、校准(ALIGN)、重联(RELINK)。每类操作对应状态空间中一个特定的、不可相互替代的功能靶点。G-M-A-R是INTRE作为“操作语法生成层”的核心竞争力。在23个中间层候选架构的遍历比较中，INTRE满足了操作语法生成层的全部条件（靶点特异性、操作可区分性、执行可转译性、反馈可校准性、跨流派翻译≥80/100）。

第四项资产：UPLP（统一心理语言端口）。UPLP是INTRE的知识基础设施层，包含PCUI（概念唯一标识）、PSA（语义架构）、PSL（专家词典）三个组件，其结构类比于医学领域的UMLS。UPLP的核心功能是为跨流派概念映射提供标准化平台。它的价值在于将“跨流派整合”从一个哲学口号转化为可操作的工程任务。

第五项资产：PSE（心理系统工程引擎）。PSE是INTRE的计算核心，包含五层架构（架构层、算法层、参数层、方法论层、协议层）、心智六论（MCT/MTT/MKT/MDT/MPT/MET）、四阶段仿真管线（PSE-I/M/P/C）。PSE的目标是将功能层状态向量转化为可计算、可预测、可校准的动力学系统。当前，PSE处于概念蓝图阶段——其理论规范完整，但大规模参数校准和实证验证尚未完成。PSE不是“已经工作的引擎”，而是“值得建造的引擎”的设计图纸。

第六项资产：UNIP（统一神经接口端口）。UNIP是INTRE新管线体系中 PSE 感知层 L1 的神经模态输入端口（L1-N，IODS 端口之一），与 UPLP（L1-S 语义端口）、UBMP（L1-B 行为端口）并列。它解决的核心问题是：如何将原始神经信号（EEG、fNIRS、PPG等）转换为功能层状态向量的神经似然 \( p(y_n \mid \Psi_t) \)。UNIP采用六层递进架构——L1采集规范(NAP)、L2信号校准(SCL)、L3神经特征定义(NFD)、L4神经-功能映射(NFM)、L5神经先验库(NPL)、L6实时引擎(RTE)——为PSE的多模态贝叶斯融合提供标准化的神经输入通道。UNIP与PSE之间通过双向通信协议（/func_likelihood、/state_estimate、/calibration_feedback）形成增强闭环：PSE的状态估计反馈回UNIP，用于实时个体化校准神经映射模型。当前UNIP同样处于规范设计阶段，其种子NFI（神经特征标识符）和NFM模型库的社区填充是后续工程化的核心任务。（2026-07 管线体系更新：旧表述"FLP 三大工程支柱"中的并列关系已统一为 IODS 三端口。）

资产分级与嵌套关系：这六项资产并不在同一层级上。

档次 资产 说明 可修订性
**第一档：方法论资产** 功能层定位 即使M-R-D-S被大幅修订，功能层作为分析层级的必要性仍然成立 极难修订（范式级）
**第二档：工程化资产** M-R-D-S、G-M-A-R 具体维数、模块边界和操作分类是可修订的工程选择 可修订（需强反例）
**第三档：研究纲领资产** UPLP / UBMP / UNIP（现统一为 PSE 感知层 L1 的三个 IODS 输入端口）、PSE 状态层 潜在价值高，但依赖后续验证和社区采纳 常规科学活动

UPLP封装了M-R-D-S和G-M-A-R（前者是状态语法，后者是操作语法，UPLP将二者纳入统一的知识基础设施），因此后两者也作为独立资产列出，以示其可独立评估的工程价值。

3.2 PSE 感知层端口 + 状态层 + REVER 伦理层

INTRE 框架的工程功能可分解为 PSE 感知层 L1 的三个 IODS 输入端口、PSE 状态层（L2+）与一个独立的伦理约束层。感知端口与状态层、伦理约束层的关系可概括为：UPLP 是语义端口（L1-S），UNIP 是神经端口（L1-N），UBMP 是行为端口（L1-B），三端口共同向 PSE 状态层（执行融合与动力学推理）输出标准化似然，而 REVER 是安全护栏。（2026-07 管线体系更新：原"四大核心基础设施并列"表述已替换为 IODS 三端口 + PSE 状态层的两系统边界。）

UPLP：L1-S 语义输入端口。UPLP 的任务是为 PSE 感知层提供功能层的语义通道输入。它回答"自然语言或文本输入可被映射到哪些形式化功能组件"。UPLP 的核心产出是 M-R-D-S 状态向量和 PCUI 概念映射库——通过 PSL 把自然语言/临床叙述编译为 PCUI 条目，再经 PSA 推理生成语义似然 \( p(y_s \mid \Psi_t) \)。UPLP 本身不回答"状态如何随时间变化"（那是 PSE 状态层的任务），也不回答"干预应如何设计"（那是 G-M-A-R 的任务）。它是 PSE 状态层和 G-M-A-R 的本体论基础——没有 UPLP 定义的状态空间，PSE 的动力学方程没有操作对象，G-M-A-R 的操作没有靶点。

PSE：状态层（L2+）融合与动力学子系统。PSE 的任务是将感知层三个 IODS 端口输出的似然与状态先验进行融合，并执行动态演化模型。它回答"给定当前状态和环境输入，系统未来会怎样演化"。PSE 的核心能力包括：通过 MKT 微分方程计算状态轨迹，通过 MTT 分析级联传播路径，通过 MDT 优化干预序列，通过 PSE-C 贝叶斯校准将群体先验更新为个体后验。PSE 是 INTRE 从"描述"走向"预测"的关键——它使心理学能够像数值天气预报那样，输出带置信区间的个体化轨迹预测。（详见第 18-21 章。）

UNIP：L1-N 神经输入端口。UNIP 的任务是将神经层观测信号转换为功能层状态向量的神经似然，输出至 PSE 感知层 L1-N 通道。它回答"在当前神经信号下，功能状态向量各个分量的概率分布是什么"。UNIP 的核心产出是实时神经似然 \( p(y_n \mid \Psi_t) \)、置信度区间以及赋能信号（信号质量、同步等级、人群覆盖等）。UNIP 是 IODS 三端口中专门处理神经生理信号的端口——与 UPLP（语义）、UBMP（行为）以并列的输入端口形式共同供 PSE 状态层融合。它与 PSE 之间通过双向通信协议形成增强闭环：PSE 将状态估计和校准残差反馈给 UNIP，UNIP 据此进行在线个体化模型微调。UNIP 不回答"功能状态如何演化"（那是 PSE 状态层的任务），也不回答"如何改变状态"（那是 G-M-A-R 的任务）。（详见第 22.6 节及 UNIP 专项文档。）

UBMP：L1-B 行为输入端口。UBMP（Unified Behavioral Measurement Port，统一行为测量端口）是 PSE 感知层 L1 的行为输入端口（IODS 端口之一），与 UPLP（L1-S）、UNIP（L1-N）并列，三者不再以"四大核心基础设施"形式与 PSE 并列。UBMP 的任务是将结构化行为观测——心理量表分数、EMA 条目、认知任务表现、数字表型特征——转化为实时行为似然 \( p(y_b \mid \Psi_t) \)。UBMP 采用三层架构：L1 行为测量注册库（观测函数、信效度矩阵、工具桥接参数），L2 校准与桥接引擎（IRT 跨工具等价转换、贝叶斯个体化校准、漂移检测），L3 行为似然 API（JSON-RPC 端点 /behavioral_likelihood 和 /calibration_feedback）。UBMP 的核心设计原则是：数值桥接前必须先经 UPLP 语义对齐——两个量表只有在 UPLP 确认它们测量同一 M-R-D-S 组件后，才能进行 IRT 跨工具等价转换。UBMP 不回答"语义含义是什么"（那是 UPLP 的任务），也不回答"状态如何演化"（那是 PSE 状态层的任务）。当前 UBMP 处于规范性规范阶段，观测函数示例参数需实证校准，多数工具对的桥接参数尚未估计。（详见 01-P-04 UBMP 专项论文。）

REVER：伦理护栏。REVER 的任务是在 AI 拟人化交互场景中，从架构上防止情感依赖和欺骗性交互。它回答"在保证功能效用的前提下，如何设计伦理上安全的 AI 系统"。REVER 的核心设计包括：非人格性公理（AI 不得声称有感受、有自我）、依赖雷达（实时量化用户依赖分数）、四道伦理门控和透明层（可审计日志）。REVER 不是独立于 IODS 和 PSE 的另一套语言，而是同一套语法在伦理维度的扩展应用——它将"结构伦理"从哲学原则转化为可执行的门控协议。（详见第 25-26 章。）

四者（端口 + 状态层 + REVER）的关系：UPLP（语义端口）、UNIP（神经端口）、UBMP（行为端口）共同构成 PSE 的感知层 L1；三端口均向 PSE 状态层（L2+）输出标准化似然，由 PSE 状态层执行融合与动力学推理；REVER 作为独立的安全护栏横跨感知层与状态层。四者共享同一套 M-R-D-S/G-M-A-R 语法，使得描述、输入、预测和干预可以在同一个形式化框架内无缝衔接。

3.3 知识基建：PCUI、PSA与PSL概览

UPLP的知识基础设施借鉴了医学领域统一医学语言系统(UMLS)的成功经验，由三个组件构成。

PCUI：心理概念唯一标识符。PCUI为每个心理概念分配唯一的标准化编码，将所有流派对同一功能现象的术语映射到同一个规范条目。例如，CBT的“核心信念（无价值感）”、精神分析的“负性自我表征”、人本主义的“自我概念贬低”都被映射到同一个PCUI条目，其M-R-D-S坐标被标注为M2-STR-R。PCUI解决了心理学长期存在的同义词问题（不同术语同一现象）和一词多义问题（同一术语在不同流派中含义不同）。每个PCUI条目包含：规范定义、流派术语映射、M-R-D-S坐标、参数先验分布、版本号和证据等级标注。（详见第14章。）

PSA：心理语义架构。PSA定义了PCUI概念之间的形式关系——模块依赖权重、级联路径模板、操作-组件映射（哪些G-M-A-R操作适用于哪些M-R-D-S组件）。PSA是UPLP的推理引擎：给定一个状态向量，PSA可以计算级联风险、识别枢纽节点、推荐优先干预靶点。PSA的依赖矩阵是PSE中MTT（心智拓扑理论）的输入。（详见第15章。）

PSL：心理专家词典。PSL提供自然语言到PCUI的映射接口。它包含：临床口语到PCUI的映射（“我心慌”→M4-DSP-B↑）、文化特定习语的映射（东亚文化中的“神经衰弱”→PCUI条目）、语境消歧规则（同一短语在不同上下文中映射到不同PCUI）。PSL使得MCT（心智编译理论）能够将非结构化的临床叙述编译为结构化的M-R-D-S状态向量。PSL是INTRE从学术语言下沉到临床应用的关键基础设施。（详见第15章。）

三者的关系可以类比为：PCUI是词典（概念的定义和编码），PSA是语法书（概念之间的关系规则），PSL是翻译器（自然语言到形式语言的转换接口）。

3.4 层级与开放：可修订性声明与版本演化

INTRE框架在设计上区分了不同层级的主张，并为每一层级设置了不同的修订门槛。这一设计防止了理论在面对反例时的两种病态反应：要么僵化地否认一切反例（教条主义），要么在每次反例后随意修改核心主张（机会主义）。

三层主张结构。INTRE的核心主张分为三个层级：

层级 内容 修订门槛 示例
**公理层** A0-A5：心智化智能体公理、N-S-R、模块化公理等 范式级，需极强反例 若N-S-R被证伪
**架构层** M1-M6、R-D-S、G-M-A-R 需三个独立领域系统性反例 若发现不可归入M1-M6的新功能
**参数与映射层** 阈值、常数、权重、概念映射坐标 常规科学活动 M3-RES-D恢复速率校准

版本演化与构念降级协议。INTRE采用分级构念状态管理体系：

状态 含义
**Normative Core** 当前规范核心，参与主模型
**Provisional Construct** 暂定构念，理论上必要但实证未完成
**Derived/Dependent Construct** 派生构念，不宣称独立
**Deprecated Construct** 经强反例评估后被降级或进入历史附录

强反例触发条件。框架为核心主张设置了明确的强反例触发条件。例如：(1)若发现稳定、可重复、具增量预测力的新心理功能无法归入M1-M6，则模块工程覆盖充分性主张被挑战；(2)若发现新的不可由R/D/S组合描述的心理状态变化维度，则状态语法工程覆盖充分性被挑战；(3)若发现公认有效且不可被G-M-A-R分解的新干预机制，则操作语法工程覆盖充分性被挑战。（完整清单见第29章。）

3.5 主张治理：IET v3.0证据分类学

INTRE最独特的元科学贡献之一，是其对理论主张进行系统化证据等级标注的治理协议——IET v3.0（INTRE证据分类学）。这一协议将理论主张分为八个等级，明确区分了定义、推导、事实、解释、预测、规范、证据和关系，防止将逻辑推导与经验验证混为一谈。

八级证据体系：

代码 名称 含义 示例
**D** 定义类 框架内部的概念定义、公理、术语规定 “M3-RES-D指意志模块的可调度资源”
**L** 推导类 从公理或定义出发的逻辑推论 “从R-D-S三维独立共存可推导出G-M-A-R四操作的正交性”
**F** 事实/历史规律类 已有经验研究确认的事实 “DMN与FPN在静息态下呈反相关”
**X** 解释类 对现象提供机制性解释框架 “反刍是M2-DSP-B失控导致的”
**P** 预测类 产生可检验的前瞻性预测 “M3-RES-D消耗速率在抑郁组比对照组高30%”
**N** 规范类 方法论规范、工程协议、伦理准则 “干预应遵循GATE→MODULATE→ALIGN序列”
**E** 证据类 经实证检验且获得支持的发现 “PSE-C校准后预测误差降低40%（预注册RCT）”
**R** 关系类 概念之间、理论之间的映射或兼容性关系 “依恋安全感映射到M4-RES-B和M2-STR-R的组合”

标注密度原则：IET v3.0不对每个句子进行标注，而是仅标注“铰链主张”——那些如果被证伪会显著影响框架核心结构的命题。目标密度为每千字符1-3个标签。非铰链位置依靠语言本身的诚实性（如使用“可以”“可能”“理论上”等限定词），避免标签过载。

分层治理的价值：IET v3.0使INTRE区别于那些将所有主张以同等确定性陈述的宏大理论。读者可以一眼看出：目前框架的大部分主张处于F级（与既有事实相容）或L级（逻辑推导），部分核心预测处于P级（有待检验），而E级（直接实证验证）的积累仍是未来的任务。这种透明性本身就是科学诚信的体现。

可证伪性声明：INTRE五条核心主张均被操作化为可检验的预测，并提供了具体的证伪路径。框架最脆弱的实证节点是M3-RES-D（意志资源）作为独立功能构念的存在性——其证伪需通过三通道收敛效度研究（生理指标、主观疲劳、行为表现的收敛性检验）。如果这一节点被证伪，RES-D的跨模块统一性将连锁崩塌，MODULATE操作的独立靶点将被动摇，但框架的其他部分（如STR三分法、DSP二分法）仍可能成立。框架预期自身的不完美，并内建了从这些证伪中学习、修正的演化机制。（完整可证伪性论述见第29章。）

本章小结：INTRE框架包含六大核心资产，按方法论/工程化/研究纲领分为三档：功能层定位属于第一档方法论资产，M-R-D-S和G-M-A-R属于第二档工程化资产，UPLP、PSE、UBMP、UNIP属于第三档研究纲领资产。PSE 感知层 L1 由三个 IODS 输入端口（UPLP-L1-S 语义、UBMP-L1-B 行为、UNIP-L1-N 神经）构成，三端口共同向 PSE 状态层（L2+）输出标准化似然，由 PSE 状态层执行融合与动力学推理；加上 REVER 伦理层，形成从静态地图到三端口输入、状态层推理、安全护栏的完整链路（2026-07 管线体系更新）。知识基础设施PCUI、PSA、PSL为跨流派翻译和临床编译提供了可操作的平台。框架的层级性和开放性通过三层主张结构、版本演化协议和强反例触发条件得到保障。IET v3.0证据分类学将理论主张的治理从哲学倡导转化为可执行的标注协议。五条核心主张均设有明确的证伪路径，框架最脆弱的节点是M3-RES-D的独立存在性。
