附录C PSE 六级管线速查

六级管线从静态定义走到执行反馈。每一级只回答一个问题，只输出契约规定的对象，参数归属与降级模式在级间固定。读表时沿“输入—输出”一列向下，就能看出一次完整调用如何流动。

C.1 级间契约

级输入输出参数归属降级模式
L0 本体无，静态定义坐标系、词汇、操作语法、结构约束不是参数不适用，无运行时
L1 观测文本、量表与 EMA、数字表型、EEG/fNIRS/PPG三模态观测向量与不确定度仪器参数某模态不可用则输出无信息编码，其余模态正常工作
L2 估计L1 观测加 L3 转移先验42 维后验均值与协方差无独立参数，消费 L1 与 L3融合失败退化为单模态最大后验
L3 动力学L2 后验加 S-P 环境驱动转移先验、未来分布、级联路径、风险时点、效果预测340 余个系统参数与 BMA 权重模型不确定由 BMA 加权消化
L4 规划L2 状态、L3 轨迹、资源与环境约束、伦理约束操作序列、成功概率、时间窗口、预期效果规划参数无可行解则降为低风险保守方案并报告
L5 执行L4 序列与剂量建议执行记录与依从性数据，回流 L1执行参数执行受阻则中止并回滚 L4

C.2 端口与降级

L1 的三个端口各自输出似然，不输出状态。UPLP 处理自然语言，UBMP 处理行为与数字表型，UNIP 处理神经生理信号。三路似然在 L1 汇总，进入 L2 融合。某一路缺失时，该路显式标记为无信息，不用其他路伪装。

端口层级输入输出缺失处理
UPLPL1-S，S1–S5自然语言与文本量表语义似然输出均匀分布并标记
UBMPL1-B，B1–B5行为记录、EMA、数字表型行为似然输出均匀分布并标记
UNIPL1-N，N1–N6EEG、fNIRS、PPG神经似然输出均匀分布并标记

C.3 动力学与读法

L3 的核心方程是加权动力学形式：\(d\Psi/dt=\sum_k w_k f_k(\Psi,E(t),\theta_k)\)。\(w_k\) 是候选方程的后验权重，\(\theta_k\) 是参数向量，\(E(t)\) 是环境驱动。运行期权重固定，校准期做参数、权重与状态的联合推断。

级间契约可携带伦理附件。L2 输出带访问分级与依附风险代理，L3 到 L4 带效果归属字段，L0 的术语实例带伦理标注。附件字段不改变各级主输出，只在原有契约上追加约束。

L2 不拥有参数。它消费 L1 的仪器参数与 L3 的系统参数，输出后验均值与协方差。这种设计让融合算法的改进不会触发仪器或动力学方程的修订，也让 L2 的误差可以被单独检查。

L4 的约束来自四处：L0 的操作组合规则，L3 的资源预算，S-P 的环境条件，伦理门控的脆弱性分级。四处同时装配，任何一处收紧都会缩小可行操作空间。L5 的反馈分两路，一路回到学习回路更新参数，一路进入伦理回环更新约束。

降级模式的共同原则是最保守可用。缺一个模态，该模态置为无信息；缺模型权重，用缓存版本；缺伦理服务，取更高脆弱性等级。降级不是静默跳过，必须在输出中标记，让下游知道哪一部分不可信。
