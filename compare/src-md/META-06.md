> **来源与性质**：双范式对比学习模块元层专题第 6 号。META-01 到 META-05 分别处理了硬核/保护带、整合可能性、失败模式、翻译成本、思维与训练。本件处理一个此前未展开的维度：**两套范式各自有什么伦理风险？各自需要什么治理路径？**

---

## 一、问题的提出

前面五件 META 都在处理认识论和方法论问题。但两套范式不只是认识论选择，也是**伦理选择**。

一个简单的观察：

- 变量范式把人变成**变量**——量表分数、行为频率、自我报告。
- 状态范式把人变成**状态轨迹**——42 维 Ψ、级联路径、风险时点。

两种“变成”都有伦理后果。

本件要追问：

> **两套范式各自有什么伦理风险？各自需要什么治理路径？**

---

## 二、变量范式的伦理风险

### 2.1 风险一：本质主义——把变量当实体

变量范式的硬核是“基本单位=变量”。当变量实在论被推到极端时，变量被当作**真实存在的心理实体**。

**伦理后果：**

| 后果 | 内容 |
|---|---|
| 标签化 | “你是高焦虑者”被当作对一个人本质的描述，而不是对一组测量读数的描述 |
| 本质化 | 群体差异（如性别、种族）被解释为内在变量差异，而非情境因素 |
| 归因内化 | 个体把问题归因于“我的智力不够高”“我的人格有问题”，而非环境 |
| 去情境化 | 变量被从情境中抽离，忽略文化、经济、社会结构的影响 |

**典型批评：** 智力测验的历史——它曾被用来支持种族等级论、优生学。这不是“测验本身有问题”，而是“把测验分数当作内在本质”有问题。

### 2.2 风险二：WEIRD 样本——以偏概全

变量范式的研究样本中 96% 来自 WEIRD 人群（西方、受过教育、工业化、富裕、民主），但仅占世界人口 12%。

**伦理后果：**

| 后果 | 内容 |
|---|---|
| 文化霸权 | WEIRD 样本的规律被当作“人类普遍规律” |
| 政策误导 | 基于 WEIRD 样本的研究结果被推广到非 WEIRD 人群，可能导致政策失误 |
| 认知不公 | 非 WEIRD 人群的心理现象被边缘化，甚至被病理化 |

### 2.3 风险三：构念膨胀——无限命名

PsycTests 数据库约 27,000 个量表，56% 未被任何论文引用。

**伦理后果：**

| 后果 | 内容 |
|---|---|
| 资源浪费 | 大量重复量表消耗研究资源 |
| 知识碎片化 | 每个量表可能测量的是同一底层状态的不同投影，但被当作独立构念 |
| 诊断混乱 | 临床实践中，不同量表可能给出不同结论，患者无所适从 |

### 2.4 风险四：测量工具的商品化

量表可以被商品化。心理测验产业年产值数十亿美元。

**伦理后果：**

| 后果 | 内容 |
|---|---|
| 利益驱动 | 测验开发者可能优先考虑商业利益而非科学质量 |
| 测量垄断 | 某些测验被机构垄断，限制了研究和临床实践 |
| 过度诊断 | 测验被过度使用，导致过度诊断和过度治疗 |

## 三、状态范式的伦理风险

### 3.1 风险一：监控——把状态追踪变成监视

状态范式的核心是追踪状态 Ψ。这意味着持续采集数据（EMA、神经信号、行为数据）。

**伦理后果：**

| 后果 | 内容 |
|---|---|
| 隐私侵蚀 | 持续状态追踪可能侵犯个人隐私 |
| 监控社会 | 如果状态追踪被雇主、保险公司、政府使用，可能形成监控社会 |
| 自我规训 | 个体可能因为被持续追踪而改变行为，形成“被观察的焦虑” |

### 3.2 风险二：操控——把干预变成操纵

状态范式的核心是 G-M-A-R 操作。它明确知道“哪个操作作用于哪个靶点会改变什么状态”。

**伦理后果：**

| 后果 | 内容 |
|---|---|
| 自主性侵蚀 | 如果干预过于精准，个体的自主选择空间可能被压缩 |
| 操控风险 | 干预技术可能被用于非治疗目的，如政治宣传、商业营销 |
| 责任归属 | 如果一个 Agent 的干预序列导致了不良后果，责任归谁？ |

### 3.3 风险三：状态标签——把 Ψ 分量变成新标签

变量范式有“高焦虑者”，状态范式可能产生“M4-RES-D 偏低者”“M2-DSP-B 过度激活者”。

**伦理后果：**

| 后果 | 内容 |
|---|---|
| 技术化标签 | 把人的状态还原为技术参数，可能剥夺人的主体性 |
| 碎片化身份 | 人被分解为 42 维状态向量，可能忽略人的整体性 |
| 治疗关系异化 | 治疗师可能把来访者当作“状态向量”而非“人” |

### 3.4 风险四：技术门槛——加剧不平等

状态范式需要密集纵向数据、多模态采集、高计算资源。

**伦理后果：**

| 后果 | 内容 |
|---|---|
| 资源不平等 | 只有富裕机构、富裕国家才能使用状态范式 |
| 数字鸿沟 | 需要智能手机、可穿戴设备、网络连接，可能排除低收入人群 |
| 知识垄断 | 状态范式的技术复杂度可能导致知识垄断 |

## 四、两种伦理风险的根本差异

### 4.1 差异一：风险来源不同

| 维度 | 变量范式 | 状态范式 |
|---|---|---|
| 风险来源 | 把变量当实体 | 把状态当可操控对象 |
| 风险性质 | 认知性风险（错误认知） | 关系性风险（权力关系） |
| 受害者 | 被标签化的人群 | 被监控、被操控的个体 |

### 4.2 差异二：风险的可修复性不同

| 维度 | 变量范式 | 状态范式 |
|---|---|---|
| 本质主义 | 难以根治——硬核决定 | — |
| WEIRD 样本 | 可以部分修复——多样化样本 | — |
| 构念膨胀 | 难以根治——硬核决定 | — |
| 监控 | — | 可以通过治理修复 |
| 操控 | — | 可以通过治理修复 |
| 状态标签 | — | 可以通过治理修复 |
| 技术门槛 | — | 可以通过政策部分修复 |

**关键发现：** 变量范式的伦理风险大多是**硬核层面的**——本质主义、构念膨胀是硬核决定的，无法通过保护带修正根治。状态范式的伦理风险大多是**保护带层面的**——监控、操控、状态标签、技术门槛可以通过治理修复。

### 4.3 差异三：治理路径不同

| 维度 | 变量范式 | 状态范式 |
|---|---|---|
| 治理重点 | 防止变量被本质化 | 防止状态被滥用 |
| 治理工具 | 统计素养教育、文化敏感性训练 | 隐私保护、知情同意、伦理审查 |
| 治理层级 | 研究者个人层面 | 制度层面 |
| 治理难点 | 硬核层面的风险难以通过个人努力解决 | 技术复杂度导致治理困难 |

## 五、状态范式已有的治理工具

状态范式在治理方面已有一些工具，值得梳理：

| 治理工具 | 来源 | 内容 |
|---|---|---|
| **REVER 伦理护栏** | 07-S-01；17-S-01 | 六门控一回环（G0-G5 + EC），覆盖 L0-L5 全级 |
| **IET 证据分级** | 06-S-03 | D/L/F/X/P/N/E/R 八级体系，明确证据等级 |
| **IEGP 治理规程** | 26-WP-S3-36 | 实验全过程治理，含五门签字序、六类角色席位、漏洞六类制、止损线 G1-G4 |
| **ACCP 体系** | 26-WP-S1-16 | 控制点三级制（关一档/关二档/关三档） |
| **预注册与判据冻结** | 26-WP-S3-14 | 冻结假设、分析计划、主要结局、种子封存 |
| **边界登记** | 26-RPT-01 | RDS/GMAR 边界外维度登记（11 项） |
| **强反例触发协议** | 01-M-00 | 框架核心主张的可证伪条件 |

**关键观察：** 状态范式在治理方面已有相当完善的工具链。这说明它**意识到了自己的伦理风险**，并建立了相应的治理机制。

## 六、变量范式的治理工具

变量范式也有治理工具：

| 治理工具 | 内容 |
|---|---|
| **预注册** | 研究前冻结假设、分析计划、主要结局 |
| **开放科学** | 开放数据、开放材料、开放代码 |
| **多宇宙分析** | 报告所有合理的分析路径 |
| **注册报告** | 研究前评审，接受后无论结果如何都发表 |
| **文化敏感性训练** | 训练研究者识别文化偏见 |
| **统计素养教育** | 教育研究者和公众正确理解统计结果 |

**关键差异：** 变量范式的治理工具主要在**研究实践层面**（预注册、开放科学），状态范式的治理工具主要在**实验治理层面**（IEGP、ACCP、REVER）。两者都有效，但治理的焦点不同。

## 七、两套范式共同面临的伦理问题

### 7.1 问题一：知情同意的复杂性

两套范式都需要知情同意，但状态范式的知情同意更复杂：

- 变量范式：同意参加研究，同意测量某些变量。
- 状态范式：同意持续状态追踪、多模态数据采集、干预序列执行。

**状态范式的知情同意需要更详细的说明：** 采集什么数据、追踪多长时间、数据如何存储、谁能访问、干预序列如何决定。

### 7.2 问题二：数据所有权

- 变量范式的数据通常是量表分数，所有权相对清晰。
- 状态范式的数据包括神经信号、行为轨迹、状态估计——所有权更复杂。

**关键问题：** 状态估计 Ψ 是来访者的“数据”，还是研究者的“模型输出”？来访者有没有权利要求查看自己的 Ψ 轨迹？

### 7.3 问题三：干预的责任归属

- 变量范式：处理包由研究者设计，责任相对清晰。
- 状态范式：干预序列由算法搜索，责任归属更复杂。

**关键问题：** 如果算法推荐的 G-M-A-R 序列导致了不良后果，责任归谁？算法设计者？临床执行者？还是算法本身？

## 八、与 META-01 到 META-05 的衔接

| 前置件 | 核心结论 | META-06 的补充 |
|---|---|---|
| META-01 | 硬核不同但都不可证伪 | 硬核不同决定了伦理风险的性质不同 |
| META-02 | 方法论整合可能，本体论整合不可实现 | 方法论整合需要伦理框架来协调 |
| META-03 | 变量范式失败在硬核层面，状态范式失败在保护带层面 | 伦理风险的可修复性也遵循同样的模式 |
| META-04 | 正向翻译成本低，反向翻译成本高 | 翻译过程中需要伦理审查 |
| META-05 | 两套范式需要不同的研究者 | 不同研究者需要不同的伦理训练 |

**核心衔接：** META-06 把前五件的元层结论落到了伦理层面——**两套范式不仅在认识论和方法论上不同，在伦理风险与治理路径上也不同。**

---

## 九、一句话总结

> 两套范式各自有伦理风险。变量范式的风险是认知性的——把变量当实体、WEIRD 样本、构念膨胀、测量商品化。状态范式的风险是关系性的——监控、操控、状态标签、技术门槛。变量范式的伦理风险大多是硬核层面的，难以通过保护带修正根治；状态范式的伦理风险大多是保护带层面的，可以通过治理修复。状态范式已有相当完善的治理工具链（REVER、IET、IEGP、ACCP、预注册、边界登记、强反例协议）。两套范式共同面临知情同意、数据所有权、干预责任归属等问题。
