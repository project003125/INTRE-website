## 逐项说明

### #01 右侧指示器可点击
- **位置**：屏幕右侧垂直栏（现象层/功能层/神经层三个圆点）
- **功能**：点击任意圆点直接滚动跳转到对应幕
- **交互**：鼠标点击
- **标签位置**：右侧栏底部

### #02 数据流连线
- **位置**：右侧指示器圆点之间
- **功能**：用流动的虚线连接当前幕与下一幕的圆点，显示数据从上到下流动的方向
- **动效**：虚线持续向下流动
- **标签位置**：SVG 右上角

### #03 坐标实时读数
- **位置**：屏幕左下角
- **功能**：鼠标移动时实时显示对应的世界坐标 X / Y / Z 值
- **样式**：半透明深蓝底框，等宽字体
- **标签位置**：底框右上角

### #04 遥测 HUD
- **位置**：屏幕右下角
- **功能**：实时显示 FPS（帧率）、ACT（当前幕编号）、SCR（滚动进度百分比）、LAT（帧延迟）
- **更新频率**：每 500ms 刷新 FPS，其余每帧更新
- **标签位置**：底框右上角

### #05 键盘切幕提示
- **位置**：屏幕底部中央（SCROLL 提示旁）
- **功能**：提示用户可按键盘 1/2/3/4 或上下方向键切换幕
- **交互**：按数字键跳转对应幕，方向键前进/后退
- **标签位置**：提示文字内联

### #06 噪点叠加
- **位置**：全屏覆盖
- **功能**：极淡的胶片颗粒噪点（opacity 0.04），消除数字画面的塑料光滑感，增加电影质感
- **混合模式**：overlay
- **标签位置**：右上角

### #07 辉光泛光
- **位置**：全屏覆盖
- **功能**：CSS 近似的 bloom 效果，让发光元素周围有柔和光晕溢出
- **混合模式**：screen，opacity 0.18
- **标签位置**：右上角

### #08 自定义光标
- **位置**：跟随鼠标
- **功能**：将默认箭头替换为科技感圆环 + 中心点；hover 晶格节点时圆环放大变为金色
- **状态**：默认（小圆环）→ hover 节点（大金环）
- **标签位置**：光标旁
- **注意**：触摸设备自动关闭，恢复系统光标

### #09 拖尾粒子
- **位置**：跟随鼠标
- **功能**：鼠标移动时身后拖出蓝色光点尾迹，移动停下后粒子逐渐淡出消失
- **参数**：最多 40 个粒子，每帧衰减 0.04
- **标签位置**：无可见标签（隐形 canvas）
- **注意**：触摸设备自动关闭

### #10 幕切换扫光
- **位置**：全屏过渡效果
- **功能**：从一幕切换到下一幕时，画面从左到右扫过一道光带，标志进入新章节
- **触发**：滚动跨幕、键盘切幕、点击指示器
- **时长**：0.7 秒
- **标签位置**：右上角

### #11 粒子爆发
- **位置**：画面中心
- **功能**：进入新幕时从中心爆发出 24 个粒子（蓝/白/金三色），向外扩散后消失
- **触发**：与 #10 扫光同步触发
- **时长**：0.8 秒
- **标签位置**：右上角

### #12 打字机效果
- **位置**：各幕的正文文字（act-body / act-sub）
- **功能**：文字不是一次性出现，而是一个字一个字打出来，像终端输出代码
- **触发**：首次进入对应幕时自动开始
- **速度**：每字 30ms
- **标签位置**：第一幕副标题旁

### #13 数字滚动
- **位置**：第二幕"42 / 42 可数"徽章
- **功能**：进入第二幕时数字从 0 快速跳动到 42，像机械计数器
- **触发**：滚动进度 0.32~0.40 时触发
- **速度**：每帧 +2
- **标签位置**：徽章旁

### #14 节点详情面板
- **位置**：屏幕中央弹窗
- **功能**：点击晶格中的任意节点，弹出面板显示该维度（如 M1×RES-D）的名称和描述
- **交互**：点击节点打开，点击 × 或按 ESC 关闭
- **样式**：半透明深蓝底 + 毛玻璃模糊
- **标签位置**：面板右上角

### #15 通道状态灯
- **位置**：第四幕三通道图例（UPLP / UNIP / UBMP）旁
- **功能**：每个通道圆点周围有脉冲呼吸圈，模拟"通道在线工作中"的状态
- **动效**：2 秒周期的缩放 + 透明度脉冲
- **标签位置**：图例旁

## 修订指引

- 调整某个功能时，直接报编号即可，如：
  - "#07 太亮了，opacity 降到 0.10"
  - "#09 拖尾太长，粒子数减到 20"
  - "#11 爆发太大，粒子数减到 16"
  - "#14 面板太窄，宽度加到 480px"
- 删除某个功能时，报编号 + "去掉"
- 新增功能时，按位置分配下一个可用编号（#16 起）
