UPLP

统一心理语言端口 · PSE 感知层 L1-S 语义模态输入端口 语义通道 （2026-08 五层编译流水线 / 端口体系更新）
UPLP（Unified Psychological Language Port）是 INTRE 新管线体系 PSE 感知层 L1 的 语义模态输入端口（L1-S）（归属 PSE 感知层 L1，非对外独立系统，P7 已决）。它将自然语言输入（临床叙述、量表文本、自由陈述）经 五层编译流水线 S1-S5 转化为标准化的语义似然 p(ys|Ψ) ，输出观测块 {ys, σs}（42 维）。UPLP 强依赖 IODS（L0 本体）提供的 42 维 M-R-D-S 坐标系与 PSL-L/PCUI-L 词典——坐标系与词典的定义侧内容归 IODS，本页只覆盖 UPLP 本体的编译行为与接口契约。

一、五层编译流水线

UPLP 将自然语言编译为语义似然的核心流程，按 L1-I §3.1 契约固定阶段划分：分词 → 词汇匹配 → 坐标映射 → 置信度加权；本节在此基础上增加"似然输出"封装层，构成 S1-S5 五层。

S1 STP

Semantic Text Preprocessing

语义文本预处理：分词、实体识别、语境消歧、形态归一化，将原始文本拆分为可匹配的结构化单元。

涉及库：PSL-L（形态变体层、上下文规则层）

S2 SMT

Semantic Mapping & Tokenization

语义词汇匹配：将结构化文本单元匹配到 PSL-L 词条，生成 PCUI 候选集（含消歧与共现修正），每个候选携带初始置信度。

涉及库：PSL-L 语义映射层

S3 SCM

Semantic Coordinate Mapping

语义坐标映射：将 PCUI 候选映射到 M-R-D-S 坐标，生成 42 维分布（含坐标范围与分布形态）。稀疏观测维度在本步保留为空。

涉及库：PCUI-L（坐标映射、文化变体）

S4 SCW

Semantic Confidence Weighting

语义置信加权：按编译确定性（W编译、副词强度 λ、隐喻映射、文化权重）调制似然形状：歧义越大，σs 越大，似然越平坦。

涉及库：仪器参数层（本页 §三）

S5 SLO

Semantic Likelihood Output

语义似然输出：按 L1-I §2.4 观测块格式 {ys, σs} 封装，不可编译维度写入无信息编码。

涉及契约：L1-I §2.4 / §3.1

分层原则（契约固化）： UPLP 五层流水线的阶段划分属 L1-I §3.1 契约语义（01-M-10）——本文档只细化实现，不得改变输入类型、转换流程的阶段划分或输出形式。换言之，"分词 → 词汇匹配 → 坐标映射 → 置信度加权 → 似然输出"的拓扑形态已被契约固化，任何合并或省略都会破坏跨模态对齐与下游融合的一致性。

二、语义似然输出

UPLP 的最终输出为按 L1-I §2.4 观测块封装的语义似然 p(ys|Ψ)，由 PSE 状态层（L2+）消费并与行为、神经通道联合融合。

约定项规定
似然形式截断高斯 p(ys[i] | Ψ[i]) = g(ys[i]; Ψ[i], σs[i])，g 为定义在 [0,1] 上的高斯核（截断归一化）
观测值域ys[i] ∈ [0, 1]（IEEE 754 float64）
不确定度值域σs[i] ∈ [0, 1/√12]（IEEE 754 float64）
维度索引idx(m, s) = (m-1) × 7 + s，模块-维度标识符不允许重排（L1-I §2.2）
端点POST /semantic_likelihood
消费方PSE 状态层 L2（01-M-11）——三通道贝叶斯融合的语义似然项
失败语义端点不可用按模态不可用处理，由 L1 汇总层执行降级协议（L1-I §3.5）
// /semantic_likelihood 输出观测块（示意值，完整传输为 42 维；索引规则见 L1-I §2.2）
{
  "y": [0.42, 0.61, 0.30, 0.55, 0.47, 0.38, 0.52, 0.5, 0.5, 0.5, 0.5, 0.5, 0.5, 0.5],
  "sigma": [0.11, 0.08, 0.15, 0.12, 0.09, 0.14, 0.10, 0.2887, 0.2887, 0.2887, 0.2887, 0.2887, 0.2887, 0.2887]
}

σs 的语义： σs[i] 是第 i 维观测的标准差，σ 越大，对应似然越平坦，在 L2 融合中的权重越低。σs 的来源是编译置信度——PSL 对文本编译存在歧义时（同一文本匹配多个 PCUI 或坐标分散），σs 增大，似然更平坦，信息量更低。W编译 是这一连续谱的调节旋钮。

三、仪器参数

UPLP 的仪器参数由 L1-I §3.1 登记其存在与归属，定义与校准属 UPLP 本体（01-M-07 §四）。全部参数当前为理论设定值，需 PSE-C 实证校准（P2i-m），参数修订属 L1 仪器层，不触发 IODS 架构级修订。

参数符号含义作用位置当前状态
编译置信度W编译（含副词强度 λ）编译确定性对似然形状的调制权重；λ 为"极其""非常"等副词的强度系数S4 置信度加权理论设定值 P2i-m
语义衰减率τ语义强度随时间的衰减率（观测时效校准，τ 校准的是"陈述何时生效、以何种权重计入当前观测"，不构成对心理状态 Ψ 自身演化的预测——后者属 L3）S4 置信度加权（时序观测）理论设定值 P2i-m
隐喻映射强度隐喻"脑子转不动""心累"等隐喻表述向 M-R-D-S 坐标（如 M2-RES-D↓、M4-DSP-B↑）的映射强度S2/S3 匹配与映射理论设定值 P2i-m
文化权重W文化各文化下 M-R-D-S 坐标权重的调整系数（如东亚文化下表达强度系数）；结构由 IODS PCUI-L 定义，数值由 UPLP 校准S3/S4 映射与加权理论设定值 P2i-m

校准轴： 群体先验（注册库标准参数 + 知识生产流水线积累的编译统计）→ 个体后验（PSE-C 临床数据贝叶斯校准 + 个体编译历史反馈，层级收缩个体化）。参数校准属"参数填充"层级（数据 → 参数值，WP-04 §3.5），不触发架构级修订。

四、降级模式

UPLP 的降级模式与 L1-I §四（降级协议）保持一致：缺一模态 → 精度下降不瘫痪（WP-07 §6.1 降级运行）。语义模态的降级分两个粒度。

降级类型触发场景处理
维度级降级模态可用，但文本仅覆盖部分维度（不可编译维度）未覆盖维度写入无信息编码，覆盖维度正常输出
模态级降级整个语义模态不可用（L1-I §4.1 判定：数据流中断 / 数据质量不达标 / 主动禁用）观测块整体写入无信息编码，其余模态正常输出
编译歧义（非降级）同一文本匹配多个 PCUI、坐标映射分散σs 增大，似然更平坦，在 L2 融合中权重降低（与"无信息编码"是同一原理的连续谱，无信息编码是"完全歧义"的极限形式）
强依赖边界 · IODS 不可用坐标系或词典缺失语义编译无法运行（强依赖，无降级）
强依赖边界 · L1-S 不可用UPLP 端点不可用PSE 将 p(ys|Ψ) 视为无信息（p = 常数），退化为行为 + 神经双通道融合
词典版本过期语义锚定版本过期（L1-I §5.3）接收方要求当前版本锚定，否则按未对齐处理

无信息编码（与 L1-I 一致）： 观测值 y[i] = 0.5（U(0,1) 均匀分布均值 E[y] = 0.5）；不确定度 σ[i] = 1/√12 ≈ 0.2887（U(0,1) 标准差 SD[y] = 1/√12）；模态级降级时 modalities.semantic.available = false（工程层显式声明）。其数学语义：降级维度的观测块对应似然为常数（不随 Ψ 变化），在 L2 贝叶斯融合中不贡献信息。

契约四义务： 不伪造（禁止以非均匀分布值填充不可用维度）、不静默（降级必须在 modalities 声明中显式可见）、记录（降级事件写入审计日志）、恢复（模态恢复后从下一观测周期恢复正常输出）。

五、强反例协议

UPLP 的核心主张是可证伪的。若出现满足条件的强反例，相应主张应被修正或放弃。

ID主张证伪条件
SC1语义通道必要性（继承 WP-06 §4.7）证明自然语言中不包含任何可被稳定映射到 M-R-D-S 坐标的功能层信息（语义似然始终接近均匀分布，编译后 σs 恒接近 1/√12）；充分反例需在至少三个独立的高质量语料上复现
SC2IODS 强依赖（继承 WP-06 §4.7）证明存在无需 IODS 坐标系即可有效计算语义似然的路径，且其精度显著优于 UPLP 输出；充分反例需提供可复现的独立实现与公平比较
SC3五层流水线契约充分性（L1-I §3.1）发现一类合法语言观测无法经五层流水线（文本预处理 → 词汇匹配 → 坐标映射 → 置信度加权 → 似然输出）编译，且该信息对 L2 融合不可省略（需要改变 L1-I §3.1 规定的阶段划分）；充分反例需提供具体观测类型与 L2 融合中的信息损失论证
SC4仪器参数理论设定（P2i-m）PSE-C 校准后，某仪器参数（W编译、τ、隐喻映射强度、W文化）在独立数据上持续无法收敛或出现系统性偏差（如 W文化 在不同生态位下方向相反）；参数修订属 L1 仪器层，不触发 L0 架构修订

六、知识生产流水线

知识生产流水线（PCC-P → PCF-P → PCV-P）按 P1 决策从 L0 内容中移出，重新定位为 L1-S 的离线校准流程（01-M-07 §三，01-M-02 §1.3 行 76、§七 行 316 明确移入）。它是离线、非运行时的，持续为编译流水线供给、修正 PSL-L/PCUI-L 的术语实例层（R1 已决：术语实例层数据驱动修订，不触发架构级审查）。

PCC-P · 心理概念采集协议

原则：广度优先（先广泛覆盖各流派、各文化、各来源类型，容忍适度噪声）

四类来源：

  • 理论文献源：INTRE / CBT / 精神分析 / 人本 / 神经科学 / 跨文化
  • 临床实践源：去标识化案例、诊断手册、治疗师反馈
  • 社区与新兴源：患者社区、社交媒体、新兴概念
  • 多语言源：中文约 30% / 日韩约 15% / 其他约 10%

通过率目标： 约 95%（月度 500-1000 个概念原材料）

PCF-P · 心理概念形式化协议

原则：精度优先

团队： 15-20 人跨流派专家（INTRE/CBT/精神分析/人本/神经科学/文化心理学各 2-3 人）

五个形式化编译阶段：

  1. 理论中立化
  2. 参数化定义
  3. M-R-D-S 架构映射
  4. 多流派解释添加
  5. 逻辑一致性检查（五维自动化）

通过率目标： 约 60%

PCV-P · 心理概念验证协议

原则：权威性优先

评议团： 25-35 人（覆盖五大流派 + 独立研究者 + 临床工作者 + 方法学专家；性别 ≥ 40% / 文化多样性 ≥ 30% / 机构 ≤ 20% / ≥ 8 国）

两阶段评议： 结构化评议（14 天）→ 公开评议（14 天）

五重共识标准： 流派 ≥ 4 / 总体 ≥ 80% / 各流派 ≥ 60% / 临床 ≥ 70% / 无原则性冲突

通过率目标： 约 75%

与编译流水线的闭环： 运行时编译（S1-S5 流水线）中发现新术语 / 新用法 / 编译歧义 → 反馈至 PCC-P（采集新概念原材料）→ PCF-P（编译为 PCUI 草案）→ PCV-P（跨流派验证） → 验证通过后写入 IODS 术语实例层（PSL-L / PCUI-L 增补）→ 经词典加载接口（01-M-07 §6.2）更新 L1-S 本地词典缓存，后续编译生效。运行时的编译反馈（新术语、新用法进入术语主表）不触发 IODS 架构级审查（R1 已决：术语实例层数据驱动修订；核心定义层仍属 IODS）。

UPLP 的定位（2026-08 端口体系更新）： UPLP 是 INTRE 新管线体系 PSE 感知层 L1 的 语义模态输入端口（L1-S），与 UNIP（神经端口 L1-N）、UBMP（行为端口 L1-B）并列，构成 IODS 三输入端口。三端口通过 PSE 状态层（L2+）执行贝叶斯乘积融合，将各自输出合并为联合似然：

p(y | Ψ) = p(yb | Ψ) · p(ys | Ψ) · p(yn | Ψ)

当前进展： UPLP 处于规范设计阶段。定义侧内容（M-R-D-S 状态语法 / G-M-A-R 操作语法 / PCUI-L / PSL-L 等）已整体迁移至 IODS（L0 本体页）；UPLP 本体页聚焦于"编译行为 + 接口契约 + 离线知识生产流水线"。五层编译流水线与降级模式以本文档为准，待 PSE-C 实证校准（仪器参数 P2i-m）后可用于临床决策。
