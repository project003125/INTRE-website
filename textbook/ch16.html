第16章 L2 状态估计

学习目标：(1) 说明 L2 如何把三模态观测融成 Ψ_t 后验；(2) 列出 F1–F5 的职能与验证对象；(3) 解释 42×42 协方差为何不能截断为对角阵；(4) 区分运行时迭代滤波与校准期联合推断；(5) 判断三条间接验证路径各自能证明什么。

16.1 L2 的任务：从三模态观测到 Ψ_t 后验

状态估计回答的问题很窄：给定此刻的三路观测，Ψ_t 最可能是什么，以及这个判断有多不确定。它不问“为什么状态会这样”，也不问“下一步该做什么”。这两个问题分别属于 L3 动力学与 L4 规划。

L1 的三个端口各自输出一个 42 维观测块：语义块 \(y_s\) 来自语言编译，行为块 \(y_b\) 来自量表、EMA 与数字表型，神经块 \(y_n\) 来自 EEG、fNIRS、PPG 等信号。每个块都带同维度的不确定度向量 \(\sigma_s,\sigma_b,\sigma_n\)。观测块描述的是“看到了什么”，不是“状态是什么”。L2 的职责是把观测块、不确定度与 L3 给出的转移先验合成为状态后验。

\[ p(\Psi_t\mid y_t)\ \propto\ p(y_s\mid\Psi_t)\,p(y_b\mid\Psi_t)\,p(y_n\mid\Psi_t)\,p(\Psi_t\mid\Psi_{t-1}) \]

式中的三项似然由 L1 的观测块实例化而来，转移先验由 L3 的加权预测分布提供。L2 不定义似然的分布族，也不决定候选动力学方程。它只做一件事：把已经定义好的部件按贝叶斯规则组合起来，并完整保留组合产生的不确定性。

输入或输出 来源 维度 在融合中的角色
语义观测块 \(y_s,\sigma_s\)L1-S 语言端口42 + 42语言似然 \(p(y_s\mid\Psi_t)\)，σ 决定似然宽度
行为观测块 \(y_b,\sigma_b\)L1-B 行为端口42 + 42行为似然 \(p(y_b\mid\Psi_t)\)，未对齐时按无信息处理
神经观测块 \(y_n,\sigma_n\)L1-N 神经端口42 + 42神经似然 \(p(y_n\mid\Psi_t)\)，信号质量决定权重
转移先验L3 模型选择子层均值 42，协方差 42×42BMA 加权预测分布，约束相邻时刻状态
状态后验L2 输出均值 42，协方差 42×42供 L3 作初始条件、供 L4 作规划起点
诊断字段L2 输出标量有效模态数、迭代次数、收敛标志

描述与预测在数学上可以分开。后验更新只需要转移先验的数值，不需要知道动力学方程的候选集合；动力学预测只需要当前状态分布，不需要知道观测似然的具体形式。把两者合并，会让状态估计的误差直接混入预测误差，之后再也分不清一个偏差究竟来自“看错了”还是“算错了”。L2 作为独立一级，首先是为了保住这条误差分界线。

L2 的边界同样清晰：三模态端口内部实现不属于它，似然的分布族与仪器参数不属于它，动力学方程与 BMA 权重不属于它，干预规划与执行不属于它。L2 只消费这些部件，不重新定义它们。

16.2 内部层 F1–F5

L2 内部按“多传感器融合到状态后验”的通用管线分为五层。每层有独立的输入类型、输出类型与验证对象，层与层之间没有职责重叠，五层合起来覆盖从 L1 观测消息到 L2 后验输出的完整变换。

编号 缩写 中文全称 职能 输入 → 输出 验证对象
F1FIV融合输入验证校验观测消息的契约版本、42 维完整性、降级标志与语义对齐声明，拒绝不合规消息L1 观测消息 → 合规消息或拒绝记录契约合规性
F2FLC融合似然构造把三模态观测块实例化为似然函数；无信息模态生成常数似然合规观测块 → 三路似然似然实例化正确性、降级处理正确性
F3FPC融合先验消费接收 L3 的 BMA 加权预测分布，校验维度一致性与权重归一化L3 预测分布 → 合规先验先验格式一致性、维度匹配
F4FBU融合贝叶斯更新执行后验计算，支持多轮迭代，按后验变化阈值判断收敛三路似然 + 先验 → 后验均值与协方差数值精度、收敛性、迭代稳定性
F5FDO融合分布输出封装均值、协方差与诊断信息，按规定格式交给 L3 与 L4后验 → 输出消息格式合规、维度完整性、诊断完整性

F2 与 F4 不能合并。似然的分布族选择是观测侧决策，融合算法是估计侧决策，两者的修订节奏不同；换似然形式不应迫使融合算法重写。F1 与 F3 也不能合并。两者都在“接收并校验”，但来源不同、格式不同、失败模式不同：F1 面对的是模态降级，F3 面对的是先验不一致。合并会让两种校验共用一套错误码，审计时无法区分问题出在端口还是动力学。

F2 的动词是“实例化”，不是“定义”。似然的参数形式由各模态文档持有，F2 在运行时把具体观测值与不确定度代入。F4 的迭代次数不固定，由收敛判据控制；后验变化低于阈值即停，不用预设轮数。

16.3 后验更新与协方差输出

融合结果不是一个点，而是一个分布。L2 输出 42 维均值向量 \(\mu_t\) 与 42×42 协方差矩阵 \(\Sigma_t\)。均值给出每一维的中心估计，协方差给出每一维的方差以及维度之间的协方差。

\[ \mu_t[i]=\mathbb{E}[\Psi_t[i]\mid y_t],\qquad \Sigma_t[i][j]=\operatorname{Cov}(\Psi_t[i],\Psi_t[j]\mid y_t) \]

第 i 维的置信区间由对角元导出：

\[ \mu_t[i]\pm z\sqrt{\Sigma_t[i][i]} \]

完整协方差不能截断为对角阵。维度间的协方差承载融合带来的交叉信息：语言通道说“睡眠尚可”，神经通道说“交感活动偏高”，两条信息对 M1-RES-D 的约束方向不同，融合后的不确定性不能由两个独立方差相加得到。丢掉非对角元，等于丢掉通道之间的互补与冲突，后续 L3 的不确定度传播也会随之失真。

输出字段 类型 含义 下游用途
posterior_mean42 维向量后验均值 \(\mu_t\)L3 演化的初始条件；L4 规划的状态起点
posterior_cov42×42 矩阵后验协方差 \(\Sigma_t\)L3 初始不确定度；L2 自身置信区间
effective_modalities整数 0–3本次融合实际有效的模态数判断后验可信度；触发端口检查
iteration_count整数迭代滤波轮次诊断收敛成本与稳定性
converged布尔是否达到收敛判据未收敛时下游降低置信
timestamp时间字符串估计时刻时序对齐；闭环反馈的时间锚点

降级不需要为每种缺失模态写分支。L1 把不可用模态编码为无信息块，F2 将其转成常数似然，融合自动退化为剩余模态加先验。三模态全部缺失时，后验等于先验，输出仍是完整的 42 维均值与协方差，但均值与协方差完全由 L3 的预测分布决定。此时后验的“置信”只反映纯预测的不确定性，不反映任何当刻观测。

降级场景 融合行为 后验协方差的变化
单模态缺失该路似然为常数，剩余两路加先验相关维度方差增大，非对角元保留剩余通道信息
双模态缺失退化为单路似然加先验方差进一步增大，置信区间变宽
三模态全部缺失后验等于转移先验完全由 L3 预测协方差决定
行为块未对齐按无信息处理并写入审计日志与单模态缺失相同
先验不可用沿用上一时刻先验或均匀先验，并加诊断标记方差取所沿用先验的方差

16.4 迭代滤波：运行时与校准期两种模式

L2 需要 L3 的转移先验，L3 需要 L2 的状态估计作为演化起点。这是一个双向依赖，但不必合并两级。解决方式是迭代滤波：上一时刻的后验进入 L3，L3 输出加权预测分布，L2 把它当作先验，与本时刻观测融合，得到新的后验，再交回 L3。

\[ p(\Psi_t\mid\Psi_{t-1})=\sum_k w_k\,p_k(\Psi_t\mid\Psi_{t-1},\theta_k),\qquad \sum_k w_k=1 \]

运行时，BMA 权重固定。L2 收到的是加权后的预测分布，看不到内部有几个候选方程，也不参与权重更新。候选方程族的增删、权重的重新估计都发生在 L3 内部；L2 的融合算法不感知模型集合的变化。这条隔离让换积分算法、换候选方程、换似然形式三件事互不阻塞。

校准期是另一种模式。PSE-C 把模型权重、参数与状态序列放在同一次联合推断中，用真实数据重新确定各候选方程的后验权重。L2 在校准期提供历史状态估计序列，不改变自身的运行时行为；更新后的权重经 L3 的模型选择子层，在下一个运行时周期生效。

维度 运行时迭代滤波 校准期联合推断
触发方式每个观测时刻自动执行定期校准，离线执行
L2 的角色消费先验、输出后验提供状态估计序列
模型权重固定，不更新与参数、状态一起更新
参数只消费已校准值执行后验更新
迭代对象后验分布，直到变化低于阈值权重、参数与状态
产出当刻 \(\mu_t,\Sigma_t\)新的权重后验与参数后验

还有第三种调用方式用于快速筛查：只问“当前状态是什么”，不需要 L3 预测。此时 F3 不等待新的预测分布，直接把上一时刻后验当作先验，F4、F5 照常完成。层结构不变，改变的只是先验来源。

16.5 无地面真值下的间接验证：三条路径

心理状态没有独立于框架的地面真值。没有任何外部仪器能直接读出“M2-STR-R 的真实值”，因此 L2 无法用完全外在于框架的数据证明自己的后验正确。可行的约束来自三条间接路径，它们各自捕捉不同的问题，也各自有盲区。

第一条是多模态一致性检验。融合前三路似然对同一维度的峰值位置应当大致靠拢；若语言指向“资源充足”、行为指向“资源枯竭”、神经指向“唤起作用偏高”，峰值严重分歧就提示融合或端口校准出了问题。它复用三路观测块的独立输出机制，不需要额外采集数据。盲区是共享偏差：三个通道可能一起错，且错得一致。

第二条是 L3 预测精度反推。L3 以 L2 的 \(\mu_t\) 为起点做演化，用后续真实观测检验预测。若预测精度跨个体、跨时段持续偏低，L2 的估计质量被反向质疑。这条路径的弱点是误差不可分离：预测偏差同时包含 L2 的估计误差与 L3 的模型误差，模型误差占主导时，它对 L2 的判别力下降。

第三条是临床专家交叉校准。把 L2 后验的维度排序结构与独立临床评估的排序结构做一致性比较。临床评估本身也是理论构成的，因此这不是对外部真值的验证，而是算法通道与临床通道之间的交叉校准。它的价值在于临床通道相对独立于融合算法，能给排序结构提供有意义的约束。

方法 能证明什么 不能证明什么
多模态一致性检验通道之间是否失谐；融合或端口校准是否存在明显问题不能发现三通道共享的系统性偏差
L3 预测精度反推估计质量是否长期劣化；后验作为初始条件是否可用不能把 L2 误差与 L3 模型误差分开
临床专家交叉校准后验排序结构与临床判断是否一致；校准数据可服务 PSE-C不能构成独立于框架的外部真值确证

三条路径合起来，给 L2 提供的是相对约束，不是绝对正确。它们能发现“明显不对”，不能证明“完全正确”。在无地面真值的系统里，这是可执行的上限；把间接验证说成独立验证，会让使用者误以为后验已经获得外部背书。

16.6 无独立参数的制度含义

L2 不拥有独立参数。它消费 L1 的仪器参数来决定似然形状，消费 L3 的系统参数与 BMA 权重来决定转移先验。融合算法本身使用概率论的固定结构，没有需要校准的自由参数。

这不削弱 L2 的独立级地位。独立级由三个问题界定：它回答的功能问题是否与其他级正交，它的验证是否与其他级分离，它的修订是否与其他级隔离。参数所有权不在其中。把参数所有权当作独立性判据，会迫使每个级自建一套校准通道，最终得到四套互不一致的参数账。

制度上的含义很直接：仪器参数修订走 L1 的版本化流程，系统参数与权重修订走 L3 的校准流程，融合算法修订留在 L2 内部。三条修订线各自有负责人、各自有审计记录。任何一次后验异常，都可以沿参数来源回溯到具体端口或具体方程，而不是在一团共享参数里猜测。
